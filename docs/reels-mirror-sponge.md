## 1. 이 구성의 전제

제거력 하나만 보여주므로 **실연 비트가 하나**입니다. 여기서 두 가지가 결정됩니다.

### 분량은 짧게

| | |
| --- | --- |
| ❌ 40~50초 | 보여줄 게 하나인데 길면 늘어집니다 |
| ✅ **30~35초** | 비트 하나에 맞는 길이 |

> 디깅클럽 미션용이면 **30초 이상**이 권장 기준이므로 [확인], 하한은 지켜야 합니다.
> 아래 구성은 30~35초가 나오도록 짰습니다.

### 비교 대상이 있어야 제거력이 보입니다

"지워진다"만 보여주면 밋밋합니다. **"안 지워지던 것"** 이 먼저 있어야 합니다.

```
휴지로 문질러봄  →  안 지워짐   ← 4번 컷
스펀지로 문지름  →  지워짐      ← 7번 컷
```

이 대비가 이번 영상의 구조 전부입니다. **4번 컷을 빼지 마세요.**

## 2. 촬영 전 테스트 (10분)

**제거력이 실제로 어느 정도인지 작성자는 모릅니다.** 찍기 전에 거울 구석에서 확인하세요.

| 테스트 결과 | 대응 |
| --- | --- |
| 한 번에 확 지워짐 | 그대로 진행. 7번 컷을 짧게 |
| 여러 번 문질러야 지워짐 | 그대로 진행. 7번 컷을 **길게**, "몇 번 문질러야 됨" 자막 추가 |
| 거의 안 지워짐 | **촬영 중단.** 안 되는 걸 된다고 찍으면 안 됩니다 |

> 지워지는 정도를 확인한 뒤에 자막을 정합니다. 미리 정해두고 찍지 마세요.

## 4. ⚠️ 촬영 순서 — 되돌릴 수 없습니다

```
1단계  거울 그대로 둔 채   →  2, 3번 컷 (더러운 상태)
2단계  휴지로 문지르기     →  4번 컷 (실패)
3단계  스펀지 소개         →  5, 6번 컷
4단계  테이프 붙이고 반만 닦기 → 7, 8번 컷
5단계  테이프 떼고 마무리  →  9번 컷
6단계  훅(1번)은 8번에서 잘라 씀 — 따로 안 찍음
```

> 🚨 **촬영 전에 거울 닦지 마세요.** Before가 없으면 영상이 성립하지 않습니다.

**카메라 화면에서 거울 면을 손가락으로 2초간 길게 누르기** → `AE/AF 잠금` 표시가 뜨면 성공.
**컷마다 다시 걸어주세요.**

## 6. 세팅 — 거울 앞 자리 잡기

### ① 각도: 정면 금지, **15~30도 사선**

정면이면 카메라와 본인이 거울에 그대로 찍힙니다.
카메라를 켜고 **화면에 내 얼굴이나 폰이 보이면 각도를 더 트세요.**

### ② 조명: 반드시 **측면 45도**

| 위치 | 결과 |
| --- | --- |
| 정면 | **얼룩이 안 보임** — 영상 실패 |
| **측면 45도** | 얼룩·물때가 드러남 ✅ |

낮이면 **창가를 옆에 두고** 서면 됩니다.
**화면에서 얼룩이 안 보이면 촬영을 시작하지 마세요.** 이 영상은 얼룩이 보여야 성립합니다.

### ③ 옷·배경

검정·남색 상의. 거울에 비칠 범위의 잡동사니 치우기. 손톱·소매 정리.

### ④ 삼각대 고정

**7·8번 컷은 프레임이 1mm도 움직이면 안 됩니다.** 움직이면 비교가 안 읽혀요.

### ⑤ 마스킹 테이프

거울 **정중앙에 세로로** 붙이고 한쪽만 닦습니다. 경계가 칼같이 나옵니다.

## 7. 컷 리스트 (9컷)

> **찍는 시간**은 실제 촬영 시간입니다. 편집에서 잘라 쓰니 넉넉히.

| # | 편집 후 | 화면 | 카메라 | 찍는 시간 / 반복 | 자막 |
| --- | --- | --- | --- | --- | --- |
| **1** | 0~3s | **경계선 클로즈업** — 반은 더럽고 반은 깨끗 | 클로즈업 | *8번에서 추출* | **"왼쪽만 닦았는데"** |
| **2** | 3~7s | 얼룩진 **거울 전체** | 고정, 사선, 풀샷 | **10초 / 2번** | "자취방 거울 이 상태였음" |
| **3** | 7~11s | 얼룩 **클로즈업** — 물때·치약 튄 자국 | 거울 30cm까지 접근 | **10초 / 3번**<br>*각도 바꿔가며* | "물때랑 치약 자국" |
| **4** | 11~16s | **휴지로 문질러봄 → 안 지워짐** | 클로즈업, 고정 | **15초 / 2번** | **"휴지로는 이게 안 지워짐"** |
| **5** | 16~20s | 스펀지 손에 들고 보여주기 | 손 클로즈업 | **12초 / 2번** | **"다이소 2천원짜리"** |
| **6** | 20~22s | 스펀지에 **물 묻히는** 컷 | 클로즈업 | **8초 / 2번** | "물만 묻히면 됨" |
| **7** | 22~29s | **테이프 왼쪽만** 닦기. 위→아래로 천천히 | **고정 · 절대 안 움직임** | **30초 / 1번**<br>*끊지 말고 쭉* | "왼쪽만 닦아봄" |
| **8** | 29~32s | **경계선 클로즈업** | 클로즈업 | **12초 / 2번** | *(자막 없이 그림만)* |
| **9** | 32~35s | 테이프 떼고 **거울 전체** 깨끗한 샷 | 고정 → 살짝 뒤로 | **20초 / 2번** | **"2천원으로 이게 됨"**<br>"다이소에 있음"<br>"저장해두고 써먹어" |

### 컷별 주의

- **1번** — 따로 안 찍습니다. 8번에서 잘라 앞에 붙이세요.
- **4번** — **이 영상의 절반입니다.** 휴지로 여러 번 세게 문지르는 게 화면에 보여야 합니다. 대충 문지르면 "덜 닦은 거 아냐?" 소리 들어요.
- **5번** — 스펀지 **양면이 보여도 됩니다.** 코팅면을 설명만 안 하면 됩니다.
- **7번** — 끊지 말고 한 번에. **평소보다 느리게** 닦으세요. 빠르면 변화가 안 읽힙니다.
- **8번** — 자막 넣지 마세요. 한 번 비워야 리듬이 생깁니다.
