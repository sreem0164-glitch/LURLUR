# 릴스 연출안 — 거울 양면 스펀지 (얼룩제거 + 유리 코팅)

> 제품: 한쪽 = 얼룩 제거 / 반대쪽 = 유리 코팅
> 목표 분량: **30~45초** (디깅클럽 미션용이면 30~60초)

---

## 1. 감독 판단 — 이 제품의 강점

이 아이템은 숏폼에서 유리한 조건을 **세 개 동시에** 갖고 있습니다.

| 조건 | 이 제품에서 |
| --- | --- |
| **극명한 Before/After** | 얼룩 제거는 화면에서 바로 보임 |
| **구조적 반전** | "뒤집으면 코팅면" — 제품 자체에 2막이 내장 |
| **증명 가능한 결과** | 코팅 효과를 **물·김서림으로 눈앞에서 증명** 가능 |

대부분의 생활템 리뷰는 "써보니 좋다"는 말로 때워야 하지만,
이 제품은 **말이 필요 없습니다. 화면이 증명합니다.**

---

## 2. 킬러 컷 — 이 영상은 이 한 컷을 위해 존재합니다

> ### 거울 절반만 코팅 → 김 서림 → **반은 뿌옇고 반은 선명**

물 흘러내리는 컷보다 이게 훨씬 셉니다. 이유:

- **비교 대상이 같은 화면 안에** 있음 (전/후 컷 전환이 필요 없음)
- 김서림은 **누구나 겪는 불편** — 공감이 즉시 붙음
- 경계선이 칼같이 나오면 **조작 의심이 안 듦**

**이 컷을 먼저 확보하고, 나머지를 거기에 맞춰 붙이세요.**

### ⚠️ 촬영 전 리허설 필수

**이 제품의 코팅이 김서림 방지까지 되는지 저는 모릅니다.** 제품마다 다릅니다.
결과를 정해놓고 찍으면 안 됩니다 — **오늘 테스트부터 하세요.**

| 테스트 결과 | 대응 |
| --- | --- |
| 김서림 방지 됨 | 위 구조 그대로. 최고의 시나리오 |
| 김서림은 안 되고 **물 흘러내림만** 됨 | 킬러 컷을 **물 비딩 컷**으로 교체, 구조는 동일 |
| 코팅 효과가 눈에 안 보임 | **광택(반사)** 축으로 전환 — 조명 반사가 선명해지는 비교 |

> 안 되는 걸 된다고 찍으면 그 순간 채널 신뢰가 끝납니다. 되는 것만 보여주세요.

## 3. 씬 구성

### 훅 방식 — **결과 선공개**를 권합니다

| | A안 (권장) | B안 |
| --- | --- | --- |
| 구조 | **결과를 0초에 던지고** 역순으로 풀기 | 순서대로 진행 |
| 0초 화면 | 김 서린 거울, **반만 선명** | 더러운 거울 |
| 효과 | "이게 왜 이래?" → 이탈 방지 | 무난하지만 밋밋 |

숏폼은 첫 1초가 전부입니다. **가장 센 그림을 맨 앞에** 놓으세요.

---

### 컷 리스트

| # | 시간 | 화면 | 카메라 | 자막 |
| --- | --- | --- | --- | --- |
| **1** | 0~3s | **김 서린 거울, 반만 선명** (킬러 컷 선공개) | 고정, 사선 | **"왜 반만 이럴까?"** |
| **2** | 3~7s | 얼룩·물때 가득한 거울 전체 | 고정, 사이드광 | "자취방 거울 이 상태였는데" |
| **3** | 7~10s | 스펀지 꺼내 보여주기 (양면 구조가 보이게) | 손 클로즈업 | "이 스펀지 하나로" |
| **4** | 10~18s | **A면으로 반만 닦기** → 경계선 생김 | **고정 프레임 유지** | "한쪽은 얼룩 제거" |
| **5** | 18~20s | 경계선 클로즈업 (반 더러움 / 반 깨끗) | 클로즈업 | *(자막 없이 그림만)* |
| **6** | 20~25s | **스펀지 뒤집기** | 손 클로즈업, 슬로우 | **"근데 뒤집으면 코팅면"** |
| **7** | 25~30s | 코팅면으로 **반쪽만** 문지르기 | 고정 | "반만 코팅해봤다" |
| **8** | 30~36s | **물 뿌리기** → 코팅면 주르륵 / 반대쪽 맺힘 | 고정, **슬로우** | "물이 안 맺힘" |
| **9** | 36~43s | **김서림 테스트** — 반은 뿌옇게, 반은 선명 | 고정 | **"이게 되네"** |
| **10** | 43~48s | 거울 전체 코팅 마무리 / 선명한 거울 | 풀샷 | "이제 매일 안 닦아도 됨" |

> **4번과 7번의 "반만"** 이 이 영상의 전부입니다. 전체를 다 닦아버리면 비교 대상이 사라집니다.

---

## 4. 촬영 지시 — 거울 촬영의 함정

거울은 **초보가 가장 많이 실패하는 피사체**입니다. 아래 5개만 지키면 됩니다.

### ① 정면에서 찍지 마세요 — 15~30도 사선

정면이면 **카메라와 본인이 거울에 그대로 찍힙니다.**
비스듬히 서서 찍고, 거울 면이 화면을 꽉 채우게 하세요.

### ② 어두운 옷 · 배경 정리

거울은 **방 전체를 반사합니다.** 밝은 옷은 화면에 하얗게 박힙니다.
검정·남색 옷을 입고, 거울에 비칠 범위의 잡동사니를 치우세요.

### ③ 조명은 옆에서 — 얼룩은 측면광에서만 보입니다

| 조명 위치 | 결과 |
| --- | --- |
| 정면 | **얼룩이 안 보임** — 영상이 망함 |
| **측면 (45도)** | 얼룩·물때가 확 드러남 ✅ |

> 창가 자연광을 옆으로 받는 게 가장 쉽습니다. 얼룩이 안 보이면 각도부터 바꾸세요.

### ④ 삼각대 고정 — 비교 컷은 프레임이 같아야 합니다

손으로 들면 before/after가 미세하게 어긋나 **변화가 안 읽힙니다.**
삼각대가 없으면 책을 쌓아 폰을 기대 놓고, **4~9번 컷 내내 절대 안 움직이게** 하세요.

### ⑤ 마스킹 테이프로 경계 만들기

거울 정중앙에 테이프를 세로로 붙이고 한쪽만 작업하면
**경계선이 칼같이 나옵니다.** 촬영 직전에 테이프를 떼면 됩니다.
이 한 가지가 영상의 설득력을 가장 크게 올립니다.

### 추가

- **물 흘러내리는 컷은 슬로우모션**으로 (폰 기본 기능)
- 손이 계속 나오므로 **손톱·소매 정리**
- 김서림 테스트에 뜨거운 물을 쓸 경우 **화상 주의** — 대야를 거울 아래 두고 거리를 두세요

## 5. 자막 톤

설명하지 말고 **반응**으로 쓰세요. 화면이 이미 설명하고 있습니다.

```
왜 반만 이럴까?
자취방 거울 이 상태였는데
이 스펀지 하나로
한쪽은 얼룩 제거
근데 뒤집으면 코팅면
반만 코팅해봤다
물이 안 맺힘
이게 되네
이제 매일 안 닦아도 됨
```

> 5번 컷처럼 **자막 없이 그림만 가는 구간**을 한 번 넣으면 리듬이 생깁니다.

## 6. 디깅클럽 미션용이라면 — 추가 필수 요건

개인 채널용이면 위까지로 끝입니다. **미션 제출용이면 아래를 반드시 넣으세요.**

### 삽입 지점: 2번과 3번 컷 사이 (7초 지점)

| 추가 컷 | 화면 | 자막 |
| --- | --- | --- |
| 2-1 | **네이버 앱 → AI탭 진입** | "AI탭한테 물어봄" |
| 2-2 | *(화면)* "거울 물때 지우는 법" | |
| 2-3 | 답변에서 이 제품 발견 | "이런 게 있었네" |

> 진입 → 입력 → 답변 **3단계 다 노출**해야 요건 충족. 알림·계정명 안 찍혔는지 확인. (DO ④)

### 그 외 필수

- **정체성 한 줄** — "학식도 없는 방통대 3학년, 자취방 관리도 혼자" 같은 자막 하나
- **솔직한 코멘트 한 줄** — "코팅면은 힘 좀 줘야 함" 등 (DO ① 피상적 칭찬 금지)
- **해시태그** `#네이버` `#AI탭` `#네이버AI디깅클럽`
- **캡션 하단 문구** "네이버 AI 디깅클럽 활동의 일환으로 제작한 콘텐츠입니다."
- **제출물 4종** — 영상 · 캡션 · 썸네일 · 콘텐츠 제목
- **안전 영역** 1,080×1,350 안에 핵심 자막

### 썸네일

**1번 컷(김서림 반반)** 을 그대로. 이 영상에서 가장 강한 그림입니다.

## 7. 오늘 순서

```
1. 김서림·물 테스트 먼저        ← 결과 확인 후에 구조 확정
2. 거울을 일부러 그대로 두기     ← 미리 닦으면 Before가 없음
3. 테이프로 중앙 경계 표시
4. 삼각대 세팅 + 측면광 확인
5. 4~9번 컷을 프레임 고정한 채 연속 촬영
6. 훅(1번)은 9번 촬영분에서 뽑아 쓰기
```

> **거울을 미리 닦지 마세요.** 가장 흔한 실수입니다. Before가 없으면 영상이 성립하지 않습니다.
