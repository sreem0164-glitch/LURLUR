## AI탭 화면 크롭 (4·5·6번)

```bash
ffmpeg -ss 21 -t 9 -i "b9cd3cbc-______ai__________________.mp4" \
  -vf "crop=1020:620:30:150,scale=1080:-1,pad=1080:1920:0:(1920-ih)/2:black" \
  -c:a copy aitab_crop.mp4
```

- `crop=너비:높이:x:y` — 위아래를 더/덜 자르려면 `620`과 `150`만 조정
- 편집 앱에서 할 경우: **화면 영역만 남기고 확대**하면 동일
