### 훅 설계 — Before/After를 붙입니다

초판 훅은 **After 클로즈업 하나(1.5초)** 였습니다. 문제가 있었습니다.

> "2천원으로 이렇게 됨"이라고 해도 **시청자는 뭐가 "이렇게"인지 모릅니다.**
> Before를 못 봤으니 깨끗한 수도꼭지는 그냥 평범한 수도꼭지입니다.
> **광택은 비교가 있어야 광택으로 읽힙니다.**

→ 훅 안에 **Before(0.9초) + After(1.1초)** 를 붙였습니다.

| | |
| --- | --- |
| 소스 | 둘 다 **세면대 전체샷** — 같은 구도라 변화가 즉시 읽힘 |
| 처리 | **동일한 줌 크롭** (`crop=830:1476:0:222` → 1080×1920) |
| 이유 | After 클립 오른쪽 끝에 스펀지가 놓여 있어 프레임 밖으로 밀어냄. 수전도 커져 훅으로 유리 |

## AI탭 화면 크롭 — 질문 컷과 답변 컷을 다르게

초판은 `crop=1020:620:30:150` 하나로 처리했는데, **y=150에서 시작해 탭바와 질문 윗줄이 잘렸습니다.**
질문이 반만 보이고, 이 화면이 네이버 AI탭이라는 표시도 사라졌습니다.

→ **두 종류로 분리**했습니다.

### 원본 화면 좌표 (1080×1920 기준)

| 요소 | 위치 |
| --- | --- |
| 탭바 `< AI 블로그 카페 클립 …` | y ≈ 35~62 · x ≈ 189~841 |
| 질문 문구 | y ≈ 123~147 · x ≈ 363~833 |
| 답변 본문 시작 | y ≈ 181 |

### 질문 컷 (4번)

```
crop=670:140:178:25   →  scale=1080  (1.61배 확대)
overlay 중앙 / 자막 y=1290
```

탭바 + 질문만 담아 세로가 짧으므로 **크게 확대**됩니다. `AI` 탭이 선택된 표시가 보입니다.

### 답변 컷 (5·6번)

```
crop=800:1040:150:25  →  scale=1080  (1.35배 확대)
overlay y=420 (아래로 내림) / 자막 y=250 (상단)
```

탭바 + 질문 + 본문 + 표 + 사용법까지 한 화면에. 초판(1.06배)보다 글씨가 큽니다.

> **자막을 상단으로 올린 이유**: 밴드가 커지면서 하단 자막이 y=1700까지 밀렸는데,
> 인스타그램 하단 UI 영역은 **y=1470 이하**입니다 [확인]. 상단 안전 경계는 220px이므로 y=250에 배치.

### 배경

검은 레터박스 대신 같은 화면을 흐리게 깔았습니다 (`gblur=sigma=50`).
**성과 차이 데이터는 없습니다 [모름]** — 미관상 선택입니다.

## 자막 전문 — 하소연체

설명체는 밋밋합니다. **"아니 ~했는데"** 로 시작하는 수다 톤이 몰입이 빠릅니다.
친구한테 말 거는 느낌이라 시청자가 이야기 중간에 끼어든 것처럼 읽힙니다.

```
[1]  아니 이게 뭐야
[2]  2천원에 이게 된다고?

[3]  아니 3학년 2학기인데
     온라인이라 집이 강의실이야
     근데 이 꼴...

[4]  그래서 AI탭한테 물어봤거든
[5]  근데 단점까지 알려주네?
[6]  물 묻혀서 살살 문지르래

[7]  그래서 해봤지
[8]  (자막 없음)
[9]  아 근데 팔 좀 아파

[10] 개강 준비 끝!
     다이소 2천원이야
```

### 톤 규칙

| | 설명체 (이전) | 하소연체 (현재) |
| --- | --- | --- |
| 훅 | "이랬는데" | **"아니 이게 뭐야"** |
| 반전 | "2천원으로 이렇게 됨" | **"2천원에 이게 된다고?"** |
| 전달 | "AI탭한테 물어봄" | **"그래서 AI탭한테 물어봤거든"** |
| 발견 | "단점까지 알려주네" | **"근데 단점까지 알려주네?"** |
| 단점 | "팔 좀 아프긴 함" | **"아 근데 팔 좀 아파"** |

- **`아니` / `근데` / `그래서`** 로 문장을 이어 한 사람이 계속 말하는 흐름을 만듭니다
- 물음표를 살려 **반응을 유도**합니다 (`된다고?` `알려주네?`)
- 종결을 `~함` `~됨` 대신 **`~거든` `~네?` `~지` `~야`** 로

### 연결 논리

```
온라인 강의 → 집에서 들음 → 집이 곧 강의실 → 개강 전에 집부터 정리
```

3번 컷 3줄이 이 논리를 그대로 말합니다.

억지로 "개강"을 끼운 게 아니라 **인과로 이어집니다.** 2번에서 상황을 세우고,
9번에서 "개강 준비 끝"으로 닫아 앞뒤를 묶습니다.

> **학교명은 넣지 않습니다.** "온라인 강의라 집에서 듣는다"는 상황 서술로 대체했습니다.
> 특정 학교를 밝히지 않아도 공감 폭이 넓어지고, 같은 논리가 그대로 성립합니다.
>
> **요건 충족**: 브리프가 "캠퍼스, 전공, 학년 **등**"이라 했고 **3학년**이 자막에 있습니다 [확인].
> 농학과는 세면대 청소와 연결이 없어 자막에서 빼고 **캡션에만** 넣습니다.

### 정렬을 어떻게 확정했는가

v15·v16 은 음성 측정만으로 정렬했다가 두 번 다 틀렸습니다.
실패 이유와 최종적으로 쓴 방법을 남깁니다.

**실패한 방법 1 — 무음 종료점 순서대로 꿰기 (v15).**
컷 경계가 무음 끝에 붙는지만 확인했습니다. 전부 붙어 있었지만 그 지점에서
시작되는 발화가 한 줄 앞 대사였습니다. 이 음성에는 무음이 28개 있는데
문장 사이 무음(0.36s)과 문장 안 호흡(0.30s)이 길이로 구분되지 않습니다.

**실패한 방법 2 — 음절 수 기반 DP 정렬 (v16).**
발화 구간 27개에 대본 13줄 177음절을 배분했습니다. 결과가 v15 와 거의
같아서 자가 검증이 되지 않았고, 역시 틀렸습니다.

**실제로 통한 방법 — 청취 확인.**
음성 인식 모델을 이 환경에서 받을 수 없어(huggingface / modelscope /
openslr 전부 네트워크 정책 차단) 사용자 청취로 대조했습니다. 가정한
경계에서 음성을 잘라 "무엇이 들리는지"만 물었습니다. 초를 읽게 하면
반응 지연으로 값이 1.9초씩 밀려 쓸 수 없었지만, 조각을 듣고 받아쓰는
방식은 지연이 개입하지 않습니다.
