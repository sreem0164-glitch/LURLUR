### 훅 설계 — Before/After를 붙입니다

초판 훅은 **After 클로즈업 하나(1.5초)** 였습니다. 문제가 있었습니다.

> "2천원으로 이렇게 됨"이라고 해도 **시청자는 뭐가 "이렇게"인지 모릅니다.**
> Before를 못 봤으니 깨끗한 수도꼭지는 그냥 평범한 수도꼭지입니다.
> **광택은 비교가 있어야 광택으로 읽힙니다.**

→ 훅 안에 **Before(0.9초) + After(1.1초)** 를 붙였습니다.

| | |
| --- | --- |
| 소스 | 둘 다 **세면대 전체샷** — 같은 구도라 변화가 즉시 읽힘 |
| 처리 | **동일한 줌 크롭** (`crop=830:1476:0:222` → 1080×1920) |
| 이유 | After 클립 오른쪽 끝에 스펀지가 놓여 있어 프레임 밖으로 밀어냄. 수전도 커져 훅으로 유리 |
| 자막 | "이랬는데" → "2천원으로 이렇게 됨" |

### 푸시인 (3번 컷)

정지 화면에 움직임을 주고 시선을 석회로 모읍니다.

```
zoompan  z: 1.0 → 1.45 (4.5초에 걸쳐)
         중심: 수전 위치 (x 38%, y 33%)
         2160×3840으로 업스케일 후 처리 → 지터 방지
```

### ⚠️ 순서 수정 이력

`f3b4271f-5.mp4`는 초반에 **파란 스펀지로 문지르는 장면**이 들어 있습니다.
초판에서 이를 "수전 클로즈업"으로만 보고 **Before 자리(3번)** 에 배치했는데,
그러면 **AI탭으로 제품을 알기 전에 제품이 먼저 등장**해 서사가 뒤집힙니다.

→ **AI탭 구간 뒤(6번)로 이동.** 이제 순서가 맞습니다:

```
문제 확인 → AI탭에 질문 → 추천·주의사항 확인 → 사용 → 결과
```

> 자막도 `바로 사서 해봄` → **`바로 해봄`** 으로 고쳤습니다.
> 실제 구매 시점을 확인할 수 없어 [모름], 구매 순서를 단정하지 않습니다.

> 인~아웃은 시작점입니다. **눈으로 보고 0.3초 단위로 조정**하세요.
> 특히 7·8번은 손이 프레임을 가리는 구간이 있으니, **가장 덜 가리는 5초**를 고르세요.

## AI탭 화면 크롭 (4·5·6번)

```bash
ffmpeg -ss 21 -t 9 -i "b9cd3cbc-______ai__________________.mp4" \
  -vf "crop=1020:620:30:150,scale=1080:-1,pad=1080:1920:0:(1920-ih)/2:black" \
  -c:a copy aitab_crop.mp4
```

- `crop=너비:높이:x:y` — 위아래를 더/덜 자르려면 `620`과 `150`만 조정
- 편집 앱에서 할 경우: **화면 영역만 남기고 확대**하면 동일
- 결과: 베젤·키보드·작업표시줄·URL 쿼리스트링 전부 제거됨

### 연결 논리

```

```

억지로 "개강"을 끼운 게 아니라 **인과로 이어집니다.** 2번에서 상황을 세우고,
9번에서 "개강 준비 끝"으로 닫아 앞뒤를 묶습니다.

> **학교명은 넣지 않습니다.** "온라인 강의라 집에서 듣는다"는 상황 서술로 대체했습니다.
> 특정 학교를 밝히지 않아도 공감 폭이 넓어지고, 같은 논리가 그대로 성립합니다.

> **요건 충족**: 브리프가 "캠퍼스, 전공, 학년 **등**"이라 했고 **3학년**이 자막에 있습니다 [확인].
