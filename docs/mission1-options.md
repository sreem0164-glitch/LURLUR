# 미션1 주제 대안 4안 — 무엇을 찍을 것인가

> 결정 시한: **오늘 9/3(목)**. 제출 9/7(월), 예비일 없음.
> 공통 요건: AI탭 진입+사용 화면 필수 · 30~60초 · 개강 시즌성 · 나를 표현하는 키워드(방통대/농학과/3학년)

---

## 공통 뼈대 — 어느 안을 골라도 구조는 같습니다

```
AI탭에 물어본다  →  답을 그대로 실행한다  →  내가 판정한다  →  O / X
     (화면 = 근거)                          (여기가 차별점)
```

"급상승" 같은 **증명 못 할 주장을 하지 않고**, 화면에 찍히는 것만으로 근거가 서는 구조입니다.
안마다 달라지는 건 **무엇을 물어보고, 무엇으로 판정하느냐**뿐입니다.

---

## A안 — 개강 책상 식물: AI 추천 vs 농학과 검증

**질문:** "개강했는데 책상에 두기 좋은 식물 추천해줘"
**실행:** 오늘 구매 → 이틀 키움 → 농학과 관점 판정
**후킹:** "AI가 추천한 식물, 농학과가 검증합니다"

| | |
| --- | --- |
| 🟢 강점 | 전공이 판정관이 되는 구조. "이 조합은 과습 온다" 한 줄이 대체 불가 |
| 🔴 약점 | **이틀로는 식물에 변화가 안 납니다.** 성장이 아니라 진단만 보여줄 수 있음 |
| ⏱ 실행 | 오늘 구매 필수. 품절·매장 헛걸음 시 하루 날아감 |

## B안 — 캠퍼스 없는 대학생의 강의실 찾기 (카공 플레이스)

**질문:** "○○동에서 오래 앉아 공부하기 좋은 카페"
**실행:** 실제 방문 → 콘센트·좌석·소음·체류시간 체크 → O/X
**후킹:** "저는 캠퍼스가 없어서, 강의실을 직접 찾아야 합니다"

| | |
| --- | --- |
| 🟢 강점 | **공식 앵글 예시("카공 플레이스")와 정면 일치** → 요건 충족이 가장 안전. 이동·공간 컷이라 그림이 제일 좋음 |
| 🔴 약점 | **타인 개인정보 노출 위험**(DO ④) — 손님 얼굴 모자이크 부담. 농학과 전공을 못 씀 |
| ⏱ 실행 | 외출 촬영. 첫 1인 촬영에 외부 변수(사람·소음·촬영 허락)가 가장 많음 |

## C안 — 개강 책상 세팅: 있는 것으로, 오늘 바로 ⭐ 추천

**질문:** "형광등만 있는 방에서 키우는 식물 관리법" / "물 자주 못 주는 사람이 키우기 쉬운 식물"
**실행:** **이미 있는 식물·물건**으로 개강 책상 세팅 → AI 답변을 전공 지식으로 채점
**후킹:** "AI가 알려준 관리법, 농학과 3학년이 채점합니다"

| | |
| --- | --- |
| 🟢 강점 | **구매 0원, 배송·품절 변수 0, 오늘 바로 촬영 가능.** 전공 활용도 최대. 재촬영도 자유로움 |
| 🟢 요건 | 공식 앵글 "2학기 시작 필수 데스크테리어 tip"에 해당 |
| 🔴 약점 | 집에 식물·소품이 있어야 함. 그림이 밋밋해질 수 있어 **컷 설계로 보완** 필요 |
| ⏱ 실행 | **가장 안전.** 4일 안에 확실히 끝남 |

## D안 — 자취 N년차의 개강 장바구니

**질문:** "개강 앞둔 자취생 필수템 추천해줘"
**실행:** 추천대로 다이소 등에서 구매 → 실사용 → O/X
**후킹:** "AI가 사라는 거 다 사봤다"

| | |
| --- | --- |
| 🟢 강점 | 기존 채널(자취템) 자산과 연속성. 아이템 선택 자유도 높음 |
| 🔴 약점 | **자취템 검증은 이미 포화** — 마지막 펭귄 구간. 농학과를 못 씀 |
| ⏱ 실행 | 구매 필요. 아이템 여러 개면 60초 안에 안 들어감 |

## 결정 규칙

```
집에 식물이 있는가?
├─ YES  →  C안   (구매 없이 오늘 촬영, 가장 안전)
└─ NO   →  A안   (오늘 하나 사서 이틀 키움)

B안은 그림이 가장 좋지만, 첫 1인 촬영에 외부 변수가 너무 많음
     →  미션2 이후로. 촬영이 손에 붙은 뒤에 하면 강력함
D안은 차별성이 낮아 권하지 않음
```

### 왜 C안인가

지금 상황에서 가장 중요한 변수는 **"4일 안에 확실히 완성되는가"** 입니다.
동기지원서의 목표 ②가 *1인 제작 루틴 정착*이었고, 미션1은 그 **첫 한 바퀴**입니다.
첫 바퀴에서 외부 변수(배송·품절·타인 촬영)를 최대한 없애고 **완주하는 것**이 성과보다 중요합니다.

C안은 구매·이동·타인 노출이 전부 0이고, 재촬영이 자유로우며, 전공을 100% 씁니다.
**A안은 C안의 상위호환이 아니라, 집에 식물이 없을 때의 대체안**으로 두는 게 맞습니다.

## C안을 고를 경우 — 밋밋함을 막는 컷 설계

집에서만 찍으면 단조로워집니다. 아래 3개로 리듬을 만듭니다.

| 장치 | 방법 |
| --- | --- |
| **화면 전환** | AI탭 화면 녹화 ↔ 실물 컷을 빠르게 교차 |
| **채점 그래픽** | AI 답변 위에 ⭕/❌ 를 얹는 컷 — 판정이 눈에 보이게 |
| **각도 변화** | 탑다운 → 아이레벨 → 클로즈업 3종을 반드시 섞기 |

> 특히 **"AI 답변을 화면에 띄우고 그 위에 채점 표시를 올리는 컷"** 이 이 콘텐츠의 시그니처가 됩니다.
> 반복 가능한 포맷이라 미션2·3에서도 그대로 씁니다.
