# 전자책 퍼널 전략 — 프로필 링크 · 주제 선정

> 작성 기준: 근거 등급 표기. **[확인]** = 사용자가 말한 사실 / **[추정]** = 거기서 추론 / **[모름]** = 확인 불가

---

## 0. 확인된 사실

| 항목 | 내용 |
| --- | --- |
| 인스타 | **1,100 팔로워 / 운영 3개월** [확인] |
| 스레드 | **160명 / 주제: 자취템** [확인] |
| 크몽 | **AI 키워드 추출 → 네이버 블로그 대행 / 6개월 총 200만 원** [확인] |
| 현재 콘텐츠 | AI 데이터 기반 생활용품 큐레이션, 다이소 2천원 제품 검증 [확인] |
| 본인 | 방통대 농학과 3학년 [확인] |

**[모름]** — 팔로워 연령·성별·관심사 구성, 전자책 시장 가격대, 어떤 주제가 잘 팔리는지.
→ 아래 판단은 **오디언스-상품 정합성**이라는 논리에만 기대고 있습니다. 판매 데이터가 아닙니다.

---

## 1. ⚠️ 구조적 충돌

```
현재 콘텐츠:  다이소 2천원 생활템 검증
        ↓
오는 사람:    돈을 아끼려는 사람
        ↓
파는 것:      유료 전자책
```

**2천원을 아끼려고 온 사람에게 2만 원짜리를 파는 구조**입니다.
불가능하진 않지만, 같은 노력으로 훨씬 쉬운 길이 있습니다.

반대로 **크몽 6개월 200만 원**은 지불 의사가 있는 주제인데, 지금 채널이 그 사람들을 모으고 있지 않습니다.

---

## 2. 세 갈래

| | 방향 | 오디언스 일치 | 지불 의사 | 채널 변경 |
| --- | --- | --- | --- | --- |
| **A** | 채널에 맞춘다 — 자취·살림 전자책 | 🟢 높음 | 🔴 낮음 [추정] | 없음 |
| **B** | 수익 경험에 맞춘다 — AI 부업 전자책 | 🔴 안 맞음 | 🟢 높음 [추정] | 큼 |
| **C** | **축을 "제품"에서 "찾는 법"으로 옮긴다** | 🟡 전환 필요 | 🟢 높음 [추정] | **작음** |

### C안을 권합니다 — 이유

지금 이미 **AI탭으로 제품을 찾는 과정**을 찍고 있습니다. 디깅클럽 미션 요건이라 어차피 찍어야 합니다.
**그 과정을 콘텐츠의 부속이 아니라 주인공으로 올리면** 되는 것이라, 채널을 갈아엎을 필요가 없습니다.

```
지금:  "이 제품 좋다"           →  제품이 주인공
C안:  "이렇게 찾았다"           →  방법이 주인공
                                     ↓
                               전자책 = 그 방법
```

- 크몽 200만 원이 **"AI로 실제 돈을 벌어본 사람"** 이라는 증거가 됩니다 [확인]
- 전자책 주제가 **본인이 실제로 해본 것**과 일치합니다 — 안 해본 걸 쓰지 않아도 됩니다
- 생활템 영상을 계속 만들면서도 축만 바꾸면 됩니다

> **[추정]** 입니다. 판매 데이터로 검증된 게 아니라, 오디언스와 상품이 어긋나지 않는 조합을 고른 것입니다.

## 3. 전자책 주제 후보

### C안 기준 (권장)

| 주제 | 근거 | 비고 |
| --- | --- | --- |
| **AI 키워드 추출로 블로그 대행 시작하기** | 크몽 6개월 200만 원 [확인] | 실제 해본 것. 가장 안전 |
| **AI로 팔리는 아이템 찾는 법** | 현재 콘텐츠와 직결 | 채널 연결이 가장 자연스러움 |
| **본업 있는 사람의 AI 부업 세팅** | 방통대 재학 + 부업 병행 [확인] | 본인 상황 자체가 사례 |

### A안 기준 (채널 유지)

| 주제 | 비고 |
| --- | --- |
| 다이소로 끝내는 자취방 세팅 | 가격 저항 큼. **무료 배포 후 리스트 확보용**으로는 적합 [추정] |
| 자취템 실패 기록 | 검증 콘텐츠와 톤이 맞음 |

> **첫 전자책은 "실제로 해본 것"에서 고르세요.** 안 해본 주제는 쓰다가 막히고, 막힌 티가 납니다.

## 4. 프로필 링크 문구

### 원리

인스타 바이오 링크는 **클릭할 이유**가 한 줄에 있어야 합니다.

| ❌ 안 되는 것 | 왜 |
| --- | --- |
| "프로필 링크 확인" | 클릭할 이유가 없음 |
| "전자책 판매 중" | 파는 사람 사정이지 보는 사람 사정이 아님 |
| "많은 관심 부탁드립니다" | 요청이지 제안이 아님 |

| ✅ 되는 것 | 왜 |
| --- | --- |
| **구체적 산출물** (숫자·개수) | 뭘 받는지 명확 |
| **즉시성** (바로·오늘) | 지금 클릭할 이유 |
| **영상과의 연결** | 방금 본 것의 연장 |

### 문구 예시

**리스트형 (무료 배포용)**
```
영상에 나온 제품 전부 여기 ↓
다이소 자취템 리스트 ↓
```

**방법형 (C안 / 전자책)**
```
AI로 제품 찾는 프롬프트 ↓
이거 찾을 때 쓴 AI 방법 ↓
AI로 부업 만든 기록 ↓
```

**증거형 — 본인 실적만**
```
AI 부업으로 6개월간 번 기록 ↓
```

> **숫자는 정확히 쓰세요.** "6개월 총 200만 원"을 **"월 200만 원"으로 쓰면 허위**입니다 [확인].
> 수익 관련 과장은 표시광고법 문제가 될 수 있고, 무엇보다 한 번 들키면 채널이 끝납니다.

### 클릭은 영상에서 만들어집니다

프로필 문구만으로는 클릭이 안 납니다. **영상 안에서 링크를 언급해야** 합니다.

```
영상 마지막 자막:  "제품 리스트는 프로필에"
캡션 첫 줄:        "영상 속 제품 전부 프로필 링크에 정리"
```

## 5. ⚠️ 디깅클럽 미션 콘텐츠에는 붙이지 마세요

미션 영상은 **네이버 AI 디깅클럽 활동물**입니다 [확인].
여기에 개인 전자책 판매를 유도하는 건 문제가 될 수 있습니다.

| 콘텐츠 | 전자책 유도 |
| --- | --- |
| 미션 제출·업로드 영상 | ❌ 붙이지 말 것. 붙이려면 **운영사무국에 먼저 확인** |
| 개인 채널 일반 콘텐츠 | ⭕ 자유 |

> 프로필 링크 자체는 상시 걸려 있는 것이라 문제 소지가 적지만,
> **미션 영상 캡션·자막에서 직접 유도하는 것**은 확인 없이 하지 마세요. [추정 — 규정 원문에 명시된 바 없음]

## 6. 순서

```
1. 주제 확정          ← 실제로 해본 것 중에서
2. 무료 리드 자료 먼저  ← 리스트·체크리스트 1장
3. 프로필 링크에 무료 자료 걸고 반응 관찰
4. 반응 있으면 유료 전자책
```

무료 자료를 먼저 거는 이유: **지금 오디언스가 지불 의사가 있는지 [모름]** 이기 때문입니다.
추측으로 유료부터 만들면, 안 팔렸을 때 원인을 알 수 없습니다.
