## 2. 공고와 양식이 말해주는 심사 기준

### 양식이 대놓고 적어둔 문장 — 여기가 채점표입니다

> **"일정은 시장경제 자유의 가치를 경험하고, 본인의 진로 포부와 연계되도록 구성해주세요."**
> — 해외연수계획서 「2. 연수계획」 안내문

이 한 줄이 이번 심사의 전부입니다. 요구는 **두 축의 곱**입니다.

```
시장경제·자유의 가치를 경험  ×  본인의 진로 포부와 연계
        (자유기업원의 정체성)        (당신이어야 하는 이유)

둘 중 하나만 있으면 탈락 구간
  - 가치만 있고 진로가 없다  →  누가 가도 되는 계획서
  - 진로만 있고 가치가 없다  →  그냥 해외 견학
```

### 샘플 계획서가 알려주는 것

샘플(뉴욕 5일)의 방문지는 **뉴욕증권거래소 · 연방준비은행 · 페더럴 홀 · 엘리스 아일랜드 · 하이라인 파크 · 첼시마켓**입니다.
관광지가 아니라 **제도와 시장이 작동하는 현장**을 고른 구성입니다.

| 샘플이 정한 암묵 규칙 | 해석 |
| --- | --- |
| 5일 구성 | **길 필요 없습니다.** 밀도가 기간보다 중요 |
| 장소마다 "내용" 한 줄 | 관람이 아니라 **무엇을 볼 것인지**를 씀 |
| 민간·개방·기회를 반복 | 자유기업원 코드를 계획서 언어로 번역해둔 것 |
| 500만원은 "기준", 가감 가능 | 정확도가 성실성 신호. 부풀릴 이유 없음 |

## 3. 지원자 페르소나 — 확정안

### 한 줄 정의

> # 캠퍼스가 없어서 세계를 강의실로 쓰는 농학도
> ## — 다녀오는 사람이 아니라, 남기는 사람

### 세 개의 기둥

| 기둥 | 내용 | 어디서 나왔나 |
| --- | --- | --- |
| **① 캠퍼스가 없다** | 방통대 3학년. 통학도 강의실도 없다. 배움의 장소를 **스스로 정해야 하는 학생** | 실제 조건 |
| **② 판정할 자격이 있다** | 농학 전공자는 농업 현장을 보고 **맞다/아니다를 말할 수 있다** | 실제 전공 |
| **③ 기록해서 남긴다** | 숏폼 기획·촬영·편집을 혼자 돌리는 사람. 네이버 AI 디깅클럽 공식 활동 이력 | 실제 실적 |

### 왜 이 조합이 강한가 — 당신의 펭귄 이론을 그대로 적용

| 지원자 유형 | 판정 |
| --- | --- |
| 4년제 재학생 + 어학연수·문화체험·봉사 계획 | 🔴 **포화** — 매년 반복되는 마지막 펭귄 구간 |
| 4년제 재학생 + 시장경제 테마(샘플 따라가기) | 🟡 현역 — 샘플이 뉴욕을 제시했으므로 뉴욕·런던이 몰릴 것 |
| **캠퍼스 없는 학생이 스스로 커리큘럼을 짜서 나가는 연수** | 🟢 **빈 자리** |
| **농학 전공자가 시장 제도를 농업 현장에서 검증** | 🟢 **빈 자리** |
| **다녀와서 영상으로 남기는 것까지 설계된 계획** | 🟢 **빈 자리 + 사후 의무와 정확히 일치** |

> "캠퍼스가 없다"는 미션1에서 이미 검증한 후킹입니다. **연수계획서에서 훨씬 더 세게 먹힙니다.**
> 자율 해외 연수 = **스스로 커리큘럼을 짜는 프로그램**이고, 방통대생은 그걸 이미 4년째 하고 있는 사람이기 때문입니다.
> 즉 프로그램의 이름 자체(**자율**)와 지원자의 조건이 포개집니다. 이건 다른 지원자가 흉내 낼 수 없습니다.

### 페르소나의 목소리 — 문장 톤 기준

| 쓴다 | 안 쓴다 |
| --- | --- |
| "저는 강의실이 없어서 배울 곳을 직접 골라왔습니다" | "귀 재단의 훌륭한 프로그램에 지원하게 되어" |
| "농학과 3학년이 보기엔 이 부분이 아쉬웠습니다" | "많은 것을 배우고 성장하고 싶습니다" |
| "돌아와서 영상 N편으로 남기겠습니다" | "소중한 경험을 잊지 않겠습니다" |
| 숫자·장소·날짜가 박힌 문장 | 형용사로 채운 문장 |

> 미션1에서 세운 원칙 그대로입니다. **근거를 못 대는 주장은 하지 않습니다.**
> 자기소개서 500자에 형용사를 넣으면 검증 불가능한 말이 되고, 2차 발표(10분)에서 무너집니다.

## 4. 페르소나에서 도출되는 연수 테마 — 3안

공통 구조는 미션1과 동일합니다. **가서 본다 → 전공으로 판정한다 → 남긴다.**

### A안 — 네덜란드: 가격은 누가 정하는가 ⭐ 추천

**테마(가안):** `시장이 농업을 어떻게 키웠는가 — 네덜란드 농업의 가격발견 현장`

| 축 | 내용 |
| --- | --- |
| 시장경제·자유 | **알스미어 화훼경매(Royal FloraHolland)** — 세계 최대 화훼 경매시장이자 **하락식(더치) 경매**의 원형. 가격이 정부가 아니라 **거래로 발견되는 과정**을 눈으로 봄 |
| | **웨스트란트 유리온실 단지** — 민간 주도 집적이 만든 생산성 |
| | **바헤닝언 대학·푸드밸리** — 대학·기업·농가가 붙어 있는 혁신 클러스터 |
| 진로 연계 | 농학 전공자가 **한국 농업의 유통·규제 구조와 대비**해 판정 |
| 왜 강한가 | 국토가 한국의 절반 이하인 나라가 **농식품 수출 세계 2위**. "왜?"에 시장으로 답하는 구조가 이미 서 있음 |
| 리스크 | 경매장·온실·대학 **방문 가능 여부와 예약 조건을 직접 확인해야 함** (사전 확인 필수) |

> 🟢 **이 안의 결정적 강점:** 자유기업원이 원하는 "시장경제"와 당신의 "농학"이 **한 장소에서 겹칩니다.**
> 뉴욕증권거래소가 주식의 가격발견 현장이라면, 알스미어는 **농산물의 가격발견 현장**입니다.
> 샘플과 같은 논리 구조를 쓰면서 장소는 아무도 안 쓰는 자리 — 정확히 두 번째 펭귄입니다.

### B안 — 일본: 농협 밖의 농가

**테마(가안):** `농가가 직접 값을 매길 때 — 일본 직매장과 6차산업`

| 축 | 내용 |
| --- | --- |
| 시장경제·자유 | 도로역(道の駅)·직매장 — **농가가 스스로 가격을 붙이는 유통**, 공동판매 구조와의 대비 |
| 진로 연계 | 소규모 농가의 생존 전략. 한국 로컬푸드 직매장과 비교 |
| 강점 | **비용·언어·이동 부담이 가장 낮음.** 계획의 실현 가능성이 높게 읽힘 |
| 약점 | 가까운 만큼 **"연수"로서의 무게가 약해 보일 수 있음.** 지원자도 몰릴 가능성 |

### C안 — 싱가포르: 땅 없이 먹는 나라

**테마(가안):** `식량자급 1%의 도시가 먹는 법 — 도시농업과 민간 수직농장`

| 축 | 내용 |
| --- | --- |
| 시장경제·자유 | 개방 무역으로 식량을 조달해온 도시국가 + 민간 수직농장 스타트업 |
| 진로 연계 | 농학 + 도시농업, 기술농업 |
| 강점 | 이동 짧고 안전, 영어권, 일정 밀도 높음 |
| 약점 | **국가 주도('30 by 30' 정책) 색채가 강해** 자유기업원 코드와 미묘하게 어긋날 수 있음. 각도를 "민간 기업"으로 확실히 틀어야 함 |

### 비교표

| | 시장경제 부합 | 농학 진로 연계 | 차별성 | 500만원 실현성 | 영상 소재 |
| --- | --- | --- | --- | --- | --- |
| **A 네덜란드** | ◎ | ◎ | ◎ | ○ | ◎ |
| **B 일본** | ○ | ◎ | △ | ◎ | ○ |
| **C 싱가포르** | △ | ○ | ○ | ○ | ◎ |

### 결정 규칙

```
"시장경제 × 진로"를 한 장소에서 동시에 보여줄 수 있는가?
├─ A안 네덜란드  →  경매장 하나로 두 축이 동시에 성립       ⭐ 1순위
├─ B안 일본      →  안전하지만 '연수'의 무게가 가벼움        예비안
```
