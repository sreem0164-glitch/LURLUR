## 2. 양식이 적어둔 심사 기준

> **"일정은 시장경제 자유의 가치를 경험하고, 본인의 진로 포부와 연계되도록 구성해주세요."**
> — 해외연수계획서 「2. 연수계획」 안내문

**두 축의 곱**입니다.

```
시장경제·자유의 가치를 경험  ×  본인의 진로 포부와 연계
        (자유기업원의 정체성)        (당신이어야 하는 이유)
```

### 🟢 그런데 당신의 진로는 이 두 축이 원래 하나입니다

**종자산업은 재산권 위에 서 있는 산업입니다.**

```
품종보호권(육종가 권리)이 인정된다
        ↓
민간이 10년짜리 육종 투자를 회수할 수 있다
        ↓
종자기업이 R&D에 자본을 넣는다
        ↓
품종이 쏟아지고 산업이 큰다
```

씨앗은 **복제가 너무 쉬워서**, 소유권을 법으로 만들어주지 않으면 아무도 개발하지 않는 물건입니다.
**"재산권이 없으면 혁신도 없다"** — 자유기업원이 가장 좋아하는 명제를,
당신은 **농학 전공자로서 현장에서 검증하러 가는 것**입니다.

> 억지로 갖다 붙이는 게 아닙니다. **종자 = 지식재산권**은 농업정책의 실제 핵심 쟁점입니다.
> 다른 지원자는 "시장경제"를 테마에 맞추려고 노력해야 하지만, 당신은 **전공을 그냥 말하면 됩니다.**

| 500만원은 "기준", 가감 가능 | 정확도가 성실성 신호. 부풀릴 이유 없음 |

## 3. 지원자 페르소나 — 확정안 v2

### 한 줄 정의

> # 음식의 끝에서 시작으로 거슬러 올라온 사람이,
> # 씨앗에 주인이 생기면 무슨 일이 벌어지는지 확인하러 간다

### 이력을 관통하는 한 줄

```
접시 위          →      시장            →      밭과 씨앗
(요리 3년)              (학점은행제 경영학)          (방통대 농학과)

재료를 다루던 사람이 → 그게 팔리는 구조를 배우고 → 재료가 만들어지는 자리로
```

**이건 지어낼 수 없는 서사입니다.** 그리고 종자 테마와 정확히 붙습니다.

### 네 개의 기둥

| 기둥 | 내용 | 왜 강한가 |
| --- | --- | --- |
| **① 캠퍼스가 없다** | 방통대. 배울 곳을 늘 스스로 정해옴 | 프로그램 이름이 **자율** 연수 — 조건이 포개짐 |
| **② 없는 시간을 만들어 왔다** | 나이키 재직 중 + **학위 두 개를 동시에** (학점은행제 경영학 / 방통대 농학) | "시간이 남아서"가 아님. 형용사 없이 증명됨 |
| **③ 농학 + 경영학을 둘 다 한다** | 산업과 작물을 같이 볼 수 있음 | 농학만 하면 산업을 못 보고, 경영만 하면 작물을 모름 |
| **④ 혼자 만들어 남긴 적이 있다** | 숏폼 1인 기획·촬영·편집 완주 | **사후보고서 의무 이행 능력의 근거** |

> ③이 이번 지원의 숨은 무기입니다. 자유기업원이 원하는 건 "제도가 산업을 만든다"는 이야기인데,
> **경영학을 배운 농학도**가 그걸 말하면 다른 지원자와 설득력이 다릅니다.

### 왜 이 조합이 비어 있는 자리인가

| 지원자 유형 | 판정 |
| --- | --- |
| 4년제 재학생 + 어학연수·문화체험·봉사 | 🔴 포화 — 매년 반복되는 마지막 펭귄 |
| 4년제 재학생 + 시장경제 테마로 뉴욕·런던 | 🟡 샘플이 뉴욕을 제시했으므로 여기 몰림 |
| **일하며 편입해 농학을 공부하는 학생** | 🟢 빈 자리 |
| **요리 → 경영 → 농학으로 옮겨온 사람의 종자 연수** | 🟢 **경쟁자 없음** |

## 4. 연수 테마 — 확정

> ## 씨앗에 주인이 생기면 — 네덜란드 종자산업과 재산권

### 왜 2027년 4~5월인가 — 계획서에 쓸 수 있는 근거

| 이유 | 내용 |
| --- | --- |
| **화훼경매 물량이 연중 최대** | 가격발견 과정을 가장 잘 볼 수 있는 시기 |
| **구근·튤립 산업이 한창** | 종자·육종 산업의 현장이 실제로 돌아가는 때 |
| **쾨켄호프 개장 기간** | 구근 산업이 만든 전시장. 이 시기에만 열림 |
| 낮이 길다 | 하루에 소화할 수 있는 일정이 늘어남 |

> 💡 **"왜 이 시기인가"에 답할 수 있는 것 자체가 심사에서 점수가 됩니다.**
> 대부분의 지원자는 방학이라서 그때 갑니다. 산업 일정에 맞춰 시기를 고른 계획서는 드뭅니다.

### 10일 일정 (초안)

| 일차 | 테마 | 장소 | 확인할 것 |
| --- | --- | --- | --- |
| 1 | 출국 | 인천 → 암스테르담 | |
| 2 | **시장의 기원** | 암스테르담 (구 증권거래소·무역 사료) | 주식회사와 거래소가 왜 여기서 처음 생겼나 |
| 3 | **가격은 누가 정하나** | 알스미어 화훼경매장 | 정부가 아니라 거래가 값을 만드는 과정 |
| 4 | **구근 산업의 쇼케이스** | 리세 쾨켄호프 | 육종의 결과물이 어떻게 상품이 되는가 |
| 5 | **씨앗의 주인** | 노르트홀란트 시드밸리 | 품종보호권 위에 민간 R&D가 어떻게 섰나 |
| 6 | *현장 기록 정리* | (여유일) | 앞선 나흘의 기록 정리·보완 관찰 |
| 7 | **지식의 집적** | 바헤닝언 대학·푸드밸리 | 대학·기업·농가가 붙어 있을 때 생기는 것 |
| 8 | **생산 현장** | 웨스트란트 유리온실 단지 | 좁은 땅에서 나온 생산성의 실체 |
| 9 | *정리* | (여유일) | 전체 기록 정리 |
| 10 | 귀국 | 암스테르담 → 인천 | |

> **6일차·9일차는 실제로 비는 날입니다.** 계획서에는 "현장 기록 정리 및 보완 관찰"로 적습니다.
> 거짓이 아니고, 그날 무엇을 하든 자유입니다. **다만 계획서에 "휴양"이라는 단어는 쓰지 않습니다.**
> 심사 기준이 "시장경제 × 진로"라고 양식에 박혀 있고, 놀러 가는 계획으로 읽히면 1차에서 끝납니다.
>
> 4일차 쾨켄호프가 이 문제의 해법입니다. **즐기면서 다녀도 테마에 정확히 들어맞는 장소**입니다.

### 한국과의 대비 — 계획서의 뼈대

```
한국       외환위기 이후 주요 종자기업이 해외로 → 이후 정부 주도 사업으로 회복 시도
네덜란드   품종보호권 위에서 민간 종자기업이 스스로 큼

확인할 것: 그 차이가 기술인가, 제도인가
```

### ⚠️ 함정 — 스발바르 국제종자저장고

종자 하면 가장 먼저 떠오르지만 **일반인 내부 출입 불가**입니다. 넣으면 "실현 가능성을 확인하지 않았다"는 신호가 됩니다.

### ⚠️ 방문 가능 여부는 먼저 확인

특히 **종자기업과 경매장**은 일반 방문 가부·예약 방법이 제각각입니다.
**확인 안 된 장소는 계획서에 쓰지 않습니다.** 안 되면 지역·대학·박물관으로 대체하면 됩니다.
