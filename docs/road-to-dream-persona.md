## 2. 양식이 적어둔 심사 기준

> **"일정은 시장경제 자유의 가치를 경험하고, 본인의 진로 포부와 연계되도록 구성해주세요."**
> — 해외연수계획서 「2. 연수계획」 안내문

**두 축의 곱**입니다.

```
시장경제·자유의 가치를 경험  ×  본인의 진로 포부와 연계
        (자유기업원의 정체성)        (당신이어야 하는 이유)
```

### 🟢 그런데 당신의 진로는 이 두 축이 원래 하나입니다

**종자산업은 재산권 위에 서 있는 산업입니다.**

```
품종보호권(육종가 권리)이 인정된다
        ↓
민간이 10년짜리 육종 투자를 회수할 수 있다
        ↓
종자기업이 R&D에 자본을 넣는다
        ↓
품종이 쏟아지고 산업이 큰다
```

씨앗은 **복제가 너무 쉬워서**, 소유권을 법으로 만들어주지 않으면 아무도 개발하지 않는 물건입니다.
**"재산권이 없으면 혁신도 없다"** — 자유기업원이 가장 좋아하는 명제를,
당신은 **농학 전공자로서 현장에서 검증하러 가는 것**입니다.

> 억지로 갖다 붙이는 게 아닙니다. **종자 = 지식재산권**은 농업정책의 실제 핵심 쟁점입니다.
> 다른 지원자는 "시장경제"를 테마에 맞추려고 노력해야 하지만, 당신은 **전공을 그냥 말하면 됩니다.**

## 3. 지원자 페르소나 — 확정안 v2

### 한 줄 정의

> # 음식의 끝에서 시작으로 거슬러 올라온 사람이,
> # 씨앗에 주인이 생기면 무슨 일이 벌어지는지 확인하러 간다

### 이력을 관통하는 한 줄

```
접시 위          →      시장            →      밭과 씨앗
(요리 3년)              (학점은행제 경영학)          (방통대 농학과)

재료를 다루던 사람이 → 그게 팔리는 구조를 배우고 → 재료가 만들어지는 자리로
```

**이건 지어낼 수 없는 서사입니다.** 그리고 종자 테마와 정확히 붙습니다.

### 네 개의 기둥

| 기둥 | 내용 | 왜 강한가 |
| --- | --- | --- |
| **① 캠퍼스가 없다** | 방통대. 배울 곳을 늘 스스로 정해옴 | 프로그램 이름이 **자율** 연수 — 조건이 포개짐 |
| **② 없는 시간을 만들어 왔다** | 나이키 재직 중 + **학위 두 개를 동시에** (학점은행제 경영학 / 방통대 농학) | "시간이 남아서"가 아님. 형용사 없이 증명됨 |
| **③ 농학 + 경영학을 둘 다 한다** | 산업과 작물을 같이 볼 수 있음 | 농학만 하면 산업을 못 보고, 경영만 하면 작물을 모름 |
| **④ 혼자 만들어 남긴 적이 있다** | 숏폼 1인 기획·촬영·편집 완주 | **사후보고서 의무 이행 능력의 근거** |

> ③이 이번 지원의 숨은 무기입니다. 자유기업원이 원하는 건 "제도가 산업을 만든다"는 이야기인데,
> **경영학을 배운 농학도**가 그걸 말하면 다른 지원자와 설득력이 다릅니다.

### 왜 이 조합이 비어 있는 자리인가

| 지원자 유형 | 판정 |
| --- | --- |
| 4년제 재학생 + 어학연수·문화체험·봉사 | 🔴 포화 — 매년 반복되는 마지막 펭귄 |
| 4년제 재학생 + 시장경제 테마로 뉴욕·런던 | 🟡 샘플이 뉴욕을 제시했으므로 여기 몰림 |
| **일하며 편입해 농학을 공부하는 학생** | 🟢 빈 자리 |
| **요리 → 경영 → 농학으로 옮겨온 사람의 종자 연수** | 🟢 **경쟁자 없음** |

### 네덜란드인 이유

| 축 | 근거 |

| **한국 연결** | 한국 파프리카 재배가 네덜란드 품종·기술 도입에서 출발 |
