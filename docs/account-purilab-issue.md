# 푸리랩이슈 — 계정 운영 기준

> 네이버 AI 디깅클럽 미션 콘텐츠를 업로드할 **인스타그램 계정 `푸리랩이슈`** 기준 문서입니다.
> 미션 규격은 [운영 가이드](./naver-ai-digging-club-guide.md), 업로드 직전 점검은 [릴스 도달률 가이드](./instagram-reels-reach-guide.md),
> 미션1 실행안은 [개인미션1 기획안](./mission1-plan.md)을 보세요.

---

## 1. 계정 정의

| 항목 | 내용 |
| --- | --- |
| **계정** | `푸리랩이슈` (인스타그램) |
| **콘텐츠 축** | ① **이슈·트렌드 큐레이션** ② **제품 리뷰·검증** ③ **해외/쿠팡 상품 재편집 릴스** |
| **운영자 노출** | **얼굴 노출 없음.** 손 컷 + 자막 중심, 목소리(내레이션)는 선택 |
| **수익 구조** | 쿠팡 파트너스 등 제휴 링크 |

### 노출 범위 — 무얼굴 운영

- 기본 화자는 **자막**입니다. 얼굴 정면 컷은 쓰지 않습니다.
- 등장하는 신체는 **손(제품을 집고, 놓고, 조작하는 손)** 까지.
- 내레이션은 넣어도 되고 무음+자막으로 가도 됩니다. 단, **한 콘텐츠 안에서는 통일**합니다.
- 얼굴이 빠진 자리를 채우는 건 **탑다운 구도 · 클로즈업 · 결과 컷(O/X)** 세 가지입니다.

> 릴스 체크리스트 6번은 썸네일에 **결과 · 인물 · 문제** 중 하나를 명확히 담으라고 합니다.
> 인물 축이 없는 계정이므로 **결과** 또는 **문제**로 고정합니다.

## 2. 미션 콘텐츠는 계정에 "별도 게시물"로 올린다

계정의 평소 포맷(해외·쿠팡 상품 **재편집** 릴스)과 미션 콘텐츠는 **제작 규칙이 다릅니다.**
둘을 섞지 않고, **미션 영상은 규정을 지킨 별도 게시물로 따로 발행**합니다.

| | 계정 평소 콘텐츠 | **미션 콘텐츠 (별도 게시물)** |
| --- | --- | --- |
| 소재 | 해외·쿠팡 상품 영상 재편집 | **전량 직접 촬영** |
| 캡션 | 자유 (제휴 고지 포함) | **전체 SNS 동일 캡션 + 필수 해시태그 3개 + 지정 하단 문구** |
| 링크 | 제휴 링크 | **제휴 링크 없음** |
| 업로드 시점 | 자유 | **운영사무국 확인 후에만** |
| 동시 발행 | 인스타 단독 | **네이버 클립 + 인스타 릴스 동시** |

### 미션 게시물에서 지켜야 할 것

- **재편집 소재 금지** — 타인이 촬영한 영상·사진을 가져다 쓰지 않습니다.
  운영 가이드 DO ④(타인 개인정보)와 저작권 양쪽에 걸립니다.
- **제휴 링크·제휴 고지 문구를 미션 게시물 캡션에 넣지 않습니다.**
  미션 캡션은 지정된 문구(`네이버 AI 디깅클럽 활동의 일환으로 제작한 콘텐츠입니다.`)로 광고 관계를 밝히는 구조입니다.
  여기에 쿠팡 제휴 고지가 겹치면 **어떤 광고인지 흐려지고**, 캡션 동일 조건도 깨집니다.
- **프로필 링크(bio)는 계정 자산이라 그대로 둡니다.** 미션 게시물 자체가 제휴로 읽히지 않으면 됩니다.
- 화면 녹화본에 **계정명·알림·DM 등 개인정보**가 찍히지 않았는지 확인합니다.

### ⚠️ 먼저 확인할 것 — 지원서에 적은 계정

운영 가이드 STEP 3은 **"지원 시 기재한 개인 인스타그램"** 에 업로드하도록 규정합니다.

- [ ] 지원할 때 기재한 계정이 **`푸리랩이슈`가 맞는지** 확인
- [ ] 다르다면 업로드 전에 **운영사무국에 계정 변경 가능 여부 문의**

> 이건 제작보다 먼저 처리해야 합니다. 업로드 채널이 어긋나면 링크 제출(STEP 3)과
> 인사이트 제출(STEP 4)이 통째로 막힙니다.

## 3. 계정 컨셉과 미션 각도의 접점

미션1의 요건은 "**전공·학년 등 나를 표현하는 키워드**"이고, 계정의 축은 "**급상승 아이템 검증**"입니다.
두 축이 겹치는 자리에 기획을 놓습니다.

```
계정 축   :  급상승 이슈·상품을 골라 → 직접 써보고 → 결론을 낸다
미션 요건 :  네이버 AI탭으로 발굴 + 나를 표현하는 키워드(전공·학년)
──────────────────────────────────────────────────────────
교집합    :  AI탭으로 개강 급상승템을 발굴 → 농학과 3학년의 눈으로 검증 → O/X
```

- **포맷은 계정 그대로입니다.** 손 컷 + 자막 + O/X 결론. 시청자에게 이질감이 없습니다.
- **바뀌는 건 소재 조달 방식뿐입니다.** 재편집 → 직접 촬영.
- **전공(농학과 3학년)은 얼굴을 대신하는 신뢰 장치**입니다.
  무얼굴 계정에서 "누가 검증했는가"를 세우는 유일한 수단이라 **자막으로 반드시 명시**합니다.

### 아이템 우선순위 — 계정 일관성이 먼저

인스타그램은 팔로워를 장기간 쌓는 플랫폼이라 **카테고리 일관성**이 스레드형 계정보다 중요합니다.
계정 톤에서 벗어난 소재는 미션은 통과해도 계정 지표를 깎습니다.

| 순위 | 아이템 방향 | 근거 |
| --- | --- | --- |
| **1순위** | **개강 시즌 급상승 생활템** (데스크·자취·정리템) | 계정 평소 소재와 동일. 지표 왜곡 최소 |
| **2순위** | **식물·재배 관련 생활템** (LED 식물등, 자동 급수기, 토양 수분계, 재배 키트) | 전공이 곧 전문성. **계정 톤과 붙기만 하면 최상** |
| 보류 | 계정에서 다뤄본 적 없는 카테고리 | 미션은 통과해도 팔로워 반응이 끊김 |

> 2순위가 1순위를 겸할 수 있으면 그게 최선입니다.
> "**책상 위에 두는 식물템**"은 데스크테리어(계정 톤)와 농학과(전공)를 동시에 만족시킵니다.

## 4. 계정 운영 원칙

### 4-1. 하나를 정해 3개월 반복한다

수익을 막는 건 정보 부족보다 **방향 전환의 반복**입니다. 성과가 없을 때 플랫폼부터 바꾸지 말고
**소재 · 구조 · 타깃 · 발행량**을 먼저 바꿉니다. 집중은 고집이 아니라 **실험 범위를 한곳에 모으는 것**입니다.

- 수익 모델 하나 / 주력 플랫폼 하나를 고정
- 최소 3개월 같은 문제를 반복해서 푼다
- 미션 4회(개인) 자체가 이미 **일관된 실험 구간**입니다 → 각도를 흩지 않습니다

### 4-2. 카테고리보다 타깃

상품군이 달라도 **같은 사람이 관심 가질 만하면** 묶을 수 있습니다.
"어떤 카테고리인가"보다 "**이걸 누가 보는가**"를 먼저 적습니다.

> 푸리랩이슈 타깃 예시: *자취·개강 시즌에 살림을 새로 세팅하는 20대 후반*
> → 데스크 셋업, 자취 정리템, 식물 관리템, 생활 가전이 한 사람 안에서 연결됩니다.

단, **인스타는 카테고리 일관성이 더 중요한 플랫폼**입니다. 타깃으로 묶되 시각적 톤은 좁게 유지합니다.

### 4-3. 바이럴은 운이 아니라 구조

터진 콘텐츠는 **단어가 아니라 순서**를 봅니다. 첫 문장이 상황을 열고, 중간이 갈등을 키우고,
마지막이 답하고 싶게 만드는 흐름 — 소재를 바꿔도 **심리 흐름은 그대로 재사용**할 수 있습니다.

구조를 읽는 순서:
1. 반응이 검증된 콘텐츠를 모은다 (조회수 최상위만이 아니라 **꾸준히 중간이 나오는 계정**도 본다)
2. 왜 터졌는지 **한 문장으로 설명**할 수 있게 분해한다
3. 다른 소재·타깃에 적용한다
4. 같은 양식이 과열되면 빠져나온다

> 하루 10개가 각 1천 조회면 하루 1만, 한 달 30만입니다. **초대형 하나만 기다릴 이유가 없습니다.**
> 댓글·좋아요는 조회수에, **저장·공유는 팔로우**에 유리합니다 → 미션 콘텐츠의 CTA는 **저장**으로 겁니다.

### 4-4. AI는 백지에서 쓰게 하지 않는다

반응이 검증된 사례를 **입력으로 주고** 구조를 분석시킨 뒤 다른 소재에 적용합니다.
프롬프트 자체가 자산이 아니라, **왜 터졌는지 설명할 수 있는 능력**이 자산입니다.

- AI 결과에서 **사실 오류와 과장을 걸러내는 것은 사람 몫**입니다
- 마지막에 **자신의 경험과 관찰**을 넣습니다. 같은 구조를 여럿이 쓰면 패턴이 드러납니다
- 도구가 사라져도 직접 다시 할 수 있게 **기록해 둡니다**

> ⚠️ 미션 콘텐츠에 AI 생성물을 쓸 때는 운영 가이드 **DO ③** — *AI탭으로 만든 산출물로 오해되지 않는 범위* — 를 지킵니다.

### 4-5. 광고 표기와 저작권 — 꼼수보다 공식 기준

- **남이 생략한다고 따라 생략하지 않습니다.** 더보기를 누르지 않아도 광고 관계를 알 수 있어야 합니다
- 가격·성분·효능을 사실처럼 쓸 때는 **근거를 확인**합니다
- **직접 촬영한 소재가 가장 안전합니다.** 도우인·틱톡·인스타에서 가져왔다고 원저작권이 사라지지 않습니다
- 다른 계정의 콘텐츠는 **구조와 아이디어만 학습**하고, 문장·사진·영상 자체는 복제하지 않습니다
- 플랫폼 정책과 법령은 바뀝니다 → 애매하면 **공식 가이드·운영사무국에 확인**

### 4-6. 자동화보다 재현 가능한 수동 운영

자동화의 목적은 판단을 없애는 게 아니라 **반복 작업을 줄이는 것**입니다.
소재 선택, 사실 검증, 카피 최종 편집, 광고 표기 확인은 사람이 남습니다.

- 한 계정에서 **수동으로 성과를 낸 적이 있는가**를 먼저 통과합니다
- 짧은 시간에 좋아요·댓글을 몰아 하는 활동은 **비정상 패턴**으로 읽힐 수 있습니다
- 제재 회피를 목적으로 환경을 위장하지 않습니다

## 5. 미션 게시물 발행 체크 (푸리랩이슈 기준)

**업로드 전**
- [ ] 지원서 기재 계정 = `푸리랩이슈` 확인 완료 (다르면 운영사무국 문의 완료)
- [ ] 운영사무국 최종 확인(STEP 3)을 받았는가 — **확인 전 업로드 금지**
- [ ] 영상에 **얼굴 노출이 없고** 손 컷 + 자막으로 통일되는가
- [ ] 영상 안에 **방통대 · 농학과 3학년**이 자막으로 드러나는가
- [ ] **전량 직접 촬영**인가 (재편집 소재 0)
- [ ] 캡션에 **제휴 링크·제휴 고지 문구가 없는가**
- [ ] 캡션에 필수 해시태그 3개 + 지정 하단 문구가 있는가
- [ ] [릴스 도달률 체크리스트 6가지](./instagram-reels-reach-guide.md#part-2-업로드-전-반드시-체크할-6가지) 통과
- [ ] 음악이 **인스타·네이버 클립 양쪽에서** 문제없는가

**업로드 직후**
- [ ] 네이버 클립 + 인스타 릴스 **동시 업로드**
- [ ] 콘텐츠 링크 제출 게시판에 링크 제출 (미러링분 포함)
- [ ] **업로드 직후 초기 지표를 기록** (1시간 / 24시간 시점)

**업로드 +10일**
- [ ] 네이버 클립 · 인스타 릴스 인사이트 제출
- [ ] **계정 평소 콘텐츠 대비** 도달·저장·프로필 방문 비교 기록
- [ ] 국내/해외 도달 비율 확인 (번역 기능을 켰다면)
