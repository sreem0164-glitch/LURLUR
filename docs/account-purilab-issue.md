# 푸리랩이슈 — 계정 운영 기준

> 인스타그램 계정 **`푸리랩이슈`** 운영 문서입니다.
> 축은 **이슈·트렌드 큐레이션 + 제품 검증 + 해외/쿠팡 상품 재편집 릴스**, 수익은 **쿠파스(쿠팡 파트너스)** 전환.
> 업로드 직전 점검은 [릴스 도달률 가이드](./instagram-reels-reach-guide.md), 기획 원칙은 [콘텐츠 밸런싱 전략](./content-balancing-strategy.md) 참고.

---

## 1. 계정 정의

| 항목 | 내용 |
| --- | --- |
| **계정** | `푸리랩이슈` (인스타그램) |
| **콘텐츠 축** | ① 이슈·트렌드 큐레이션 ② 제품 리뷰·검증 ③ 해외/쿠팡 상품 재편집 릴스 |
| **운영자 노출** | **얼굴 노출 없음.** 손 컷 + 자막 중심, 목소리(내레이션)는 선택 |
| **수익 구조** | 쿠파스(쿠팡 파트너스) 링크 전환 |
| **주력 포맷** | 세로 릴스 · 짧은 호흡 · 자막이 화자 |

### 무얼굴 운영 규칙

- 기본 화자는 **자막**입니다. 얼굴 정면 컷은 쓰지 않습니다.
- 등장하는 신체는 **손(제품을 집고, 놓고, 조작하는 손)** 까지.
- 내레이션은 넣어도 되고 무음+자막으로 가도 되지만, **한 콘텐츠 안에서는 통일**합니다.
- 얼굴이 빠진 자리를 채우는 건 **탑다운 구도 · 클로즈업 · 결과 컷(비포/애프터, O/X)** 세 가지입니다.
- 릴스 체크리스트 6번의 썸네일 축(**결과 · 인물 · 문제**)에서 인물은 못 쓰므로 **결과 또는 문제**로 고정합니다.

### 거울·화면 반사 체크

무얼굴 포맷의 최대 리스크는 **거울·유리·제품 표면·폰 화면 반사에 얼굴이 찍히는 것**입니다.
편집 마지막에 한 번 더 훑고, 화면 녹화본에는 **계정명·알림·DM**이 남지 않았는지 확인합니다.

## 2. 하나를 정해 3개월 반복한다

수익을 막는 건 정보 부족보다 **방향 전환의 반복**입니다.
플랫폼을 계속 갈아타면 어떤 방식도 **데이터가 쌓이기 전에 중단**됩니다.

**실행 기준**
1. 수익 모델 하나를 고른다 → **쿠파스 전환**
2. 주력 플랫폼 하나를 정한다 → **인스타그램 릴스**
3. 최소 **3개월** 같은 문제를 반복해서 푼다
4. 성과가 없을 때 **플랫폼을 바꾸기 전에** 소재·구조·타깃·발행량을 바꾼다

> 꾸준함은 같은 걸 반복하는 게 아니라 **목표를 유지하면서 가설을 바꾸는 일**입니다.
> 집중은 고집이 아니라 **실험 범위를 한곳에 모으는 전략**입니다.

---

## 3. 카테고리보다 타깃

상품군이 달라도 **같은 사람이 관심 가질 만하면** 묶입니다.
"어떤 카테고리인가"보다 **"이걸 누가 보는가"** 를 먼저 적습니다.

- 캠핑용품과 헬스용품은 다른 카테고리지만 **활동적인 30대 남성**으로 묶입니다
- "건강·다이어트에 관심 많은 28세 여성"을 잡으면 다이어트 식품·운동용품·뷰티·레시피가 한 줄에 꿰입니다

### ⚠️ 단, 인스타는 스레드형과 다릅니다

추천 피드로 단타가 뜨는 플랫폼과 달리 **인스타는 팔로워를 장기간 쌓는 구조**라
**카테고리 일관성이 더 중요합니다.** "동일 타깃, 다양한 상품군"을 그대로 옮기면 그리드가 흩어집니다.

> **운영 원칙:** 타깃으로 상품을 고르되, **시각적 톤과 그리드는 좁게 유지**합니다.
> 새 상품군을 넣고 싶으면 파일럿 기능으로 먼저 반응을 봅니다.

**푸리랩이슈 타깃 정의(초안 — 데이터 쌓이면 갱신)**

```
누가  :  생활템·이슈에 반응하는 20~30대. 가격보다 "이게 진짜 되나"에 반응
언제  :  스크롤하다 멈추는 저녁 시간대
무엇  :  해외에서 먼저 뜬 물건 / 국내에 막 들어온 물건 / 써보기 전엔 모를 물건
```

## 4. 바이럴은 운이 아니라 구조

터진 콘텐츠는 **단어가 아니라 순서**를 봅니다.
첫 장면이 상황을 열고, 중간이 갈등이나 궁금증을 키우고, 마지막이 반응하고 싶게 만드는 흐름 —
**소재를 바꿔도 심리 흐름은 그대로 재사용**할 수 있습니다.

**구조를 읽는 순서**
1. 반응이 검증된 콘텐츠를 모은다
2. **왜 터졌는지 한 문장으로** 설명할 수 있게 분해한다
3. 다른 소재·타깃에 적용한다
4. 같은 양식이 과열되면 **먼저 빠져나온다**

> 조회수 최상위만 보지 말고 **꾸준히 중간(1천~3천)이 나오는 계정**도 봅니다.
> 하루 10개가 각 1천이면 하루 1만, 한 달 30만입니다. **초대형 하나만 기다릴 이유가 없습니다.**

### 반응 지표를 목적에 맞게 읽는다

| 지표 | 무엇에 유리한가 |
| --- | --- |
| 댓글 · 좋아요 | **조회수**를 밀어준다 |
| **저장 · 공유** | **팔로우**로 이어진다 |

→ 상품 검증형 콘텐츠의 CTA는 **저장**으로 겁니다. "저장해두세요"가 아니라
**"살 때 헷갈리니까 저장해두세요"** 처럼 **저장할 이유**까지 붙입니다.

### 재편집 릴스에서 쓰기 좋은 후킹 골격

| 골격 | 문장 형태 | 붙는 소재 |
| --- | --- | --- |
| **황당함** | "이걸 진짜 돈 주고 산다고? 주작인 줄 알고 찾아봤는데 품절이더라" | 기발한 굿즈, 특이 상품 |
| **신제품 충격** | "이 혼종을 출시했다고? 찌라시인 줄 알고 앱 켜봤는데 진짜 팔더라" | 괴식·신제품 |
| **스펙 반전** | "가성비인 줄만 알았는데 성분표 보고 놀랐다" | 식품·생활용품 |
| **검증형** | "○○ 진짜 되나 사서 써봤다 → 결론 O/X" | 계정 대표 포맷 |

> 마지막 검증형이 계정의 축입니다. 앞의 세 개는 **재편집 소재에 붙이는 후킹**으로 씁니다.
> 단, **없는 사실을 만들지 않습니다.** 품절·가격·성분은 확인하고 씁니다.

## 5. 광고 표기와 저작권

### 5-1. 광고 표기 — 꼼수보다 공식 기준

- **남이 생략한다고 따라 생략하지 않습니다.** 기준은 하나입니다:
  **더보기를 누르지 않아도** 이용자가 광고 관계를 알 수 있는가
- `[광고]` 표기만으로 쿠팡 파트너스 고지 문구를 대체할 수 있는지 같은 건
  **추측하지 말고 공식 매뉴얼·문의로 크로스체크**합니다
- 광고 표기는 계정 생존의 문제가 아니라 **소비자에게 이해관계를 투명하게 알리는 기본**입니다
- 법령과 플랫폼 정책은 바뀝니다. 예전에 정리해둔 기준도 **주기적으로 재확인**합니다

### 5-2. 저작권 — 재편집 계정의 실제 리스크

해외 영상을 가져와 재편집하는 포맷에서 가장 큰 리스크입니다.
**도우인·틱톡·인스타에서 가져왔다고 원저작권이 사라지지 않습니다.** 재가공 여부와 무관합니다.

**리스크를 줄이는 순서**

| 순위 | 소재 | 비고 |
| --- | --- | --- |
| **1** | **직접 촬영** | 가장 안전. 물건을 사서 찍은 컷 |
| **2** | 판매자·브랜드가 **사용을 허락한 소재** | 근거를 기록해 둘 것 |
| 3 | 출처 표기 후 인용 | 표기만으로 권리 문제가 사라지지 않음 |
| ⚠️ | 무단 재편집 | 신고·삭제·계정 제재 가능성을 안고 가는 것 |

- 다른 계정의 콘텐츠는 **구조와 아이디어만 학습**하고, 문장·사진·영상 자체는 복제하지 않습니다
- 워터마크가 남은 영상은 **저작권 이전에 도달에서 불이익**을 받습니다
- 플랫폼마다 **재사용 콘텐츠 정책**이 다릅니다. 같은 파일을 여러 곳에 그대로 올리는 건 위험합니다
- 가격·성분·효능을 사실처럼 쓸 때는 **근거를 확인**합니다

> **점진적 전환 권장:** 재편집 100%에서 시작하더라도, 반응이 확인된 상품은
> **직접 촬영 컷을 섞어** 가는 편이 장기적으로 안전하고 검증형 포맷과도 맞습니다.

## 6. 조회수를 클릭과 매출로 바꾸는 설계

**링크는 모든 게시물에 다는 게 아니라, 반응이 생긴 흐름에 연결합니다.**

- 피드를 링크로 도배하지 말고 **터진 게시물에 링크를 세팅**합니다
- 초반에는 **반응을 만드는 콘텐츠로 타깃을 모으고**, 그 관심이 이어지는 상품을 붙입니다
- 어그로를 쓰더라도 **확인하고 싶게 만드는 구체적 상황**으로 씁니다
  (예: "수량 많은 쪽이 더 싸다") — **없는 가격·혜택을 지어내지 않습니다**
- 터진 게시물의 **댓글을 읽고** 다음 콘텐츠와 다음 상품을 정합니다
- **조회수가 아니라 클릭과 판매가 어디서 났는지**를 봅니다

### 하루 운영안 (10분 루틴)

```
아침 10분 :  반응용 콘텐츠 1개 + 상품 콘텐츠 2~3개 예약
낮        :  전날 터진 게시물 댓글 확인 → 후속 소재 확정
저녁      :  클릭·전환 데이터 확인 → 다음날 상품 선정
```

- 상품은 같은 카테고리일 필요는 없지만 **같은 타깃이 관심 가질 만해야** 합니다
- 큰 계정에서 클릭률이 높았던 아이템을 **작은 계정에 적용해 보는 것**도 유효한 실험입니다

## 7. AI는 백지에서 쓰게 하지 않는다

**반응이 검증된 사례를 입력으로 주고** 구조를 분석시킨 뒤 다른 소재에 적용합니다.

```
터진 콘텐츠 찾기 → 캡처 → AI에 구조 분석 요청 → 다른 소재·타깃으로 재생성
→ 사실관계·어투 직접 수정 → 업로드 → 반응 데이터 확인
```

- **프롬프트 자체는 자산이 아닙니다.** "왜 터졌는지 한 문장으로 설명할 수 있는 능력"이 자산입니다
- AI 결과에서 **사실 오류와 과장을 걸러내는 건 사람 몫**입니다
- 마지막에 **자신의 관찰과 경험**을 넣습니다. 같은 구조를 여럿이 쓰면 패턴이 드러납니다
- 분석해둔 구조는 노션 등에 **모아서 다시 참고 자료로** 씁니다
- **도구가 사라져도 직접 다시 할 수 있게 기록**해 둡니다

**프롬프트 다음 단계 체크**
- [ ] 왜 터졌는가를 한 문장으로 설명할 수 있는가
- [ ] 다른 제품 10개에 적용할 수 있는가
- [ ] AI 결과에서 사실 오류와 과장을 걸러냈는가
- [ ] 같은 양식이 과열됐을 때 이동할 다음 구조가 있는가

## 8. 자동화 — 반복만 줄이고 판단은 남긴다

자동화의 목적은 **판단을 없애는 게 아니라 반복 작업을 줄이는 것**입니다.
소재 선택, 사실 검증, 카피 최종 편집, **광고 표기 확인**은 사람이 남습니다.

**자동화 전 확인**
- [ ] 한 계정에서 **수동으로 성과를 낸 적**이 있는가
- [ ] 무엇을 자동화할지 **작업 단계가 문서화**돼 있는가
- [ ] 실패·중복·과도한 발행을 막는 **제한**이 있는가
- [ ] 광고 표기와 사실 검증을 **사람이 확인**하는가
- [ ] 도구가 멈춰도 **수동으로 이어갈 수 있는가**

**계정 안전**
- 짧은 시간에 좋아요·댓글·리포스트를 몰아서 하면 **비정상 패턴**으로 읽힐 수 있습니다
- 무한 발행과 기계적 품앗이는 단기 노출을 만들어도 계정을 망가뜨립니다
- **제재 회피를 목적으로 환경을 위장하지 않습니다**
- 계정을 늘리기 전에 **한 계정에서 재현 가능한 운영법**부터 만듭니다

## 9. 수익 관리

- 수익이 생기면 건보료·종합소득세가 따라옵니다. **매달 예상 세금을 따로 빼두는** 방식으로 현금흐름을 관리합니다
- 청년창업 세액감면 같은 제도는 **해마다 조건이 바뀌므로** 현재 기준을 확인합니다
- 수익을 부풀려 보여주는 것보다 **실제 클릭·판매·정산을 기록**하고 다음 실험에 연결합니다

> AI와 자동화는 수익을 만드는 마법이 아니라 **시행 횟수와 학습 속도를 높이는 도구**입니다.

## 발행 전 체크 (푸리랩이슈)

**콘텐츠**
- [ ] 후킹이 **3초 안에** 뜨는가
- [ ] 자막만으로 내용이 전달되는가 (무음 시청 기준)
- [ ] 핵심 메시지가 **1개**로 정리되는가
- [ ] **얼굴이 어디에도 찍히지 않았는가** (거울·유리·제품 표면·화면 반사 포함)
- [ ] 워터마크·타 플랫폼 로고가 남아 있지 않은가
- [ ] 화면 녹화본에 계정명·알림·타인 개인정보가 없는가
- [ ] 가격·성분·품절 등 **사실로 쓴 내용의 근거**를 확인했는가

**전환**
- [ ] CTA가 **저장** + 저장할 이유까지 들어갔는가
- [ ] 링크를 붙일 만큼 **반응이 검증된 소재**인가
- [ ] **광고 표기가 더보기 없이 보이는 위치**에 있는가

**마무리**
