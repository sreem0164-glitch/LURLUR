## 1. 주제

**디깅 분야: 창업 · 상권 · 기업 마케팅 리서치**

```
일반인   :  공실 지나감
나       :  공실을 센다  →  "왜 안 될까"  →  파바는 왜 되지?  →  AI탭으로 리서치
```

훅에서 공실을 세는 행동 자체가 전문성 증거입니다.
동네 사는 사람은 공실 3곳을 연속으로 찍지 않습니다. 상권 보는 사람만 그럽니다.

질문 2개도 소비자 질문이 아니라 **출점 전략 질문**입니다.

```
[1]  요즘 파리바게뜨 24시 계속 생기는 거 알고 있었어요?   🟢
[2]  이 자리 원래 계속 비어있었거든요
[3]  여기도
[4]  여기도
[5]  근데 파리바게뜨가 들어와서 밤새 열어요

[6]  저 이런 거 보면 왜 망하나 궁금하더라고요
[7]  그래서 AI탭한테 물어봤어요
[8]  낮엔 직원 있고 밤엔 무인이래요
[9]  무인점포는 관리할 사람이 없어서 망하는 거였어요      🟢

[10] 근데 우리 동네 파바 또 있거든요
[11] 왜 역 앞에만 이렇게 했을까요?
[12] 사람 많은 데부터 바꾸는 중이래요

[13] 새로 가게 낸 게 아니라
[14] 원래 있던 가게를 밤에도 여는 거였어요              🟢

[15] 이런 거 파보는 AI 질문법 궁금하면
[16] 댓글에 정보 남겨줘!                              🟢
```

### 톤

**시청자에게 말 거는 질문으로 엽니다.** 1차는 혼잣말(`아니 이게 뭐야`)이었는데
2차는 정보 무게가 큰 미션이라 질문형이 더 맞습니다.

전체를 구어체 존댓말(`~거든요` `~더라고요` `~이래요`)로 통일했습니다.
CTA만 반말인데, 릴스에서 흔한 형태이고 1차와 문구가 같아 채널 톤이 이어집니다.

### 업계 용어를 쓰지 않습니다

| 쓰지 않음 | 대신 |
| --- | --- |
| 상권 | 왜 망하나 |
| 유동인구 | 사람 많은 데 |
| 되던 자리에 시간을 붙인다 | 원래 있던 가게를 밤에도 연다 |
| 재고 관리 | 관리할 사람 |

마케터끼리 쓰는 말이 하나라도 들어가면 일반 시청자가 멈춥니다.
[14]가 이 영상의 결론인데, 용어 없이 누구나 이해됩니다.

### 줄별 역할

| 줄 | 역할 |
| --- | --- |
| [1] | 훅 — 시청자에게 직접 질문 |
| [2]~[4] | 공실 3컷과 1:1. `여기도` 반복이 리듬 |
| [6] | 디깅 분야 — 용어 없이 |
| [9] | 무인점포가 망하는 진짜 이유 |
| [14] | **결론** — 새 가게가 아니라 영업시간 확장 |

> 음성은 1차와 동일하게 ElevenLabs Deok su, 같은 설정으로 통으로 뽑으면 됩니다.

## 3. AI탭 질문

```
질문 ①
창업 알아보는 중인데 무인점포는 다 망하고 파리바게뜨 하이브리드는 왜 달라?

질문 ②
동네에 파바 또 있는데 왜 역 앞 매장만 바꿨을까?
```

②는 ①의 답변에 나온 **"유동 인구 많은 도심 번화가 우선 확대"** 를 받아
"그럼 우리 동네는 왜?"로 좁힌 것입니다.

### 페르소나를 ①에만 넣는 이유

`창업 알아보는 중인데` 가 페르소나입니다. 이게 없으면 AI탭이 백과사전식으로 답합니다.
실제로 페르소나 없이 던졌을 때 일반 설명이 나왔습니다 [확인].
창업 관점을 넣으면 답변도 그 관점으로 좁혀지고, 영상 주제와 맞습니다.

②에는 붙이지 않습니다. 같은 대화 안에서 두 번 선언하면 작위적으로 읽히고,
실제 사람도 두 번째 질문에는 안 붙입니다. 가이드가 요구한 것은
질문마다 선언하는 게 아니라 **대화 전체에서 내 기준이 드러나는 것**입니다.
