## 1. 주제

**디깅 분야: 창업 · 상권 · 기업 마케팅 리서치**

```
일반인   :  공실 지나감
나       :  공실을 센다  →  "왜 안 될까"  →  파바는 왜 되지?  →  AI탭으로 리서치
```

훅에서 공실을 세는 행동 자체가 전문성 증거입니다.
동네 사는 사람은 공실 3곳을 연속으로 찍지 않습니다. 상권 보는 사람만 그럽니다.

질문 2개도 소비자 질문이 아니라 **출점 전략 질문**입니다.

## 2. 나레이션 (16줄 / 약 44초)

```
[1]  요즘 파리바게뜨 24시 계속 생기는 거 알고 있었어요?   🟢
[2]  이 동네 이렇게 빈 자리 많거든요
[3]  근데 파리바게뜨가 들어와서 밤새 열어요

[4]  저 이런 거 보면 왜 망하나 궁금하더라고요
[5]  그래서 AI탭한테 물어봤어요
[6]  낮엔 직원 있고 밤엔 무인이래요
[7]  실제로 문 앞에 이렇게 써있어요                ★
[8]  무인점포는 관리할 사람이 없어서 망하는 거였어요   🟢

[9]  근데 우리 동네 파바 또 있거든요
[10] 이렇게 가까운데 왜 또 생길까요?
[11] 출점 제한이 풀린 거였어요

[12] 무인 창업은 빈자리에서 사람 없이 시작하는데
[13] 파바는 잘 되던 가게를 밤까지 늘린 거예요      🟢
[14] 시작부터 다른 거죠                           🟢

[15] 이런 거 파보는 AI 질문법 궁금하면
[16] 댓글에 정보 남겨주세요!                      🟢
```

### 줄별 역할

| 줄 | 역할 |
| --- | --- |
| [1] | 훅 — 시청자에게 직접 질문 |
| [2] | 공실 컷. 여기서 깐 `빈 자리`가 [12]에서 회수됨 |
| [4] | 디깅 분야 선언 — 용어 없이 |
| [7] | **출입인증 단말기 확대** — AI 답변을 현장에서 확인하는 장면 |
| [12]~[14] | **결론** — 리스크 구조가 정반대라는 해석 |

### 결론의 구조

```
무인 창업 :  빈자리 + 사람 없음   →  둘 다 도박
파바      :  되는 자리 + 낮엔 직원 →  둘 다 안 함
```

[12]의 `빈자리`가 훅의 공실 컷을 회수합니다.
처음에 깔아둔 그림이 마지막에 의미를 얻는 구조입니다.

### 업계 용어를 쓰지 않습니다

| 쓰지 않음 | 대신 |
| --- | --- |
| 상권 | 왜 망하나 |
| 유동인구 | — (답변이 출점 규제로 나와 불필요해짐) |
| 시간을 붙인다 | 밤까지 늘린다 |
| 재고 관리 | 관리할 사람 |

### TTS 입력 시 주의 [확인]

- **줄 번호와 이모지를 전부 지우고** 붙여넣을 것. 안 그러면 음성으로 읽힘
- 빈 줄 4곳에 **Pause 태그** 삽입 → 구간 경계가 명확해져 편집 정확도가 올라감
  (1차 싱크 오류의 원인이 "어느 무음이 줄 바뀜인지 구분 불가"였음)
- **Speed 1 / Pitch 0 / Volume 1 기본값 유지.** 1차에서 속도 조정 후 자막 전면 재작업 발생
- Emotion·Voice Modifier 미사용 — 본인 목소리 클론이라 기본이 가장 자연스러움
- Volume은 편집 시 `loudnorm` 으로 -14 LUFS 정규화하므로 무관

## 3. AI탭 질문

```
질문 ①
창업 알아보는 중인데 무인점포는 다 망하고 파리바게뜨 하이브리드는 왜 달라?

질문 ②
동네에 파바 또 있는데 왜 역 앞 매장만 바꿨을까?
```

②는 ①의 답변에 나온 **"유동 인구 많은 도심 번화가 우선 확대"** 를 받아
"그럼 우리 동네는 왜?"로 좁힌 것입니다.

### 페르소나를 ①에만 넣는 이유

`창업 알아보는 중인데` 가 페르소나입니다. 이게 없으면 AI탭이 백과사전식으로 답합니다.
실제로 페르소나 없이 던졌을 때 일반 설명이 나왔습니다 [확인].
창업 관점을 넣으면 답변도 그 관점으로 좁혀지고, 영상 주제와 맞습니다.

②에는 붙이지 않습니다. 같은 대화 안에서 두 번 선언하면 작위적으로 읽히고,
실제 사람도 두 번째 질문에는 안 붙입니다. 가이드가 요구한 것은
질문마다 선언하는 게 아니라 **대화 전체에서 내 기준이 드러나는 것**입니다.

### 브랜드 노출 — 로고로만 처리

초안에는 **"네이버"라는 글자가 영상에 한 번도 나오지 않았습니다.**
화면 녹화에 N 로고와 `search.naver.com` 이 보이는 정도였습니다.

자막에 `네이버` 를 넣어봤으나 **음성과 어긋나 되돌렸습니다.**

| | 음성 | 시도했던 자막 |
| --- | --- | --- |
| [5] | AI탭한테 물어봤어요 | 네이버 AI탭한테 물어봤어요 |
| [15] | 이런 거 파보는 AI 질문법 **궁금하면** | 이런 거 파보는 **네이버 AI탭** 질문법 |

[5]는 한 단어 추가라 무해하지만 [15]는 `궁금하면` 이 사라지고
문장 구조가 바뀌어 소리를 켜면 티가 납니다. 둘 다 음성대로 되돌렸습니다.

**브랜드는 공식 로고 2개로 확보합니다.**

| 로고 | 위치 |
| --- | --- |
| 600px | [15] 매장 내부 컷 |
| 700px | [16] 아웃트로 |

> 재녹음하면 16줄 정렬을 다시 해야 합니다. 1차에서 이 때문에 세 번 재작업했습니다.
> 요건은 `AI탭 진입 + 사용 화면 노출` 이지 발화가 아니므로 로고로 충족됩니다 [확인].

### 우연히 맞아떨어진 것

AI 답변이 나레이션 내용을 그대로 표로 만들어줬습니다.

| 자막 | 화면에 뜬 것 |
| --- | --- |
| 낮엔 직원 있고 밤엔 무인이래요 | `주간: 직원 상주 운영 / 심야·새벽: 카드 인증 입장, 바코드 스캔` |
| 실제로 문 앞에 이렇게 써있어요 | 단말기 화면 `지금은 무인시간이 아닙니다` |
| 무인점포는 관리할 사람이 없어서 망하는 거였어요 | `일반 무인점포 실패 요인과 파리바게뜨의 차별점` 표 |

낮에 촬영한 것이 오히려 유리하게 작용했습니다.
무인 시간이 아닐 때만 단말기에 저 문구가 뜹니다.
