# 네이버 AI탭 질문 세트 — 제품 발굴용

> **[모름]** 작성자는 AI탭이 실제로 어떤 형태의 답을 주는지, 긴 질문을 잘 처리하는지,
> 트렌드·검색량 데이터를 제공하는지 확인한 적이 없습니다.
> 아래는 **자연어 질문 설계**일 뿐이며, 실제 동작은 직접 테스트해서 확인하세요.

---

## 0. 두 종류를 구분하세요

| | 화면용 | 조사용 |
| --- | --- | --- |
| 목적 | 영상에 찍힘 | 소재 찾기 |
| 길이 | **짧게 (한 줄)** | 길어도 됨 |
| 기준 | **0.5초에 읽힐 것** | 답의 질 |
| 노출 | 화면 녹화 | 안 찍힘 |

숏폼에서 질문 입력 화면은 **1~2초** 지나갑니다. 세 줄짜리 프롬프트는 아무도 못 읽습니다.
그래서 화면용은 **짧게 여러 번** 던져 좁혀가는 방식으로 갑니다.

---

## 1. 화면용 — 3단 퍼널

한 번에 자세히 묻지 말고 **세 번 나눠 묻습니다.** 각 질문은 짧고, 구체성은 누적됩니다.

```
1차  상황·문제        "자취방 거울 물때가 안 지워져"
2차  조건 좁히기      "다이소에서 살 수 있는 걸로"
3차  검증            "이거 단점은 뭐야?"
```

이 구조의 이점:
- 질문마다 짧아서 **화면에서 읽힘**
- 답이 좁혀지는 과정이 **그대로 콘텐츠**가 됨
- 영상 분량이 자연스럽게 채워짐

### 🔑 3차 질문이 차별점입니다

대부분은 추천만 받고 끝냅니다. **"단점은 뭐야?"를 묻는 화면**이 찍히면 그림이 달라집니다.

```
"이거 단점은 뭐야?"
"실패하는 경우도 있어?"
"안 맞는 사람은 누구야?"
```

- 영상 속 **단점 자막의 근거**가 됩니다 (디깅클럽 DO ① 대응 [확인])
- "추천만 받는 사람"이 아니라 "검증하는 사람"으로 보입니다

---

## 2. 화면용 질문 — 카테고리별

### 청소·정리

```
1차   자취방 거울 물때가 안 지워져
      화장실 청소 제일 귀찮은 거 뭘로 해결해?
      원룸 곰팡이 생기는 데 어떻게 해?

2차   다이소에서 살 수 있는 걸로
      5천원 안 넘는 걸로
      오늘 바로 살 수 있는 거

3차   이거 단점은 뭐야?
      실패하는 경우도 있어?
```

### 자취 살림

```
1차   자취 시작할 때 진짜 필요한 것만 알려줘
      원룸에서 공간 아끼는 방법
      혼자 사는데 이건 사지 말라는 거 있어?

2차   만원 이하로
      다이소에 있는 걸로

3차   이 중에 안 사도 되는 건 뭐야?
```

### 개강·공부 (디깅클럽 미션 맥락)

```
1차   집에서 공부할 때 책상 세팅 어떻게 해?
      집중 안 될 때 환경부터 바꾸려면 뭐부터?

2차   2만원 안으로
      다이소랑 이케아에서

3차   이거 효과 없다는 후기도 있어?
```

### 식물 (농학 전공 활용 시)

```
1차   형광등만 있는 방에서 키울 수 있는 식물
      물 자주 못 주는 사람이 키우기 쉬운 거

2차   다이소에서 파는 걸로

3차   초보가 이거 키우다 실패하는 이유가 뭐야?
```

> **3차 답변이 전공 지식과 어긋나면 그게 콘텐츠입니다.**
> "AI는 이렇게 말했는데, 농학과가 보기엔" — 이 대립이 영상의 결론이 됩니다.

## 3. 조사용 — 화면에 안 나가는 질문

길게 써도 되고, 답이 마음에 안 들면 다시 물어도 됩니다.

### 소재 찾기

```
자취생이 청소할 때 가장 많이 겪는 문제를 순서대로 알려줘

원룸 살면서 사람들이 돈 낭비했다고 후회하는 물건들

혼자 사는 사람들이 검색을 많이 하는 생활 문제가 뭐야
```

> **[모름]** AI탭이 "많이 검색하는" 같은 빈도 정보를 주는지 확인되지 않았습니다.
> 답이 안 나오면 그 방향은 포기하고 **문제 서술형**으로 바꾸세요.

### 각도 찾기

```
거울 청소에 대해 사람들이 잘못 알고 있는 것

○○ 제품 살 때 사람들이 놓치는 기준
```

### 검증

```
○○ 제품이 실제로 효과 없다는 의견도 있어?

○○ 쓸 때 주의할 점
```

## 4. ⚠️ 지키세요

| 원칙 | 이유 |
| --- | --- |
| **답이 나온 그대로 찍는다** | 질문과 답을 미리 정해놓고 재현하면 조작입니다 |
| **안 나온 말을 자막으로 쓰지 않는다** | 화면에 없는 걸 있다고 하면 들킵니다 |
| **원하는 답이 안 나오면 질문을 바꾼다** | 답을 바꾸지 말고 질문을 바꾸세요 |
| **화면 녹화 전 알림·계정명 확인** | 개인정보 노출 (DO ④) [확인] |

### 원하는 답이 안 나올 때

```
❌ 답이 이상해서 자막으로 다르게 씀
✅ 질문을 바꿔 다시 물어보고, 그 과정도 찍음
```

**엉뚱한 답이 나온 화면도 콘텐츠입니다.**
"처음엔 이상한 것도 알려줌 → 다시 물어보니 이게 나옴" 이 과정이 오히려 진짜처럼 보입니다.

## 5. 테스트 먼저

아래를 직접 확인하고 이 문서를 고치세요.

- [ ] 긴 질문(두 줄 이상)도 잘 받나?
- [ ] 후속 질문에서 앞 대화를 기억하나? (기억 못 하면 매 질문에 조건을 다시 넣어야 함)
- [ ] "다이소" 같은 **매장 조건**을 반영하나?
- [ ] "단점 알려줘"에 실제로 단점을 말하나?
- [ ] 가격 조건을 지키나?

> 위 항목의 답에 따라 3단 퍼널 구조를 조정해야 합니다.
> 특히 **대화를 기억하지 못하면** 2차·3차 질문에 조건을 매번 다시 써야 하고, 그러면 질문이 길어져 화면 가독성이 떨어집니다.
