# 릴스 연출안 — 세면대 물때 제거 (9컷 / 초보용)

> 제품: **다이소 2,000원** 양면 스펀지
>
> | 항목 | 상태 |
> | --- | --- |
> | 구매처·가격 | **[확인]** 다이소 2,000원 |
> | 양면 구성 | **[확인]** 얼룩 제거 / 유리 코팅 |
> | 김서림 방지 | **[확인] 안 됨** — 영상에서 다루지 않음 |
> | 얼룩 제거력 | **[모름]** — 촬영 전 테스트 필요 |
>
> **이번 편은 세면대 물때 제거만 다룹니다.** 코팅면·거울은 등장하지 않습니다.
>
> ⚠️ **거울은 언급하지 마세요.** 제품이 거울에도 된다고 해도, **보여주지 않은 것을 말하면 근거 없는 주장**입니다.
> 거울이 이미 깨끗해 Before를 못 찍으므로 이번 편에서는 세면대만 다룹니다.
> 목표 분량: **30~35초**

## 1. 이 구성의 전제

제거력 하나만 보여주므로 **실연 비트가 하나**입니다. 여기서 두 가지가 결정됩니다.

### 분량은 짧게

| | |
| --- | --- |
| ❌ 40~50초 | 보여줄 게 하나인데 길면 늘어집니다 |
| ✅ **30~35초** | 비트 하나에 맞는 길이 |

> 디깅클럽 미션용이면 **30초 이상**이 권장 기준이므로 [확인], 하한은 지켜야 합니다.
> 아래 구성은 30~35초가 나오도록 짰습니다.

### 비교 대상이 있어야 제거력이 보입니다

"지워진다"만 보여주면 밋밋합니다. **"안 지워지던 것"** 이 먼저 있어야 합니다.

```
휴지로 문질러봄  →  안 지워짐   ← 4번 컷
스펀지로 문지름  →  지워짐      ← 7번 컷
```

이 대비가 이번 영상의 구조 전부입니다. **4번 컷을 빼지 마세요.**

## 2. 촬영 전 테스트 (10분)

**제거력이 실제로 어느 정도인지 작성자는 모릅니다.** 찍기 전에 세면대 구석에서 확인하세요.

| 테스트 결과 | 대응 |
| --- | --- |
| 한 번에 확 지워짐 | 그대로 진행. 7번 컷을 짧게 |
| 여러 번 문질러야 지워짐 | 그대로 진행. 7번 컷을 **길게**, "몇 번 문질러야 됨" 자막 추가 |
| 거의 안 지워짐 | **촬영 중단.** 안 되는 걸 된다고 찍으면 안 됩니다 |

> 지워지는 정도를 확인한 뒤에 자막을 정합니다. 미리 정해두고 찍지 마세요.

## 4. ⚠️ 촬영 순서 — 되돌릴 수 없습니다

```
1단계  세면대 그대로 둔 채 →  2, 3번 컷 (물기만 제거)
2단계  휴지로 문지르기     →  4번 컷 (실패)
3단계  스펀지 소개         →  5, 6번 컷
4단계  테이프 붙이고 반만 닦기 → 7, 8번 컷
5단계  테이프 떼고 마무리  →  9번 컷
6단계  훅(1번)은 8번에서 잘라 씀 — 따로 안 찍음
```

> 🚨 **촬영 전에 세면대에 세제 쓰지 마세요.** 물기만 닦습니다. Before가 없으면 영상이 성립하지 않습니다.

## 6. 세팅 — 세면대 촬영

거울보다 쉽습니다. **반사 문제·사선 각도·어두운 옷이 전부 불필요**합니다.
대신 아래 네 가지가 새로 중요해집니다.

### ① 🔑 조명 — 이 영상의 최대 위험

**흰 도기 위의 흰 물때는 화면에서 사라집니다.**

| 조명 | 결과 |
| --- | --- |
| 욕실 천장등만 (정면광) | **물때가 안 보임** — 영상 실패 |
| **측면에서 비추기** | 물때·비누 자국이 입체로 드러남 ✅ |

- **다른 폰의 손전등**을 옆에서 비추는 게 가장 쉽습니다
- 스탠드가 있으면 세면대 옆에 놓고 낮게
- 천장등은 꺼도 됩니다

> **촬영 전 테스트:** 카메라 화면에 물때가 안 보이면 **그 상태로는 찍지 마세요.**
> 빛 위치를 바꿔가며 물때가 가장 잘 드러나는 각도를 먼저 찾으세요.

### ② 각도 — 탑다운 (위에서 내려찍기)

세면대 전체가 한 프레임에 들어오게 위에서 내려찍습니다.
**배수구가 화면 중앙**에 오면 구도가 잡힙니다.

폰 고정 방법 (삼각대 없을 때):
- 거울장·선반에 기대 놓기
- 벽과 물건 사이에 끼우기
- 위치를 **테이프로 표시**해 두기 (7·8번 컷이 같은 프레임이어야 함)

### ③ 마른 상태에서 Before 찍기

물기가 있으면 물때가 가려집니다. **수건으로 물기만 닦고** (세제 쓰지 말고) 찍으세요.
마스킹 테이프도 **마른 면에 붙여야** 붙습니다.

### ④ 세면대 위 물건

- 칫솔·치약·화장품은 **적당히만** 치우세요. 다 치우면 생활감이 사라집니다
- **배수구 주변이 가장 더럽습니다** — 3번 클로즈업 대상

### ⑤ 반 나누기

**좌우로 나누세요.** (볼 vs 상판은 경계가 애매합니다)
마른 상태에서 세면대 볼 중앙에 마스킹 테이프를 세로로 붙이고 왼쪽만 닦습니다.

## 7. 컷 리스트 (9컷)

> **찍는 시간**은 실제 촬영 시간입니다. 편집에서 잘라 쓰니 넉넉히.

| # | 편집 후 | 화면 | 카메라 | 찍는 시간 / 반복 | 자막 |
| --- | --- | --- | --- | --- | --- |
| **1** | 0~3s | **경계선 클로즈업** — 반은 더럽고 반은 깨끗 | 클로즈업 | *8번에서 추출* | **"왼쪽만 닦았는데"** |
| **2** | 3~7s | 물때 낀 **세면대 전체** | **탑다운**, 고정 | **10초 / 2번** | "자취방 세면대 이 상태였음" |
| **3** | 7~11s | **배수구 주변 클로즈업** — 물때·비누 자국 | 20~30cm까지 접근 | **10초 / 3번**<br>*빛 각도 바꿔가며* | "물때랑 비누 자국" |
| **4** | 11~16s | **휴지로 문질러봄 → 안 지워짐** | 클로즈업, 고정 | **15초 / 2번** | **"휴지로는 이게 안 지워짐"** |
| **5** | 16~20s | 스펀지 손에 들고 보여주기 | 손 클로즈업 | **12초 / 2번** | **"다이소 2천원짜리"** |
| **6** | 20~22s | 스펀지에 **물 묻히는** 컷 | 클로즈업 | **8초 / 2번** | "물만 묻히면 됨" |
| **7** | 22~29s | **테이프 왼쪽만** 닦기. 원을 그리며 천천히 | **고정 · 절대 안 움직임** | **30초 / 1번**<br>*끊지 말고 쭉* | "왼쪽만 닦아봄" |
| **8** | 29~32s | **경계선 클로즈업** | 클로즈업 | **12초 / 2번** | *(자막 없이 그림만)* |
| **9** | 32~35s | 테이프 떼고 **세면대 전체** 깨끗한 샷 | 고정 → 살짝 뒤로 | **20초 / 2번** | **"2천원으로 이게 됨"**<br>"다이소에 있음"<br>"저장해두고 써먹어" |

### 컷별 주의

- **1번** — 따로 안 찍습니다. 8번에서 잘라 앞에 붙이세요.
- **4번** — **이 영상의 절반입니다.** 휴지로 여러 번 세게 문지르는 게 화면에 보여야 합니다. 세면대 물때는 마른 휴지로 안 지워지는 게 자명해서 설득력이 큽니다.
- **5번** — 스펀지 **양면이 보여도 됩니다.** 코팅면을 설명만 안 하면 됩니다.
- **7번** — 끊지 말고 한 번에. **평소보다 느리게.** 세면대는 곡면이라 손이 화면을 가리기 쉬우니, 손을 **프레임 아래쪽에서** 움직이세요.
- **8번** — 자막 넣지 마세요. 한 번 비워야 리듬이 생깁니다.

## 12. 촬영 → 검수 워크플로

### 🚨 0단계를 건너뛰지 마세요

세면대를 닦는 순간 **Before는 돌아오지 않습니다.**
전부 찍고 나서 "각도가 틀렸다"를 발견하면 재촬영이 불가능합니다.

```
0단계  테스트 클립  ← 세제 안 쓴 상태로 3~5초만 찍어 보내기
       ↓  **물때가 화면에 보이는지**·구도·노출 확인
       ↓  OK 받고 진행
1단계  2·3번 촬영     → 보내기
2단계  4번 (휴지 실패) → 보내기
3단계  5·6번          → 보내기
4단계  7·8번 (반만 닦기) ← 되돌릴 수 없음. 직전에 한 번 더 확인
5단계  9번            → 보내기
6단계  전체 검수 → 편집 순서 + 자르는 지점 + 자막 확정
```

### 보낼 때 같이 적을 것

```
컷 번호 (예: 3번)
테이크 몇 번째인지
고민되는 점 (있으면)
```

> 여러 번 찍어서 고르기 어려우면 **다 보내세요.** 프레임으로 비교해 고르겠습니다.

### 매번 확인하는 항목

| 항목 | 기준 |
| --- | --- |
| 조명 | **물때가 실제로 보이는지** — 안 보이면 이 컷은 무효 |
| 구도 | 배수구가 중앙 부근인지, 세면대가 잘리지 않았는지 |
| 노출 | 밝기가 널뛰지 않는지 (AE/AF 잠금 여부) |
| 프레임 | 7·8번이 서로 같은 위치인지 |
| 수평 | 세면대 라인이 기울지 않았는지 |
| 안전영역 | 자막 들어갈 자리가 1,080×1,350 안인지 |
