## 0. 이번 미션의 전략적 위치

동기지원서에서 밝힌 3개월 목표 두 가지가 그대로 이번 미션의 성공 기준입니다.

| 지원서 목표 | 미션1에서 확보할 것 |
| --- | --- |
| ① 데이터 기반 아이템 선정 기준 확립 | 아래 **2. 아이템 선정 기준**을 이번 편에 실제 적용해 1차 검증 |
| ② 1인 제작 루틴 정착 | 기획→촬영→편집을 **일주일 안에 혼자 한 바퀴** 돌려보는 첫 사이클 |

### ⚠️ 기존 방식을 그대로 쓸 수 없는 지점

지원서에 쓰신 대로 지금까지는 **기존 영상 재편집** 방식이었지만, 이번 활동에서는 그 방식을 쓸 수 없습니다.

- 운영 가이드 DO ④ — **타인의 개인정보가 나오면 안 됨** (불가피하면 모자이크)
- 운영 가이드 DO ③ — AI 산출물을 쓰더라도 **AI탭으로 만들었다는 오해가 생기지 않는 범위**
- 남의 영상을 가져다 쓰면 저작권 문제까지 겹칩니다

**→ 이번 편은 전량 직접 촬영이 전제입니다.** 지원서에서 스스로 지목한 한계(직접 기획·촬영)를 정면으로 통과하는 게 미션1의 본질입니다.

## 1. 컨셉

### 개강 D-7, 지금 뜨는 자취템 — 진짜인지 내가 써봤다

**한 줄 정의:** 네이버 AI탭으로 *트렌드 초입*의 개강/자취 아이템을 찾아내고, 직접 사서 써보고, O/X로 결론 낸다.

**목적 (기획안 CHECK LIST ②):**
네이버 AI탭이 **"검색"이 아니라 "발굴" 도구**로 쓰일 수 있다는 걸 보여주는 것.
단순히 AI탭을 칭찬하는 게 아니라, **아직 뜨지 않은 걸 먼저 찾는 데 쓴다**는 구체적 매력 포인트를 제시합니다. (DO ①)

## 2. 아이템 선정 기준 — 펭귄 판별 룰

지원서 목표 ①("주관적인 감에 의존하지 않는 선정 기준")을 강의의 펭귄 이론과 결합한 실무 룰입니다.

| 신호 | 판정 | 조치 |
| --- | --- | --- |
| 검색량은 급상승 중인데 **리뷰·후기 수는 아직 적음** | 🟢 **두 번째 펭귄** | **채택** — 가장 유리한 자리 |
| 매거진·미디어 **기사로는 올라온 상태** | 🟡 현역 | 채택 가능, 단 각도를 비틀 것 |
| **기업 광고·브랜디드 콘텐츠**가 붙기 시작 | 🔴 **마지막 펭귄** | **제외** |
| 아직 아무 데이터도 없음 | ⚪ 첫 번째 펭귄 | 리스크 과다, 이번엔 보류 |

**아이템 유형은 두 갈래로 나눠 기록** (지원서에 쓰신 분류 그대로):

- **밈형** — 갑자기 뜨는, 화제성 중심 → 후킹은 강하나 수명이 짧음
- **실용형** — 실제로 쓸모 있는 것 → 정보 밀도가 높고 저장·공유가 잘 됨

> 이번 미션1은 **실용형 1개**를 권합니다. 개강 시즌 맥락과 붙고, 검증이라는 포맷이 실용형에서 훨씬 설득력 있게 작동합니다.

## 3. 분량 판단 — 아이템 몇 개를 담을 것인가

**결론: 이번 편은 아이템 1개 집중을 권합니다.** (30~45초)

| | 1개 집중 | 3개 비교 |
| --- | --- | --- |
| 1분 안 소화 | 여유 있음 | **빠듯함 — 개당 15초** |
| 검증 설득력 | 높음 (과정을 보여줄 수 있음) | 낮음 (나열에 그침) |
| AI탭 사용 화면 노출 | 충분히 확보 | 밀려서 잘림 |
| 첫 1인 촬영 난이도 | 감당 가능 | 컷 수 3배 |

3개 비교는 정보량이 후킹을 눌러버립니다([밸런싱 원칙](./content-balancing-strategy.md#1-후킹과-정보의-밸런싱)). 3개 포맷은 제작 루틴이 손에 붙은 **미션2 이후**로 미루세요.

## 4. 영상 구성

**규격:** 1,080 × 1,920px · 30초 이상 1분 이내 · **핵심 자막은 1,080 × 1,350 안전 영역 안에**

### #1 인트로 (0~6초) — 후킹

| 구분 | 내용 |
| --- | --- |
| **화면 연출** | 1) 책상 위에 아이템을 툭 내려놓는 **탑다운 컷** (손만 등장)<br>2) 아이템 클로즈업 인서트 0.5초<br>3) 카메라 정면, 아이템을 들어 보이는 컷 |
| **자막** | "개강 D-7, 지금 급상승 중인 자취템"<br>"근데 이거 진짜 사도 되나?" |

> **썸네일 = 이 첫 컷입니다.** 자막을 화면 위쪽에 몰지 말고 **중앙(안전 영역)** 에 배치해야 그리드 탭에서 안 잘립니다.
> 후킹은 여기서 끝냅니다. 이후는 정보 구간입니다.

### #2 발굴 과정 (6~20초) — **AI탭 필수 노출 구간**

| 구분 | 내용 |
| --- | --- |
| **화면 연출** | 1) **네이버 앱에서 AI탭으로 진입하는 화면** (진입점 — DO ② 필수)<br>2) 검색어 입력 → 결과 스크롤 **화면 녹화**<br>3) 급상승 근거가 보이는 화면 |
| **자막** | "그냥 검색 말고 네이버 AI탭"<br>"아직 후기 적은데 검색량만 튀는 것 = 지금이 초입" |

> 이 구간이 **미션의 핵심 요건**입니다. 결과만 보여주지 말고 **진입점 → 입력 → 결과** 순서로 과정을 보여줘야 합니다.
> 화면 녹화본은 세로 비율로 크롭해서 붙이고, 개인정보(계정명·알림 등)가 찍히지 않게 확인하세요. (DO ④)

### #3 검증 (20~40초) — 정보

| 구분 | 내용 |
| --- | --- |
| **화면 연출** | 1) 개봉 컷<br>2) 실제 사용 컷 (자취방 실사용 상황 그대로)<br>3) 문제점이 드러나는 컷 **— 여기가 신뢰의 핵심**<br>4) 사용 전/후 비교 컷 |
| **자막** | "3일 써봤다"<br>"좋은 점 — ○○"<br>"근데 △△는 별로" ← **단점을 반드시 넣을 것** |

> 장점만 나열하면 광고로 읽힙니다. **단점 1개를 명시**하는 게 검증 포맷의 신뢰를 만들고, DO ①의 "피상적 칭찬 금지"와도 맞습니다.

### #4 엔딩 (40~50초) — 전환

| 구분 | 내용 |
| --- | --- |
| **화면 연출** | 1) 아이템 위에 **O 또는 X 표시**를 얹는 컷<br>2) 정면 마무리 컷 |
| **자막** | "결론: 개강 전에 사도 됨 ⭕ / 아직은 아님 ❌"<br>"다음 편은 △△ 검증합니다"<br>"저장해두고 개강 준비할 때 보세요" |

| 질문 | 답 |
| --- | --- |

| **③ 내 썸네일은 클릭해 볼 만한가** | "지금 뜨는 자취템 / 진짜 사도 되나?" — 개강 시즌 + 판단 유보로 클릭 유인. 안전 영역 배치 필수 |

## 6. 촬영 세팅

강의 원칙: **본인 영상에 맞는 세팅을 찾아 고정할 것.** 이 포맷에 필요한 건 3가지뿐입니다.

| 컷 종류 | 세팅 |
| --- | --- |
| 탑다운 제품 컷 | 삼각대 또는 책 쌓아 고정 + 수직 내려찍기, **위치를 고정**해 재촬영 시 동일하게 |
| 실사용 컷 | 자취방 자연광, 낮 시간 고정 (색온도 일정하게 유지) |
| AI탭 화면 | 폰 **화면 녹화** — 별도 촬영 아님 |

> 블랙매직 앱은 강의에서 아이돌 콘텐츠 사례로 나온 것이고, 이 포맷에는 과합니다.
> **기본 카메라 + 고정된 세팅값**을 정해두는 편이 1인 루틴 정착(목표 ②)에 맞습니다.

## 7. 일주일 실행 계획

| 날짜 | 할 일 |
| --- | --- |
| **9/1 (화)** | AI탭으로 후보 아이템 3~5개 발굴 → 선정 룰 적용해 **1개 확정**, 주문 |
| **9/2 (수)** | 기획안 확정 (이 문서 기준으로 자막 문구 확정), AI탭 화면 녹화 |
| **9/3~9/4 (목·금)** | 아이템 수령 후 **실사용 시작** — 검증 컷은 실제로 써본 뒤에 |
| **9/5 (토)** | 촬영 (탑다운 → 개봉 → 사용 → 엔딩 순서로 한 번에) |
| **9/6 (일)** | 편집 · 자막 · 안전 영역 확인 |
| **9/7 (월)** | **맞춤법 검사 후 제출** |

> 아이템 배송이 이 일정의 유일한 외부 변수입니다. **9/1에 주문**해야 9/3~9/4 실사용이 가능합니다.

## 제출 전 체크

- [ ] 30초~1분, 1,080 × 1,920
- [ ] 핵심 자막이 1,080 × 1,350 안전 영역 안
- [ ] **AI탭 진입점 + 사용 화면**이 실제로 보임
- [ ] 단점을 하나 이상 명시 (피상적 칭찬 아님)
- [ ] AI 생성물을 썼다면 AI탭 산출물로 오해될 여지 없음
- [ ] 화면 녹화본에 타인 개인정보·계정 정보 없음
- [ ] `AI탭` / `AI 디깅클럽` 띄어쓰기 정확
- [ ] 맞춤법 검사 완료
- [ ] 운영사무국 확인 **후** 네이버 클립 + 인스타그램 릴스 동시 업로드
