## 0. 공식 미션 요건

### 미션 브리프 (원문 요지)

- 개개인별 **디깅 키워드와 캠퍼스, 전공, 학년 등 나를 표현할 수 있는 다양한 키워드**를 활용해 **나만의 AI탭 활용법**을 콘텐츠로 제작
- **'개강'이라는 시즌성**에 맞춰, AI탭을 활용해 **나의 디깅 키워드와 연결된 장소와 아이템**을 찾아볼 것
- 캠퍼스 주위 **장소를 직접 방문**하거나, **개강 필수템을 구매해 사용해보며** AI탭과 함께 발견한 나만의 일상을 자연스럽게 담을 것

**콘텐츠 앵글 예시 (공식)**

- ☑ 생산성 높여주는 영감 수집 카공 플레이스
- ☑ ○○대학교 캠퍼스 반경 1km 대학생활 즐기기
- ☑ 건축학과 3학년의 개강 what's in my bag
- ☑ 2학기 시작 필수 데스크테리어 tip

### 미션 필수 조건

| 항목 | 내용 |
| --- | --- |
| **AI탭 노출** | 영상 내 네이버 AI탭 **진입 + 사용 화면 필수 노출** |
| **필수 해시태그** | `#네이버` `#AI탭` `#네이버AI디깅클럽` |

> ⚠️ **해시태그는 붙여 씁니다 — `#네이버AI디깅클럽`.**
> 본문에서는 `네이버 AI 디깅클럽`으로 띄어 쓰지만, 해시태그는 공백을 쓸 수 없어 붙입니다. 둘을 헷갈리지 마세요.

## 1. ⚠️ 컨셉을 손봐야 하는 지점

**미션은 "나를 표현하는 키워드(캠퍼스·전공·학년)"를 요구합니다.**

공식 앵글 예시를 보세요. 전부 **개인 정체성이 앞에 붙어 있습니다.**
"**건축학과 3학년의** 개강 what's in my bag", "**○○대학교** 캠퍼스 반경 1km".

그런데 원래 컨셉인 "급상승 생활템 검증"은 **데이터가 주어이고 사람이 없습니다.**
누가 만들어도 같은 영상이 나올 수 있고, 그러면 미션 요건을 정면으로 충족하지 못합니다.

### 해결 — 데이터에 나를 얹습니다

```
급상승 생활템 검증   ←  기존 강점 (유지)
        +
내 전공 · 학년 · 자취 맥락  ←  미션 요건 (추가)
```

**제목 형태:** `[전공] [학년]이 개강 앞두고 산 급상승 자취템, 진짜일까`

이렇게 하면 세 가지가 동시에 해결됩니다.

| | 효과 |
| --- | --- |
| **미션 요건** | 전공·학년이 명시돼 "나를 표현하는 키워드" 충족 |
| **차별화** | 같은 아이템을 다뤄도 **내 상황에서의 검증**이라 대체 불가 |
| **후킹** | "○○학과가 왜 이걸?" 하는 구체성이 클릭을 만듦 |

> **본인의 전공·학년·자취 여부를 정해서 넣으세요.** 이 문서에서는 `[전공] [학년]`으로 비워 뒀습니다.
> 학생 신분이 아니라면 브리프의 "**등 나를 표현할 수 있는 다양한 키워드**"에 기대어
> 자취 연차·생활 패턴 같은 **다른 개인 축**으로 대체하고, 애매하면 운영사무국에 확인하세요.

## 2. 컨셉

### `[전공] [학년]`이 개강 앞두고 산 급상승 자취템 — 진짜인지 써봤다

**한 줄 정의:** 네이버 AI탭으로 *트렌드 초입*의 개강 아이템을 발굴하고, 내 자취방에서 직접 써보고, O/X로 결론 낸다.

**목적 (기획안 CHECK LIST ②):**
AI탭이 **"검색"이 아니라 "발굴" 도구**로 쓰일 수 있다는 걸 보여주는 것.
칭찬이 아니라 **아직 뜨지 않은 걸 먼저 찾는 데 쓴다**는 구체적 매력 포인트 제시. (DO ①)

### ⚠️ 기존 방식을 그대로 쓸 수 없는 지점

지금까지는 **기존 영상 재편집** 방식이었지만, 이번 활동에서는 쓸 수 없습니다.

- DO ④ — **타인의 개인정보 노출 금지** (불가피하면 모자이크)
- DO ③ — AI 산출물을 써도 **AI탭으로 만들었다는 오해가 생기지 않는 범위**
- 남의 영상 사용은 저작권 문제까지 겹침
- 업로드 시 **매체별 라이선스(음악 등) 확인 필수**

**→ 전량 직접 촬영이 전제입니다.** 스스로 지목한 한계(직접 기획·촬영)를 정면으로 통과하는 게 미션1의 본질입니다.

## 3. 아이템 선정 기준 — 펭귄 판별 룰

| 신호 | 판정 | 조치 |
| --- | --- | --- |
| 검색량 급상승 + **후기·리뷰 수는 아직 적음** | 🟢 **두 번째 펭귄** | **채택** |
| 매거진·미디어 **기사로는 올라온 상태** | 🟡 현역 | 채택 가능, 각도를 비틀 것 |
| **기업 광고·브랜디드 콘텐츠**가 붙기 시작 | 🔴 **마지막 펭귄** | **제외** |
| 아직 아무 데이터도 없음 | ⚪ 첫 번째 펭귄 | 리스크 과다, 보류 |

**유형 분류** — 밈형(화제성·수명 짧음) / 실용형(정보 밀도·저장률 높음).
→ 미션1은 **실용형 1개**를 권합니다.

### 조달 조건 — 당일 구매 가능한 것만

| 구매처 | 성격 |
| --- | --- |
| **다이소** | 자취템 밀도 최고. **신상 매대**를 볼 것 |
| **올리브영 / 편의점** | 회전이 빨라 트렌드 초입이 잡힘 |
| **마트 · 이케아** | 실용형 생활용품 |
| **네이버 쇼핑 도착보장** | 발굴~구매가 네이버 안에서 이어짐 |

### ⚠️ 당일 구매와 "트렌드 초입"의 긴장

당일 살 수 있다는 건 **이미 대량 유통 중**이라는 뜻이기도 합니다. 마지막 펭귄을 집을 수 있어요.

**해소 — 매대가 아니라 데이터로 판정하세요.**

- 다이소·올리브영에도 **입고된 지 얼마 안 된 신상 구간**이 있고, 거기가 2번 펭귄 자리입니다
- 판정은 그대로 **검색량 급상승 + 후기 수 적음**. 매장에 있다는 사실은 근거가 아닙니다
- **광고·협찬 콘텐츠가 이미 여러 개 붙었으면 매대에 있어도 제외**

## 5. 영상 구성

**규격:** 1,080 × 1,920px · 30~60초 · **핵심 자막은 1,080 × 1,350 안전 영역 안에**

### #1 인트로 (0~6초) — 후킹

| 구분 | 내용 |
| --- | --- |
| **화면 연출** | 1) 책상 위에 아이템을 툭 내려놓는 **탑다운 컷** (손만 등장)<br>2) 아이템 클로즈업 인서트 0.5초<br>3) 정면, 아이템을 들어 보이는 컷 |
| **자막** | "`[전공]` `[학년]`, 개강 D-7"<br>"지금 급상승 중인 자취템 — 근데 진짜 사도 되나?" |

> **대안 후킹:** 첫 컷을 **매장 매대 앞**으로 잡아도 좋습니다("다이소에서 이거 보자마자 샀다"). 실제 공간이 배경이면 연출 티가 덜 납니다.
>
> **이 첫 컷이 썸네일입니다.** 자막을 위로 몰지 말고 **중앙(안전 영역)** 에 배치해야 그리드 탭에서 안 잘립니다.
> 후킹은 여기서 끝. 이후는 정보 구간입니다.

### #2 발굴 과정 (6~20초) — **AI탭 필수 노출 구간**

| 구분 | 내용 |
| --- | --- |
| **화면 연출** | 1) **네이버 앱에서 AI탭으로 진입하는 화면** (진입점 — 필수)<br>2) 검색어 입력 → 결과 스크롤 **화면 녹화**<br>3) 급상승 근거가 보이는 화면 |
| **자막** | "그냥 검색 말고 네이버 AI탭"<br>"후기는 아직 적은데 검색량만 튀는 것 = 지금이 초입" |

> **미션의 핵심 요건.** 결과만 보여주면 안 되고 **진입점 → 입력 → 결과** 순서를 다 보여줘야 합니다.
> 화면 녹화본은 세로로 크롭하고, **개인정보(계정명·알림 등)가 찍히지 않았는지** 확인하세요. (DO ④)

### #3 검증 (20~40초) — 정보

| 구분 | 내용 |
| --- | --- |
| **화면 연출** | 1) **매장에서 실물 집는 컷** (3~4초) — 온라인 데이터가 오프라인으로 이어지는 연결고리<br>2) 개봉 컷<br>3) **내 자취방 실사용 컷** — 전공·학년 맥락이 드러나는 소품이 배경에 있으면 더 좋음<br>4) 문제점이 드러나는 컷 **— 신뢰의 핵심**<br>5) 사용 전/후 비교 |
| **자막** | "AI탭에서 찾고 바로 사러 감"<br>"좋은 점 — ○○"<br>"근데 △△는 별로" ← **단점을 반드시** |

> **사용 기간을 부풀리지 마세요.** 당일 구매면 "3일 써봤다"는 못 씁니다. "바로 써봤다" / "이틀 써본 결과"처럼 **실제 쓴 만큼만**.
> 장점만 나열하면 광고로 읽히고, DO ①의 "피상적 칭찬 금지"에도 걸립니다.

### #4 엔딩 (40~55초) — 전환

| 구분 | 내용 |
| --- | --- |
| **화면 연출** | 1) 아이템 위에 **O 또는 X**를 얹는 컷<br>2) 정면 마무리 |
| **자막** | "결론: 개강 전에 사도 됨 ⭕ / 아직은 아님 ❌"<br>"다음 편은 △△ 검증합니다"<br>"저장해두고 개강 준비할 때 보세요" |
