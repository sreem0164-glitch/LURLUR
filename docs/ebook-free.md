## 시작하기 전에

나는 편집 프로그램을 다룰 줄 모른다.
프리미어도 파이널컷도 안 배웠다. 배우다 포기한 게 아니라 아예 시작을 안 했다.

그 상태로 **AI에게 시켜서** 릴스를 만들었다.

그리고 나온 결과물을 보고 생각이 바뀌었다.
**AI가 여기까지 온 걸 보고 나니, 이제 편집도 천천히 배워볼 생각이다.**
못 배워서 AI를 쓴 게 아니다. **AI로 일단 만들고 나니 배울 이유가 생겼다.**

시작점이 낮아도 된다는 얘기를 하려는 거다. 내 시작점이 그랬다.

### 기록 [확인]

| | |
| --- | --- |
| 인스타그램 | **3개월, 팔로워 약 1,000명** |
| 쿠팡 파트너스 | **2개월 운영 — 가장 잘 나온 달 100만 원** |

**여기서 정확히 짚고 간다.**

- "가장 잘 나온 달 100만 원"이다. **월 100만 원이 아니다.** 2개월 중 한 달이 그랬다
- 나머지 달이 얼마인지는 이 자료에 쓰지 않는다. 자랑거리가 아니라서다

이렇게 쓰는 이유가 있다.
**숫자를 부풀리는 자료는 방법도 부풀린다.** 첫 장에서 숫자를 어떻게 다루는지 보면 나머지가 보인다.

## 이 자료가 하는 말과 안 하는 말

**안 하는 말**
- "너도 3개월에 1,000명 된다" — 모른다. 네 주제도 네 실행도 내가 모른다
- "이대로 하면 월 100만 원" — 나도 한 달만 그랬다
- "알고리즘 공략법" — 그런 건 내가 모른다 [모름]

**하는 말**
1. **인스타그램이 공식 문서에 밝힌 것** — 추측이 아니라 문서에 적힌 것
2. **내가 릴스 한 편을 19번 고친 기록** — 뭘 틀렸고 왜 고쳤는지, 틀린 것까지 그대로

시중 자료의 "3초에 50% 이탈", "유지율 60% 넘으면 도달 5~10배" 같은 수치는
**출처가 확인되지 않아 한 줄도 넣지 않았다** [모름].

## 그런데 왜 이걸 무료로 푸나

솔직하게 쓴다. **이 뒤에 유료판이 있다.**

다만 이 자료는 미끼로 쓸 생각이 없다. 아래 내용만으로 오늘 올릴 영상이 바뀐다.
바뀌지 않으면 유료판도 살 이유가 없다. **여기서 판단해라.**

## 1. 대부분은 "안 터지는" 게 아니라 **추천에서 빠진 것**이다

여기서부터 보는 게 순서다. 훅을 아무리 잘 짜도 **추천 대상에서 제외되면 훅을 볼 사람이 없다.**

인스타그램이 **공식적으로 밝힌 "추천하지 않는 릴스"** [확인]:

| 제외 사유 |
| --- |
| **워터마크가 박힌 영상** |
| 저해상도 |
| 음소거된 영상 |
| 테두리(레터박스)가 있는 영상 |
| 화면 대부분이 텍스트인 영상 |
| 정치적 사안 중심 |

> 출처: Instagram 공식 블로그 「Instagram Ranking Explained」 [확인]

### ⚠️ 워터마크 — 지울 수는 있다. 문제는 그 다음이다

"다른 데서 받은 영상은 워터마크 때문에 못 쓴다"고 알고 있다면 절반만 맞다.
**워터마크를 빼고 받는 도구는 있다.** 그건 해결된다.

**진짜 함정은 바로 옆 줄이다 — 저해상도.**

다운로드는 재인코딩이다. 받는 순간 원본보다 떨어진다.
워터마크만 신경 쓰고 화질을 놓치면 **같은 목록의 다른 줄에서 빠진다.**

### 화질을 지키는 3가지 — 순서대로 중요하다

**① 받을 때가 전부다**

업스케일로 **없는 화질이 생기지는 않는다.** 이건 분명히 하자.
한 번 뭉개진 픽셀은 키운다고 살아나지 않는다. 키우면 뭉갠 걸 크게 볼 뿐이다.

```
□ 다운로드 시 해상도 옵션을 확인한다 — 기본값이 최고 화질이 아닌 경우가 많다
□ 세로 영상은 1080×1920을 목표로 받는다
□ 같은 영상을 두 번 이상 받아 비교할 가치가 있다
```

**② 편집 중 재인코딩을 반복하지 마라**

영상은 저장할 때마다 다시 압축된다. **편집 → 저장 → 다시 열기 → 편집 → 저장**을 반복하면
그때마다 화질이 깎인다. 원본을 고쳐 덮어쓰지 말고, **원본은 그대로 두고 한 번에 처리**해라.

**③ 인스타가 원하는 규격으로 맞춰서 올려라**

규격이 안 맞으면 인스타가 알아서 변환한다. **그 변환이 화질을 깎는다.**
미리 맞춰두면 그 단계가 덜 일어난다 [추정].

인스타그램 공식 문서 기준 [확인]:

| 항목 | 권장 |
| --- | --- |
| 비율 | **9:16** (다른 비율은 잘리거나 여백이 생긴다) |
| 영상 코덱 | **H.264** 또는 HEVC |
| 프레임레이트 | 23~60 FPS |
| 오디오 | **AAC**, 48kHz 이하 |
| 컨테이너 | MP4 또는 MOV |

> 출처: Instagram 공식 「Reel size & aspect ratios」 / Meta 개발자 문서 [확인]

### 확대할 거면 미리 키워놔라 — 화질과는 다른 얘기다

영상 일부를 확대(줌인)하면 그 부분만 크게 늘어나 깨진다.
나는 **원본을 2160×3840으로 먼저 키운 뒤 줌인을 걸고, 마지막에 1080×1920으로 내렸다** [확인].

**이건 화질을 올리는 게 아니다.** 확대 과정에서 생기는 떨림과 계단 현상을 줄이는 것이다.
둘을 섞어 말하는 자료가 많은데, 다른 얘기다.

### 테두리도 같은 함정

가로 영상을 세로 화면에 그냥 올리면 위아래 검은 띠가 생긴다. 이것도 제외 사유다 [확인].
띠를 없애려면 잘라내거나, **같은 화면을 흐리게 깔아 채운다.**

**체크리스트 — 올리기 전 6초면 끝난다**
```
□ 워터마크 없나
□ 화질 뭉개지지 않았나
□ 검은 띠(위아래·좌우) 없나
□ 오디오 트랙 들어있나
□ 9:16 맞나
□ 화면이 글자로 꽉 차 있진 않나
```

## 2. 인스타가 실제로 예측하는 것 4가지

공식 문서 기준, 릴스에서 인스타가 가장 중요하게 보는 예측은 이것이다 [확인]:

| 순위 | 예측 |
| --- | --- |
| 1 | **다시 공유할 확률** |
| 2 | **끝까지 볼 확률** |
| 3 | 좋아요 누를 확률 |
| 4 | **오디오 페이지로 들어갈 확률** (= 따라 만들고 싶어졌나) |

> 출처: Instagram 공식 블로그 [확인]

### 여기서 나오는 결론

**"좋아요 눌러주세요"는 3순위를 향한 요청이다.**
1순위와 2순위를 못 건드린다.

- **공유될 이유**가 영상 안에 있어야 한다 — 남에게 보낼 만한 것인가
- **끝까지 볼 이유**가 있어야 한다 — 마지막에 뭐가 있나

릴스는 **모르는 사람에게 보여주는 자리**다 [확인]. 팔로워용 인사("안녕하세요 여러분")가 안 먹히는 건 취향 문제가 아니라 **보는 사람이 애초에 남**이기 때문이다.

## 3. 훅 — 1.5초를 버렸다

> **연결되는 지표: 끝까지 볼 확률 (공식 2순위)**

첫 버전 훅은 **깨끗해진 수도꼭지 클로즈업 1.5초** 였다. 자막은 "2천원으로 이렇게 됨".

꽤 괜찮다고 생각했다. **완전히 틀렸다.**

> 보는 사람은 **뭐가 "이렇게"인지 모른다.**
> Before를 못 봤으니, 깨끗한 수도꼭지는 그냥 **평범한 수도꼭지**다.
> **광택은 비교가 있어야 광택으로 읽힌다.**

1.5초 동안 나는 "변화"를 보여준다고 믿었고, 보는 사람은 **아무 일도 없는 화면**을 보고 있었다.
그 1.5초가 영상 전체를 결정한다. 거기서 넘기면 나머지 30초는 존재하지 않는다.

**고친 것**
```
Before 0.9초  "이랬는데"
After  1.1초  "2천원으로 이렇게 됨"
```

**조건이 하나 있다 — 같은 구도, 같은 크롭.**
구도가 다르면 변화가 아니라 그냥 다른 장면 두 개로 읽힌다. 이건 비교가 아니다.

> **적용 질문**
> 내 훅은 **"결과"만** 보여주고 있나, **"차이"를** 보여주고 있나?
> 첫 화면만 떼서 남에게 보여줬을 때, **뭐가 달라졌는지 말할 수 있나?**

## 4. 자막 — 설명을 멈추는 데 가장 오래 걸렸다

> **연결되는 지표: 끝까지 볼 확률 + 다시 공유할 확률 (공식 1·2순위)**

자막을 고치는 데 제일 오래 걸렸다. 문장이 어려워서가 아니다.
**내가 계속 설명을 하고 있어서**였다.

| ❌ 설명체 | ⭕ 하소연체 |
| --- | --- |
| "세면대에 물때가 생겼습니다" | "이 꼴..." |
| "다이소 제품을 사용했습니다" | "그래서 해봤지" |
| "효과가 좋았습니다" | "아 근데 팔 좀 아파" |

**설명은 정보를 주고, 하소연은 사람을 준다.**

정보는 검색해서 얻는다. 릴스를 끝까지 보는 이유는 정보가 아니다 [추정].

### 불평 한 줄이 광고와 후기를 가른다

**"아 근데 팔 좀 아파"** — 이 한 줄을 빼면 영상이 광고가 된다.

좋은 말만 있는 후기는 후기로 안 읽힌다.
**단점을 말하는 사람만 장점도 믿어준다.**

그리고 공유는 여기서 나온다. 사람들은 정보를 공유하는 게 아니라 **"이거 완전 나잖아"** 를 공유한다.
"물때 제거법"은 저장되고, **"이 꼴"** 은 공유된다 [추정].

> **적용 질문**
> 내 자막에서 **불평·실패·귀찮음**이 한 줄이라도 있나?
> 전부 좋은 말이면, 광고를 만든 거다.

## 5. 순서 — 컷 하나 위치 때문에 후기가 광고가 됐다

> **연결되는 지표: 다시 공유할 확률 (공식 1순위)**

초판에서 **스펀지로 문지르는 장면을 앞쪽에 뒀다.** 화면이 예뻐서 골랐다.

그리고 영상 전체가 이상해졌다. 한참 뒤에 이유를 알았다.

```
❌ 내가 만든 순서
   제품 등장  →  AI에게 물어봄  →  써봄
   "이미 아는 걸 왜 물어보지?"

⭕ 고친 순서
   문제 발견  →  AI에게 물어봄  →  제품 등장  →  써봄
   "나도 몰랐는데 이렇게 찾았다"
```

**제품을 알게 된 장면보다 제품이 먼저 나왔다.**

이러면 "찾았다 → 샀다 → 해봤다"의 순서가 무너진다.
**발견의 서사가 사라지면 남는 건 광고다.** 컷을 하나도 안 바꾸고, 위치만 옮겨서 고쳤다.

### 왜 이게 공유를 결정하나

사람들이 남에게 보내는 건 **결론**이 아니라 **발견**이다.

- "이 제품 좋대" → 안 보낸다. 광고 같다
- "이렇게 찾았대" → 보낸다. **자기도 써먹을 수 있어서다**

내가 이미 다 아는 사람으로 등장하면, 보는 사람이 가져갈 게 없다.

> **적용 질문**
> 내 영상에 **"몰랐다 → 알게 됐다"** 구간이 있나?
> 없으면 그건 정보 영상이지 릴스가 아니다.

## 6. 안전영역 — 편집 화면에선 완벽했다

> **연결되는 지표: 끝까지 볼 확률 (공식 2순위)**

편집 화면에서는 멀쩡했다. 폰으로 열어보니 **자막 끝 글자가 잘려 있었다.**

내가 실제로 당한 것 두 개다 [확인].

1. **좌우 잘림을 계산에 안 넣어서** 자막 끝 글자가 날아갔다
2. **화면 속 글자를 확대한 줄 알고 축소해서** 지적을 받았다

2번이 더 뼈아프다. **확대했다고 믿고 확인을 안 했다.**

폰에서는 위아래를 UI가 덮고, 좌우가 잘린다. **편집 화면은 이걸 안 보여준다.**
그리고 글자가 안 읽히는 영상은 훅이 아무리 좋아도 거기서 끝난다.

**규칙**
```
□ 자막은 화면 중앙 쪽으로. 가장자리에 붙이지 않는다
□ "확대했다"고 생각한 것을 반드시 폰으로 다시 본다
□ 화면 녹화를 넣을 땐 크롭을 "질문용"과 "답변용"으로 분리한다
  (한 크롭으로 다 덮으려 하면 둘 다 안 읽힌다)
```

> **적용 질문**
> 올리기 전에 **폰으로 끝까지 한 번** 봤나?
> 편집 화면에서 본 건 본 게 아니다.

## 7. 정리 — 올리기 전 체크리스트

```
[ 제외 안 당하기 ]
□ 워터마크 없음
□ 화질 뭉개지지 않음 (받을 때 최고 해상도)
□ 검은 띠 없음
□ 오디오 트랙 있음
□ 9:16 / H.264 / AAC
□ 화면이 글자로 꽉 차 있지 않음

[ 끝까지 보게 하기 ]
□ 훅에 Before/After 비교가 있음
□ "몰랐다 → 알게 됐다" 구간이 있음
□ 마지막에 볼 이유가 남아 있음

[ 사람으로 읽히게 하기 ]
□ 자막이 설명체가 아님
□ 불평·실패가 최소 한 줄 있음

[ 안 잘리게 하기 ]
□ 폰으로 직접 확인함
□ 자막이 가장자리에 붙어있지 않음
```

## 8. 여기까지가 "무엇을"이다. "어떻게"가 남는다

위 체크리스트는 **어떤 편집 프로그램을 쓰든** 적용된다. 이 자료는 여기까지다.

그런데 대부분 여기서 멈춘다. 이유는 하나다.

> **구조는 알겠는데, 만들 줄을 모른다.**

나도 그랬다. 그리고 지금도 편집 프로그램은 못 쓴다.

### 내가 실제로 한 방식

앞에서 예로 든 세면대 영상 — **컷 분할, 자막, 줌인, 로고 합성, 음성 동기화를 전부 글로 지시해서** 만들었다.
타임라인을 끌어본 적이 없다.

**그런데 쉬웠다고는 안 하겠다.**

| | |
| --- | --- |
| 완성까지 만든 버전 | **19개** |
| 자막 싱크를 틀린 횟수 | **3번** |
| 최종 확인 방법 | AI 측정이 아니라 **내가 귀로 듣고** 잡음 |

"AI가 알아서 해준다"는 말은 안 한다. **정확히 지시하는 기술**이 필요하고, 여러 번 다시 돌린다.
그걸 숨기면 첫 시도에서 막히고 환불한다.

### 유료판에 있는 것

```
1장  폰에서 작업 환경 여는 법      ← 여기서 대부분 막힌다. 가장 두껍게 썼다
2장  파일 준비 — 파일명·폰트·용량
3장  구간 지정 지시문 — "적당히" 라고 쓰면 안 되는 이유
4장  컷 합치기                   ← 여기서 첫 영상이 나온다
5장  자막·음성 싱크               ← 내가 3번 틀린 곳. 가장 두껍다
6장  안전영역 검수
7장  소스 구하는 법
8장  쿠팡 파트너스 연결
```

**성공담이 아니라 틀린 기록이 본문이다.**
어디서 막히는지 알고 쓴 책과, 다 됐다고 쓴 책은 4장부터 갈린다.

## 표기 및 면책

- 나는 이 방식(해외 소스 믹스 + 직접 촬영)으로 **초기 팔로워 약 1,000명**을 모았다. 사실 기록이다.
- 쿠팡 파트너스는 **2개월 운영 중 가장 잘 나온 달 100만 원**이다. 월 평균이 아니다.
- **같은 결과를 보장하지 않는다.** 조회수·팔로워·수익 어느 것도 보장하지 않는다.
- 인스타그램 정책은 바뀐다. 적용 전 공식 문서를 직접 확인할 것.
- 다른 창작자의 영상을 사용할 경우 저작권·플랫폼 약관은 사용자 본인 책임이다.
