# (무료판) 릴스가 안 터지는 진짜 이유

> **무료 리드 자료 초안.** 독자 준비물 없음 — 구독·설치·계정 연결 전부 불필요.
> 읽고 바로 적용하는 것만 담는다. 제작 방법은 유료판.
>
> **근거 등급** [확인] 출처 있음 / [추정] 추론 / [모름] 확인 불가

## 0. 먼저, 이 책이 하는 말과 안 하는 말

이 책은 **조회수를 보장하지 않는다.** 그런 걸 보장하는 자료는 전부 의심해라.

이 책이 하는 건 두 가지다.

1. **인스타가 공식적으로 밝힌 것**을 정리한다 — 추측이 아니라 문서에 있는 것
2. **내가 릴스 한 편을 19번 고친 기록**을 공개한다 — 뭘 틀렸고 왜 고쳤는지

숫자로 겁주거나 부풀리지 않는다. 출처 없는 통계는 한 줄도 넣지 않았다.

---

## 1. 대부분은 "안 터지는" 게 아니라 **추천에서 빠진 것**이다

여기서부터 보는 게 순서다. 훅을 아무리 잘 짜도 **추천 대상에서 제외되면 훅을 볼 사람이 없다.**

인스타그램이 **공식적으로 밝힌 "추천하지 않는 릴스"** [확인]:

| 제외 사유 |
| --- |
| **워터마크가 박힌 영상** |
| 저해상도 |
| 음소거된 영상 |
| 테두리(레터박스)가 있는 영상 |
| 화면 대부분이 텍스트인 영상 |
| 정치적 사안 중심 |

> 출처: Instagram 공식 블로그 「Instagram Ranking Explained」 [확인]

### ⚠️ 워터마크 — 가장 많이 걸리는 함정

다른 플랫폼에서 받은 영상에는 **워터마크가 남아 있다.** 그 상태로 올리면 위 목록 1번에 그대로 걸린다.

**틱톡·기타 앱에서 받은 소스를 쓸 거라면, 워터마크 처리가 선택이 아니라 필수 조건이다.**
이걸 모르고 올리면 "알고리즘이 안 밀어준다"가 아니라 **애초에 후보에서 빠진 것**이다.

### 테두리도 같은 함정

가로 영상을 세로 화면에 그냥 올리면 위아래 검은 띠가 생긴다. 이것도 제외 사유다 [확인].

**체크리스트 — 올리기 전 6초면 끝난다**
```
□ 워터마크 없나
□ 검은 띠(위아래·좌우) 없나
□ 오디오 트랙 들어있나
□ 화면이 글자로 꽉 차 있진 않나
```

## 2. 인스타가 실제로 예측하는 것 4가지

공식 문서 기준, 릴스에서 인스타가 가장 중요하게 보는 예측은 이것이다 [확인]:

| 순위 | 예측 |
| --- | --- |
| 1 | **다시 공유할 확률** |
| 2 | **끝까지 볼 확률** |
| 3 | 좋아요 누를 확률 |
| 4 | **오디오 페이지로 들어갈 확률** (= 따라 만들고 싶어졌나) |

> 출처: Instagram 공식 블로그 [확인]

### 여기서 나오는 결론

**"좋아요 눌러주세요"는 3순위를 향한 요청이다.**
1순위와 2순위를 못 건드린다.

- **공유될 이유**가 영상 안에 있어야 한다 — 남에게 보낼 만한 것인가
- **끝까지 볼 이유**가 있어야 한다 — 마지막에 뭐가 있나

릴스는 **모르는 사람에게 보여주는 자리**다 [확인]. 팔로워용 인사("안녕하세요 여러분")가 안 먹히는 건 취향 문제가 아니라 **보는 사람이 애초에 남**이기 때문이다.

---

## 3. 훅 — 비교가 없으면 변화가 안 보인다

여기부터는 내가 실제로 틀렸다가 고친 기록이다 [확인].

세면대 청소 릴스를 만들었다. 첫 버전 훅은 **깨끗해진 수도꼭지 클로즈업 1.5초** 였다.
자막은 "2천원으로 이렇게 됨".

**안 된다.** 이유:

> 보는 사람은 **뭐가 "이렇게"인지 모른다.**
> Before를 못 봤으니 깨끗한 수도꼭지는 그냥 평범한 수도꼭지다.
> **광택은 비교가 있어야 광택으로 읽힌다.**

고친 것:

```
Before 0.9초  "이랬는데"
After  1.1초  "2천원으로 이렇게 됨"
```

**조건: 같은 구도, 같은 크롭.** 구도가 다르면 변화가 아니라 다른 장면으로 읽힌다.

> **적용 질문**
> 내 훅은 "결과"만 보여주고 있나, "차이"를 보여주고 있나?

---

## 4. 자막 — 설명체를 하소연체로 바꿨다

첫 버전 자막은 전부 설명이었다.

| ❌ 설명체 | ⭕ 하소연체 |
| --- | --- |
| "세면대에 물때가 생겼습니다" | "이 꼴..." |
| "다이소 제품을 사용했습니다" | "그래서 해봤지" |
| "효과가 좋았습니다" | "아 근데 팔 좀 아파" |

**설명은 정보를 주고, 하소연은 사람을 준다.**
릴스에서 남이 끝까지 보는 건 정보가 아니라 사람 쪽이다 [추정].

특히 **"아 근데 팔 좀 아파"** 같은 불평 한 줄. 이게 광고랑 후기를 가른다.
좋은 말만 있으면 광고로 읽힌다.

---

## 5. 순서 — 제품이 먼저 나오면 서사가 죽는다

초판에서 **스펀지로 문지르는 장면을 앞쪽에 배치**했다. 화면만 보고 골랐다.

문제: **제품을 알게 된 장면보다 제품이 먼저 나왔다.**
"찾았다 → 샀다 → 해봤다"의 순서가 깨지면 **발견의 서사가 사라지고 그냥 광고가 된다.**

→ 해당 컷을 뒤로 옮겼다.

> **적용 질문**
> 내 영상에서 **"몰랐다 → 알게 됐다"** 구간이 존재하나?
> 그게 없으면 정보 영상이지 릴스가 아니다.

## 6. 안전영역 — 폰에서 글자가 잘린다

내가 실제로 당한 것 두 개다 [확인].

1. **좌우 잘림을 계산에 안 넣어서 자막 끝 글자가 잘렸다**
2. **화면 속 글자를 확대한 줄 알고 축소해서** 피드백을 받았다

편집 화면에서는 멀쩡하다. **폰에서 보면 UI가 위아래를 덮고, 좌우가 잘린다.**

**규칙**
```
□ 자막은 화면 중앙 쪽으로. 가장자리에 붙이지 않는다
□ 확대했다고 생각한 것을 반드시 폰으로 다시 본다
□ 화면 녹화를 넣을 땐 크롭을 "질문용"과 "답변용"으로 분리한다
  (한 크롭으로 다 덮으려 하면 둘 다 안 읽힌다)
```

## 7. 정리 — 올리기 전 체크리스트

```
[ 제외 안 당하기 ]
□ 워터마크 없음
□ 검은 띠 없음
□ 오디오 트랙 있음
□ 화면이 글자로 꽉 차 있지 않음

[ 끝까지 보게 하기 ]
□ 훅에 Before/After 비교가 있음
□ "몰랐다 → 알게 됐다" 구간이 있음
□ 마지막에 볼 이유가 남아 있음

[ 사람으로 읽히게 하기 ]
□ 자막이 설명체가 아님
□ 불평·실패가 최소 한 줄 있음

[ 안 잘리게 하기 ]
□ 폰으로 직접 확인함
□ 자막이 가장자리에 붙어있지 않음
```

## 8. 여기서 끝나도 쓸 수 있다

위 체크리스트는 **어떤 편집 프로그램을 쓰든** 적용된다. 이 자료는 여기까지다.

다만 하나 남는다. **구조는 알겠는데, 만들 줄을 모른다.**

나는 편집 프로그램을 쓰지 않는다. 컷 분할·자막·푸시인·음성 동기화를 **전부 텍스트 지시로** 처리했다.
위 세면대 영상도 그렇게 만들었다 — **총 19개 버전**을 거쳤고, **자막 싱크를 세 번 틀렸다.**

그 과정 전부를 유료판에 적었다. 성공담이 아니라 **틀린 기록**까지.

> **유료판에 있는 것**
> 폰에서 작업 환경 여는 법 / 구간 지정 지시문 / 컷 합치기 / 자막 싱크 맞추기 /
> 안전영역 검수 / 소스 구하는 법 / 쿠팡 파트너스 연결

## 표기 및 면책

- 나는 이 방식(해외 소스 믹스 + 직접 촬영)으로 **초기 팔로워 약 1,000명**을 모았다. 사실 기록이다.
- **같은 결과를 보장하지 않는다.** 조회수·팔로워·수익 어느 것도 보장하지 않는다.
- 인스타그램 정책은 바뀐다. 적용 전 공식 문서를 직접 확인할 것.
- 다른 창작자의 영상을 사용할 경우 저작권·플랫폼 약관은 사용자 본인 책임이다.
