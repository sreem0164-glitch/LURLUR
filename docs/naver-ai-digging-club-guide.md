# 네이버 AI 디깅클럽 — 운영 가이드 정리

> 오리엔테이션 슬라이드(사진·영상 촬영본)에서 판독한 **공식 규정** 정리입니다.
> 기획·연출 방법론은 [콘텐츠 밸런싱 전략](./content-balancing-strategy.md),
> 업로드 계정 기준은 [푸리랩이슈 계정 운영 기준](./account-purilab-issue.md)을 참고하세요.

---

## 1. 프로그램 개요

> **내가 좋아하는 것과 취향을 네이버 AI탭으로 더 깊이 파고 들고,
> 나만의 숏폼 콘텐츠로 만들며 콘텐츠 크리에이터로 성장하는 활동**

| 단계 | 내용 |
| --- | --- |
| **① 디깅** | `#맛집` `#쇼핑` `#여행` `#대학생활` 등 나만의 취향을 더 깊이 있게 |
| **② 네이버 AI탭** | 네이버 AI탭을 통한 새로운 아이디어 · 정보 탐색 |
| **③ 콘텐츠** | 나만의 숏폼 콘텐츠 기획·제작 & 영상 전문가의 피드백 |

## 2. 명칭 표기 가이드 ⚠️

콘텐츠 자막·설명·해시태그에서 **띄어쓰기까지 정확히** 지켜야 합니다.

### 네이버 AI탭

| 구분 | 표기 |
| --- | --- |
| ✅ 한글 | `네이버 AI탭` , `AI탭` — **AI와 탭을 붙여 씀** |
| ✅ 영문 | `AI Tab` |
| ❌ 오표기 | `AI 탭` (띄어쓰기 X) |

### 네이버 AI 디깅클럽

| 구분 | 표기 |
| --- | --- |
| ✅ 한글 | `네이버 AI 디깅클럽` , `AI 디깅클럽` — **AI 뒤는 띄고, 디깅클럽은 붙여 씀** |
| ✅ 영문 | `AI Digging Club` |
| ❌ 오표기 | `AI디깅클럽` , `AI디깅 클럽` |

> **헷갈리기 쉬운 지점:** 두 명칭의 띄어쓰기 규칙이 서로 반대입니다.
> **`AI탭`은 붙이고, `AI 디깅클럽`은 띄웁니다.**

## 3. 미션 제출물과 필수 조건 (카페 공지 기준)

> 원문: 네이버 카페 콘텐츠 가이드 `cafe.naver.com/aidiggingclub/2`

### 제출물은 4종

| 제출물 | 비고 |
| --- | --- |
| **숏폼 영상** | 30~60초 이내 권장 |
| **영상 캡션** | **전체 SNS에서 동일하게** 작성 |
| **썸네일** | 별도 제출물 |
| **콘텐츠 제목** | 네이버 클립 / 유튜브 쇼츠 / 틱톡 등 **제목이 별도로 필요한 매체용** |

### 매 미션 공통 필수 조건

| 항목 | 내용 |
| --- | --- |
| **AI탭 노출** | 영상 내 네이버 AI탭 **진입 + 사용 화면 필수 노출** |
| **필수 해시태그** | `#네이버` `#AI탭` `#네이버AI디깅클럽` |
| **캡션 하단 문구** | "네이버 AI 디깅클럽 활동의 일환으로 제작한 콘텐츠입니다." |

> ⚠️ **해시태그는 붙여 씁니다 — `#네이버AI디깅클럽`.**
> 위 2장의 표기 규칙(`네이버 AI 디깅클럽`, 띄어쓰기)은 **본문 표기**에 적용되고,
> 해시태그는 공백을 쓸 수 없으므로 붙입니다. 서로 다른 규칙이니 헷갈리지 마세요.

### 제출 프로세스 STEP 1~4

| 단계 | 내용 |
| --- | --- |
| **STEP 1** | 미션 공지 확인 → 영상·캡션·썸네일·제목 **제출** |
| **STEP 2** | **영상 PD 피드백** 확인 → 기한 내 수정 재제출<br>⚠️ 수정 시 **게시물 제목 변경 필수** — `[활동자명] 미션 O차 제출` |
| **STEP 3** | **운영사무국 최종 확인 후** 네이버 클립 + 지원 시 기재한 개인 인스타그램(**`푸리랩이슈`**)에 업로드<br>→ 업로드 직후 **콘텐츠 링크 제출 게시판**에 링크 제출 (미러링분 전체 포함)<br>*타 SNS 미러링은 선택 · 매체별 **안전 영역·라이선스(음악 등)** 확인 필수 |
| **STEP 4** | **업로드 10일 후** — 미션 성과 제출 게시판 폼으로 **콘텐츠 결과 인사이트 제출**<br>(필수) 네이버 클립 · 인스타그램 릴스 / (선택) 미러링 채널 |

> ⚠️ **STEP 3의 "지원 시 기재한 개인 인스타그램"이 `푸리랩이슈`가 맞는지 먼저 확인하세요.**
> 지원서에 다른 계정을 적었다면 업로드 전에 운영사무국에 변경 가능 여부를 문의해야 합니다.
> 채널이 어긋나면 링크 제출(STEP 3)과 인사이트 제출(STEP 4)이 통째로 막힙니다.

## 4. 콘텐츠 제작 및 발행 규정

| 항목 | 규정 |
| --- | --- |
| **분량** | **1분 이내** 숏폼 영상 · *최소 30초 이상 권장 |
| **규격** | **1,080 × 1,920px** |
| **텍스트 검수** | 콘텐츠 자막 및 나레이션 내 **오탈자, 잘못된 표현, 맞춤법 검사 필수** |
| **발행** | 운영국 피드백 이후, **제출/업로드 기한에 맞춰 개인 채널 업로드** |
| **업로드 채널** | *본 계정을 활용하여 **네이버 클립 + 인스타그램 릴스 동시 업로드**<br>→ 인스타그램은 **`푸리랩이슈`** ([계정 운영 기준](./account-purilab-issue.md)) |

## 5. 제작 시 유의사항 — 화면 영역 가이드

### 규격 두 가지를 동시에 만족시켜야 합니다

| 영역 | 규격 | 노출 위치 |
| --- | --- | --- |
| **전체 캔버스** | **1,080 × 1,920px** | 릴스 탭 (풀스크린 재생) |
| **주요 내용 영역 (안전 영역)** | **1,080 × 1,350px** | 그리드 탭 (프로필 피드 썸네일) |

**즉 —**
- 영상은 **1,080 × 1,920**으로 만들되,
- **핵심 문구와 주요 내용은 반드시 1,080 × 1,350 안전 영역 안에** 배치합니다.
- 그리드 탭에서는 위아래가 잘려 나가므로, 안전 영역을 벗어난 자막은 프로필에서 보이지 않습니다.

### 릴스 썸네일

- 릴스 썸네일은 **인스타그램 썸네일 노출 규격을 고려하여**,
  **핵심 문구와 주요 내용이 잘리지 않도록 안전 영역 내에 배치**합니다.
- 숏폼은 인트로가 곧 썸네일이므로, **첫 컷의 자막 위치가 곧 썸네일 구도**입니다.

## 6. 콘텐츠 DO ✅

| # | 해야 할 것 |
| --- | --- |
| **①** | 피상적 칭찬보다는 **주위 친구들에게 추천한다는 마음으로 AI탭의 매력 포인트를 구체적으로 제시하기** |
| **②** | 콘텐츠 내에서 **한 번은 AI탭의 진입점과 사용 화면 보여주기** |
| **③** | 콘텐츠 내 **AI로 만든 이미지·영상 활용 OK** — 단, 해당 산출물을 **AI탭으로 만들었다는 오해가 생기지 않는 범위에서** 활용 |
| **④** | 영상에는 **본인이 아닌 타인의 개인정보가 나오지 않게 하기!** (*불가피한 경우 모자이크) |

> 슬라이드 구성상 **콘텐츠 DON'T** 장표가 이어서 존재하나, 자료가 없어 이 문서에는 담기지 않았습니다.
> 위 DO 4항목과 아래 체크리스트를 기준으로 판단하고, 애매한 건은 운영사무국에 확인하세요.

## 제출 전 최종 체크리스트

- [ ] 길이가 **30초~1분** 사이인가
- [ ] 캔버스가 **1,080 × 1,920**인가
- [ ] 핵심 문구가 **1,080 × 1,350 안전 영역** 안에 있는가 (그리드 탭에서 안 잘리는가)
- [ ] `AI탭` / `AI 디깅클럽` **띄어쓰기**가 정확한가
- [ ] 자막·나레이션 **맞춤법 검사**를 돌렸는가
- [ ] **AI탭 진입점과 사용 화면**이 한 번 이상 나오는가
- [ ] AI 생성물이 **AI탭 산출물로 오해될 여지**는 없는가
- [ ] **타인의 개인정보**(얼굴·이름·연락처 등)가 노출되지 않는가
- [ ] 운영국 피드백 반영 후 **네이버 클립 + 인스타그램 릴스에 동시 업로드**했는가
- [ ] 업로드 계정이 **지원서에 기재한 계정(`푸리랩이슈`)** 과 일치하는가
- [ ] 미션 게시물 캡션에 **제휴 링크·제휴 고지 문구가 섞이지 않았는가**
