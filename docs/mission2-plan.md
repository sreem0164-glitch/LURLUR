## 0. 확인된 사실

### 사용자 관찰 [확인]

- 대전 **탄방역점**이 하이브리드 매장

- **탄방동에 일반 파리바게뜨가 따로 있음**
- 파바 하이브리드 매장이 많은 건 아님 (여러 개씩 생기는 상황이 아님)
- 무인점포는 실제로 계속 생겼다 없어짐

## 1. 분석 — 왜 이게 흥미로운가

### ① 무인점포의 약점을 낮 시간으로 덮은 구조 [추정]

```
일반 무인점포 : 100% 무인 → 재고·신선도·도난 관리 불가 → 식품은 특히 치명적
하이브리드    : 낮에 사람이 관리 → 밤에만 무인 → 인건비만 절감
```

무인점포가 없어지는 이유가 "무인이라서"가 아니라 **"관리할 사람이 없어서"** 라면,
하이브리드는 그 문제를 피해간 형태입니다. 같은 무인이지만 구조가 다릅니다.

### ② 공실 자리에 들어온 것의 의미 [추정]

공실은 임대료 협상력이 있는 자리입니다.
심야 매출이 얹히면 기존에 수익이 안 나던 자리도 손익이 맞을 수 있습니다.

### ③ 같은 동네에 일반 매장이 있는데 왜 또? [추정]

- 일반 매장 = 주거지 낮 수요
- 역 앞 하이브리드 = **심야 통행 수요**
- 보도의 확대 기준(늦은 시간 유동인구 많은 곳)과 역세권이 일치

상권이 겹치지 않는다는 가설입니다. 서울 테스트 2곳도 역세권입니다.

> ①②③ 전부 [추정]입니다. 보도된 사실에서 추론한 것이고,
> SPC의 실제 출점 기준은 확인된 바 없습니다 [모름].

## 2. AI탭 질문

```
질문 ①
무인점포 다 망하던데 파리바게뜨 하이브리드 매장은 뭐가 달라?

        ↓ 답변에서 좁힘

질문 ②
우리 동네 파바 따로 있는데 역 앞에 하이브리드를 또 낸 이유가 뭐야?
```

- ①은 **관찰(무인점포는 없어진다) + 개념 질문**. `추천해줘` 형태가 아니므로 DON'T 아님
- ②는 **본인만 아는 사실**(같은 동네에 일반 매장 존재)로 좁힘
  → 가이드 POINT("나만의 기준이 질문 속에 드러나야")에 정면으로 부합
- 길이 32자 / 34자 — 화면에서 2~3줄

> ②는 ①의 답변을 보고 최종 확정합니다. 미리 고정하면 작위적으로 읽힙니다.

## 3. 구성

```
[훅]    와 우리 동네에 24시간 파리바게뜨 생겼어        ← 매장 외관 (야간)
[의외]  여기 한참 공실이던 자린데                     ← 공실 점포 컷
[의외]  무인점포는 생겼다 없어지기 바쁜데 파바가?
[액션]  신기해서 AI탭한테 물어봤어                    ← AI탭 진입
[질문①] 무인점포 다 망하던데 하이브리드는 뭐가 달라?    ← 화면 2초, 크게
[답변]  (AI 답변) → 매장에서 실제로 확인               ← 키오스크·카드인증 실사
[질문②] 동네에 파바 있는데 역 앞에 또 낸 이유가 뭐야?   ← 화면 2초
[답변]  (AI 답변) → 결론
[CTA]
```

**질문은 화면에 크게 2초씩, 답변은 실사 위 자막으로 소화**합니다.
1차처럼 답변 전문을 오래 띄우면 40초 중 절반이 스크린샷이 됩니다.
