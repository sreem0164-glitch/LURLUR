> 제작 기한 9/21(월) · 검수 9/22~9/23
> 주제: **무인점포는 생겼다 없어지는데, 왜 파바 하이브리드는 공실 자리에 들어왔나**

---

## 0. 확인된 사실

### 사용자 관찰 [확인]

- 대전 **탄방역점**이 하이브리드 매장
- 그 자리는 원래 다른 점포 → **한참 공실** → 파바로 바뀜
- **탄방동에 일반 파리바게뜨가 따로 있음**
- 파바 하이브리드 매장이 많은 건 아님 (여러 개씩 생기는 상황이 아님)
- 무인점포는 실제로 계속 생겼다 없어짐

### 언론 보도 [확인]

| 항목 | 내용 |
| --- | --- |
| 발표 | 2025-12-26, 프랜차이즈 베이커리 **업계 최초** 24시간 운영 |
| 운영 | **주간 = 직원 상주 / 심야·새벽 = 무인 전환** |
| 입장 | 신용카드 인증 |

## 1. 분석 — 왜 이게 흥미로운가

### ① 무인점포의 약점을 낮 시간으로 덮은 구조 [추정]

```
일반 무인점포 : 100% 무인 → 재고·신선도·도난 관리 불가 → 식품은 특히 치명적
하이브리드    : 낮에 사람이 관리 → 밤에만 무인 → 인건비만 절감
```

무인점포가 없어지는 이유가 "무인이라서"가 아니라 **"관리할 사람이 없어서"** 라면,
하이브리드는 그 문제를 피해간 형태입니다. 같은 무인이지만 구조가 다릅니다.

### ② 공실 자리에 들어온 것의 의미 [추정]

공실은 임대료 협상력이 있는 자리입니다.
심야 매출이 얹히면 기존에 수익이 안 나던 자리도 손익이 맞을 수 있습니다.

### ③ 같은 동네에 일반 매장이 있는데 왜 또? [추정]

- 일반 매장 = 주거지 낮 수요
- 역 앞 하이브리드 = **심야 통행 수요**
- 보도의 확대 기준(늦은 시간 유동인구 많은 곳)과 역세권이 일치

상권이 겹치지 않는다는 가설입니다. 서울 테스트 2곳도 역세권입니다.

> ①②③ 전부 [추정]입니다. 보도된 사실에서 추론한 것이고,
> SPC의 실제 출점 기준은 확인된 바 없습니다 [모름].
> **영상에서는 이 추론을 단정하지 말고, AI탭 답변으로 받아야 합니다.**

## 2. AI탭 질문 — 확정

```
질문 ①
창업 알아보는 중인데 무인점포는 다 망하고 파리바게뜨 하이브리드는 왜 달라?

질문 ②
동네에 파바 또 있는데 왜 역 앞 매장만 바꿨을까?
```

②는 ①의 답변에 나온 **"유동 인구 많은 도심 번화가 우선 확대"** 를 받아
"그럼 우리 동네는 왜?"로 좁힌 것입니다. 가이드가 말한 *나만의 답을 찾아가는 과정*.

## 3. AI탭 답변에서 확보한 사실 [확인 — 답변 화면 기준]

| 항목 | 내용 |
| --- | --- |
| 운영 | 낮 직원 상주 / 심야 무인 전환 |
| 출입·결제 | 카드 인증 출입 → 제품 바코드 스캔 → 키오스크 |
| 완전 무인점포 실패 요인 | 짧은 유통기한 재고 관리 / 상권 분석 부족 / 기기 고장·수리 지연 |
| 테스트 매장 심야 매출 | **추가 인건비 없이 하루 평균 10만 원 이상** |
| 일평균 매출 | **5~6% 증가** |
| 전환 규모 | **2026년 3월 말 기준 전국 16개** (서울·경기·대전·부산) |
| 확대 방향 | 유동 인구 많은 도심 번화가 우선 |

### 탄방역점 [확인 — 사용자]

- 원래 파리바게뜨였음
- 잠깐 운영 중단 → 공사 → 그랜드 오픈
- 탄방동에 일반 파리바게뜨가 별도로 있음

### 핵심 논리

```
완전 무인점포   :  빈 자리에 새로 차림 → 재고·기기 관리 공백 → 없어짐
파바 하이브리드 :  되던 매장을 공사해 전환 → 낮엔 직원이 관리 → 밤만 자동화
```

AI탭이 짚은 실패 요인 3가지가 전부 **사람이 없어서** 생기는 문제입니다.
하이브리드는 그 시간대를 유인으로 덮었습니다.

## 4. 나레이션 (40초 기준)

```
[1]  와 동네 파리바게뜨가 24시간이 됐어
[2]  공사하더니 그랜드 오픈했는데
[3]  무인점포는 생겼다 없어지기 바쁜데
[4]  여긴 왜 되는 거지?

[5]  AI탭한테 물어봤거든
[6]  낮엔 직원 있고 밤에만 무인으로 바뀌는 거래
[7]  완전 무인은 재고 관리가 안 돼서 없어지는 거였네

[8]  근데 동네에 파바 또 있잖아
[9]  왜 역 앞 매장만 바꿨지?
[10] 유동인구 많은 데부터 바꾸는 중이래

[11] 새로 차린 게 아니라
[12] 되던 매장을 바꾼 거였음

[13] 이런 거 파보는 AI 질문법 궁금하면 댓글에 정보 남겨줘!
```

### ⚠️ 숫자는 나레이션에 넣지 않습니다

`전국 16개` 는 **2026년 3월 말 기준**입니다. 지금은 9월이라 늘었을 수 있습니다 [모름].
`하루 10만 원` 은 **테스트 매장** 수치라 일반화하면 틀립니다.

→ 숫자는 **AI탭 답변 화면에 나오는 것만** 보여주고, 나레이션은 단정하지 않습니다.
   화면은 인용이고 나레이션은 주장입니다. 틀렸을 때 책임이 다릅니다.
