> 작성 2026-09-20 · 제작 기한 9/21(월) · 검수 9/22~9/23

## 0. 주제 설정

```
❌ 파리바게뜨 24시 무인점포       →  가이드 ① "장소 단순 소개" 위반
✅ 무인점포 디깅                 →  브랜드는 배경, 나만의 기준이 주인공
```

가이드의 **빈티지 헌터** 앵글과 같은 구조입니다.
샵 추천이 아니라 "건지는 노하우"가 주인공인 형태.

| 근거 | |
| --- | --- |
| 찐 경험 | 무인점포를 자주 이용 [확인] |
| 채널 연결 | 자취생 = 밤늦게 뭔가 필요한 사람 / 무인점포 = 그 시간에 열린 곳 |
| 촬영 | 24시간 운영이라 시간 제약 없음 — 마감 하루 전에도 촬영 가능 |
| 1차와 차별 | 1차는 집 안 세면대, 2차는 밖. 그림이 겹치지 않음 |

## 1. AI탭 질문 설계

### 원칙 (가이드 ②)

| | |
| --- | --- |
| DON'T | `무인 베이커리 추천해줘` — 단순 키워드 + 추천 요청 |
| DO | 내 취향·경험·기준을 질문에 담아 **좁혀가는 연쇄** |

> 1차에서 쓴 `자취하는 대학생들을 위한 화장실 청소 필수품 추천해줘` 는
> 2차 DON'T 예시와 동형입니다. 같은 방식을 쓰면 반려됩니다.

### 브랜드명은 질문에 넣지 않습니다

특정 브랜드를 AI탭에 물으면 두 가지 위험이 생깁니다.
- DON'T 슬라이드 ⑦ — AI탭이 금지 답변(특정 브랜드 평가)을 하도록 유도
- 광고성 콘텐츠로 읽힘

질문은 `24시 무인 베이커리` 로 일반화하고, 브랜드는 **매장 촬영 배경**으로만 나옵니다.

### 기준 후보 — 하나를 골라 질문에 박습니다

| | 기준 | 왜 좋은가 |
| --- | --- | --- |
| **A** | **당일 생산 · 소비기한** | 무인 베이커리의 핵심 약점. 라벨이 화면에 찍혀 그림이 됨 |
| B | 밤 시간 이용 안전·동선 | 자취생 공감대는 크나 화면에 찍을 대상이 약함 |
| C | 결제·환불 방식 | 무인 특유지만 시각적으로 밋밋함 |

**A안 권장** — 유일하게 손으로 짚어 보여줄 수 있는 기준입니다.

### 질문 연쇄 (A안 기준)

```
질문 ①
자취생인데 밤 11시 넘어 무인 베이커리를 자주 써.
빵은 당일 생산인지가 제일 중요한데,
24시 무인 베이커리는 재고를 어떻게 관리해?

        ↓ 답변에서 하나를 물고 좁힘

질문 ②
그럼 밤늦게 남은 빵 중에 고를 때,
포장 라벨에서 뭘 순서대로 봐야 해?
```

- ①에 **내 상황(자취·밤 11시) + 내 기준(당일 생산)** 이 들어가 있습니다 → DO 충족
- ②는 ①의 답변을 받아 좁힙니다 → "한 번에 끝내지 않음" 충족
- ②의 답이 곧 영상의 **노하우 파트**가 됩니다

## 2. 촬영 전 필수 확인 ⛔

**찍으러 가기 전에 AI탭에 질문 ①을 먼저 던져보세요.**

답변이 부실하면 영상 중간이 비어버립니다. 1차는 답변에 제품명·가격이 나와서
화면이 채워졌는데, 무인 베이커리는 최근 사례라 AI탭이 정보를 못 가졌을 수 있습니다 [모름].

| 결과 | 조치 |
| --- | --- |
| 답변 나옴 | 그 화면이 곧 영상 소재. 그대로 진행 |
| 부실함 | 기준 B·C로 바꾸거나 질문을 일반 무인점포로 넓힘 |

## 3. 화면 녹화 규칙 (1차 PD 피드백 반영)

1차 PD 지적 1번이 **"질문 내용이 잘 보이게"** 였습니다.
2차는 질문이 아예 주인공이라 처음부터 크게 잡아야 합니다.

| 항목 | 기준 | 근거 |
| --- | --- | --- |
| 질문 길이 | **2~3줄 이내** | 4줄 넘으면 화면에서 글자가 작아짐 |
| 질문 글자 크기 | 45px 이상 (1080 폭 기준) | 1차 v17이 29px이라 지적받음 [확인] |
| 좌우 안전폭 | 글자가 **x 100~980** 안 | 폰에서 양끝 잘림 [추정] |
| 두 질문 | **한 세션에서 이어서** 녹화 | 대화가 이어져야 "연쇄"로 읽힘 |
| 방해금지 모드 | 필수 | DON'T ④ 알림·계정명 노출 금지 |
| 답변 정지 | 핵심 문단에서 2초 멈춤 | 편집 시 정지프레임 확대용 |
