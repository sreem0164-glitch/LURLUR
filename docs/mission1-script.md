# 미션1 대본 — 만원으로 치킨 먹기 (리뷰 없음 버전)

> 제출일: **9/7(월) — 오늘** · **30초 이상 필수** · 1,080×1,920 · 안전영역 1,080×1,350
> 먹는 장면·맛 평가 없음. **"AI탭으로 찾아서 진짜 되는지 확인했다"** 까지가 전부.

---

## ⚠️ 리뷰를 빼면 생기는 문제와 해결

| 문제 | 해결 |
| --- | --- |
| **30초를 못 채울 수 있음** | AI탭 대화 구간을 늘림 — 한 번 묻고 끝내지 말고 **조건을 좁혀가며 2~3번** |
| 결론(payoff)이 사라짐 | **영수증이 결론.** "진짜 만원 안 넘는다"가 증명 |
| 단점 지적(DO ①)할 데가 없음 | 음식 대신 **AI탭 사용 과정에 솔직한 코멘트** 한 줄 |

> 대화 구간을 늘리는 게 오히려 **DO ②(AI탭 진입점과 사용 화면 보여주기)** 를 가장 잘 충족합니다.
> 리뷰를 뺀 만큼 **AI탭이 주인공**이 되는 구조입니다.

---

## 대사 / 자막 — 통본

> 원안 그대로 살리고 빈 곳만 채웠습니다. `+` 표시가 추가한 줄.

### #1 훅 (0~4초) · 늘어져 있는 컷 → 정면

```
돈 없는 대학생들!
이제 만원으로 치킨 먹어!!
```

> 이 첫 컷이 **썸네일**. 자막은 중앙(안전영역)에.

### #2 상황 (4~14초) · 가방 내려놓기 → 냉장고 열었다 닫기 → 폰 보기

```
이제 개강이라 힘이 쭉 빠진 나..
+ 학식도 없는 방통대 3학년, 저녁도 알아서 해결해야 됨
오늘 저녁 고르는데
치킨이 너무 먹고 싶은 거 있지?
+ 근데 통장은 조용하고...
```

> `+` 두 줄 중 **방통대 3학년**은 미션 요건(나를 표현하는 키워드)이라 빼면 안 됩니다.

### #3 AI탭에 묻기 (14~34초) · **필수 노출 구간, 본문**

```
그래서 AI한테 물어봄
   (화면) 네이버 앱 → AI탭 진입
   (화면) "만원으로 먹을 수 있는 치킨 알려줘"

+ 오 이런 것도 있네?
+    (화면) "편의점에서 살 수 있는 걸로"   ← 조건 좁히기

GS에 만원짜리 치킨 추천해주는 화면
+ 이건 진짜 몰랐는데
+ 처음엔 좀 엉뚱한 것도 알려주더라
```

> **진입 → 입력 → 답변** 3단계 다 보여줘야 요건 충족.
> 마지막 줄(솔직한 소감)은 DO ①(피상적 칭찬 금지) 대응이라 한 줄은 꼭 넣으세요.
> 화면 녹화본에 **알림·계정명** 안 찍혔는지 확인. (DO ④)

### #4 확인 (34~46초) · 편의점 → 매대 → 결제 → 영수증

```
+ 진짜인지 확인하러 감
+ 있네?
+ ○○○○원          ← 영수증에 찍힌 실제 금액
+ 진짜 만원 안 넘음
```

> **영수증 컷이 이 영상의 결론입니다.** 리뷰가 없으니 유일한 증거예요. 꼭 찍으세요.

### #5 엔딩 (46~53초) · 봉지 툭 내려놓기 → 정면

```
+ 오늘 저녁 해결!
+ 돈 없는 개강 시즌, 이렇게 버티는 중
+ 저장해두고 써먹어
```

## 오늘 반드시 지킬 것

| 항목 | 이유 |
| --- | --- |
| **30초 이상** | 위 구성대로면 약 50초. **AI탭 구간을 줄이지 마세요** |
| **가격·상품명은 화면에 나온 대로만** | 실제 AI탭 답변과 영수증 기준. 행사가는 시점·점포별로 다릅니다. 기억으로 쓰지 마세요 |
| **"이 시점 기준" 한 줄** | 가격 자막 옆에 작게 |
| **AI탭 3단계 화면** | 진입 → 입력 → 답변 |
| **영수증 컷** | 리뷰가 없으니 이게 유일한 증거 |
| **솔직한 코멘트 1줄** | DO ① 대응 |
| **해시태그 3개 + 하단 문구** | 누락 시 요건 미달 |

## 촬영 순서

```
1. 폰 화면 녹화     (AI탭 진입 → 질문 → 조건 좁히기 → 답변)  ← 지금 집에서 바로
2. 집 컷            (#1 훅 · #2 상황 · #5 엔딩 몰아서)
3. 편의점 컷        (들어가기 · 집기 · 결제 · 영수증)
```

> 편의점에서 **다른 손님이 화면에 안 들어오게** 하세요. 들어갔으면 모자이크 필수. (DO ④)
> 엔딩 컷은 편의점 다녀온 뒤에 찍어야 봉지가 손에 있습니다 — **집 컷을 두 번 나눠 찍는 게 편하면 그렇게 하세요.**
