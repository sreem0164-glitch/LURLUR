# 미션1 대본 — 만원으로 치킨 먹기 (리뷰 없음 버전)

> 제출일: **9/7(월) — 오늘** · **30초 이상 필수** · 1,080×1,920 · 안전영역 1,080×1,350
> 먹는 장면·맛 평가 없음. **"AI탭으로 찾아서 진짜 되는지 확인했다"** 까지가 전부.

---

## ⚠️ 리뷰를 빼면 생기는 문제와 해결

| 문제 | 해결 |
| --- | --- |
| **30초를 못 채울 수 있음** | AI탭 대화 구간을 늘림 — 한 번 묻고 끝내지 말고 **조건을 좁혀가며 2~3번** |
| 결론(payoff)이 사라짐 | **영수증이 결론.** "진짜 만원 안 넘는다"가 증명 |
| 단점 지적(DO ①)할 데가 없음 | 음식 대신 **AI탭 사용 과정에 솔직한 코멘트** 한 줄 |

> 대화 구간을 늘리는 게 오히려 **DO ②(AI탭 진입점과 사용 화면 보여주기)** 를 가장 잘 충족합니다.
> 리뷰를 뺀 만큼 **AI탭이 주인공**이 되는 구조입니다.

## 대사 / 자막

### #1 훅 (0~4초)

| 컷 | 자막 |
| --- | --- |
| 늘어져 있는 컷 | **"돈 없는 대학생 주목"** |
| 정면 / 폰 들기 | **"만원으로 치킨 먹는 법"** |

> 썸네일은 이 첫 컷. 자막은 **중앙(안전영역)** 에.

### #2 상황 (4~12초)

| 컷 | 자막 |
| --- | --- |
| 가방 툭 내려놓기 | "개강하니까 진이 쭉 빠짐" |
| 냉장고 열었다 닫기 | "근데 오늘따라 치킨이 너무 당겨" |
| 방 둘러보기 | **"학식도 없는 방통대 3학년은 저녁도 알아서 해결"** |
| 폰 화면 | "근데 통장은 조용하고" |

> 세 번째 줄이 **정체성 삽입 자리**입니다. 억지로 농학과를 넣지 말고 이 한 줄이면 요건 충족.

### #3 AI탭에 묻기 (12~32초) — **본문, 필수 노출 구간**

여기가 이제 콘텐츠의 중심입니다. **한 번 묻고 끝내지 마세요.**

| 컷 | 자막 |
| --- | --- |
| **네이버 앱 → AI탭 진입 화면** | "그래서 네이버 AI탭한테 물어봄" |
| 질문 입력 녹화 | *(화면)* "만원으로 먹을 수 있는 치킨 알려줘" |
| 답변 스크롤 | "오, 이런 것도 있네" |
| **다시 묻기** | *(화면)* "편의점에서 살 수 있는 걸로" ← **조건 좁히기** |
| 답변 클로즈업 | **"GS에 만원짜리 있대"** |
| 살짝 갸웃 | **"이건 진짜 몰랐는데"** |

> ⚠️ **진입점 → 입력 → 답변** 을 다 보여줘야 요건 충족.
> 화면 녹화본에 **알림·계정명**이 안 찍혔는지 확인. (DO ④)
>
> **솔직한 코멘트 한 줄** 을 이 구간 어딘가에 넣으세요 (DO ① 대응) —
> 예: "처음엔 좀 엉뚱한 것도 알려줌", "이건 우리 동네엔 없더라"

### #4 확인 (32~45초)

| 컷 | 자막 |
| --- | --- |
| 편의점 들어가는 컷 | "진짜인지 확인하러 감" |
| 매대에서 집는 컷 | "있네" |
| 결제 / **영수증 클로즈업** | **"○○○○원"** ← 실제 금액 그대로 |
| 봉지 들고 나오는 컷 | **"진짜 만원 안 넘음"** |

> **영수증 컷이 이 영상의 결론입니다.** 먹지 않아도 여기서 증명이 끝납니다. 반드시 찍으세요.

### #5 엔딩 (45~52초)

| 컷 | 자막 |
| --- | --- |
| 봉지 툭 내려놓는 컷 | **"오늘 저녁 해결 ⭕"** |
| 정면 마무리 | "돈 없는 개강 시즌, 이렇게 버티는 중" |

## 오늘 반드시 지킬 것

| 항목 | 이유 |
| --- | --- |
| **30초 이상** | 위 구성대로면 약 50초. **AI탭 구간을 줄이지 마세요** |
| **가격·상품명은 화면에 나온 대로만** | 실제 AI탭 답변과 영수증 기준. 행사가는 시점·점포별로 다릅니다. 기억으로 쓰지 마세요 |
| **"이 시점 기준" 한 줄** | 가격 자막 옆에 작게 |
| **AI탭 3단계 화면** | 진입 → 입력 → 답변 |
| **영수증 컷** | 리뷰가 없으니 이게 유일한 증거 |
| **솔직한 코멘트 1줄** | DO ① 대응 |
| **해시태그 3개 + 하단 문구** | 누락 시 요건 미달 |

## 촬영 순서

```
1. 폰 화면 녹화     (AI탭 진입 → 질문 → 조건 좁히기 → 답변)  ← 지금 집에서 바로
2. 집 컷            (#1 훅 · #2 상황 · #5 엔딩 몰아서)
3. 편의점 컷        (들어가기 · 집기 · 결제 · 영수증)
```

> 편의점에서 **다른 손님이 화면에 안 들어오게** 하세요. 들어갔으면 모자이크 필수. (DO ④)
> 엔딩 컷은 편의점 다녀온 뒤에 찍어야 봉지가 손에 있습니다 — **집 컷을 두 번 나눠 찍는 게 편하면 그렇게 하세요.**
