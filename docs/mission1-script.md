## 대사 / 자막

### #1 훅 (0~4초)

| 컷 | 자막 |
| --- | --- |
| 침대·책상에 늘어져 있는 컷 | **"돈 없는 대학생 주목"** |
| 정면 or 폰 화면 | **"만원으로 치킨 먹는 법"** |

> 썸네일은 이 첫 컷. 자막을 **중앙(안전영역)** 에 배치.

### #2 상황 (4~12초)

| 컷 | 자막 |
| --- | --- |
| 지친 표정 / 가방 툭 내려놓기 | "개강하니까 진이 쭉 빠짐" |
| 냉장고 열었다 닫기 | "근데 오늘따라 치킨이 너무 당겨" |
| 방 안 둘러보기 | **"학식도 없는 방통대 3학년은 저녁도 알아서 해결"** |
| 통장/잔액 화면 (금액 가려도 됨) | "근데 통장은 조용하고" |

> 세 번째 줄이 **정체성 삽입 자리**입니다. "캠퍼스가 없어서 학식도 없다" → 돈 없는 저녁과 자연스럽게 연결됩니다. 억지로 농학과를 넣지 말고 이 한 줄이면 요건은 충족됩니다.

### #3 AI탭에 묻기 (12~24초) — **필수 노출 구간**

| 컷 | 자막 |
| --- | --- |
| **네이버 앱 → AI탭 진입 화면** | "그래서 네이버 AI탭한테 물어봄" |
| 질문 입력 화면 녹화 | *(화면)* "만원으로 먹을 수 있는 치킨 알려줘" |
| 답변 나오는 화면 | "오, 이런 것도 있었어?" |
| 답변 클로즈업 | **"GS에 만원짜리 있대"** |

> ⚠️ **진입점 → 입력 → 답변** 세 단계를 다 보여줘야 요건 충족입니다.
> 화면 녹화본에 **알림·계정명**이 안 찍혔는지 확인하세요. (DO ④)

### #4 실행 (24~38초)

| 컷 | 자막 |
| --- | --- |
| 편의점 들어가는 컷 | "바로 가봄" |
| 매대에서 집는 컷 | "진짜 있네" |
| 결제 / 영수증 | **"진짜 ○○○○원"** ← 실제 금액 그대로 |
| 집에 와서 펼치는 컷 | "개봉" |

### #5 검증 (38~50초)

| 컷 | 자막 |
| --- | --- |
| 양이 보이는 탑다운 | "양은 이 정도" |
| 먹는 컷 | "맛은 — ○○" |
| 살짝 아쉬운 표정 | **"근데 △△는 좀 아쉬움"** ← **단점 필수** |

> 장점만 나열하면 광고로 읽히고 DO ①("피상적 칭찬 금지")에 걸립니다. **아쉬운 점 하나는 반드시.**

### #6 엔딩 (50~58초)

| 컷 | 자막 |
| --- | --- |

| 정면 마무리 | "개강하고 돈 없을 때 이걸로 버티자" |

