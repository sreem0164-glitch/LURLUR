# 미션1 대본 — 만원으로 치킨 먹기 (리뷰 없음 버전)

> 제출일: **9/7(월) — 오늘** · **30초 이상 필수** · 1,080×1,920 · 안전영역 1,080×1,350
> 먹는 장면·맛 평가 없음. **"AI탭으로 찾아서 진짜 되는지 확인했다"** 까지가 전부.

---

## ⚠️ 리뷰를 빼면 생기는 문제와 해결

| 문제 | 해결 |
| --- | --- |
| **30초를 못 채울 수 있음** | AI탭 대화 구간을 늘림 — 한 번 묻고 끝내지 말고 **조건을 좁혀가며 2~3번** |
| 결론(payoff)이 사라짐 | **영수증이 결론.** "진짜 만원 안 넘는다"가 증명 |
| 단점 지적(DO ①)할 데가 없음 | 음식 대신 **AI탭 사용 과정에 솔직한 코멘트** 한 줄 |

> 대화 구간을 늘리는 게 오히려 **DO ②(AI탭 진입점과 사용 화면 보여주기)** 를 가장 잘 충족합니다.
> 리뷰를 뺀 만큼 **AI탭이 주인공**이 되는 구조입니다.

---

## 대사 / 자막 — 통본

> **구매·리뷰 없음.** "저녁 뭐 먹지" 고민을 AI탭으로 끝내는 과정이 전부.
> 원안 그대로 살리고 빈 곳만 채웠습니다. `+` 가 추가한 줄.

### #1 훅 (0~4초) · 늘어져 있는 컷 → 정면

```
돈 없는 대학생들!
이제 만원으로 치킨 먹어!!
```

> 이 첫 컷이 **썸네일**. 자막은 중앙(안전영역)에.

### #2 상황 (4~14초) · 가방 내려놓기 → 냉장고 열었다 닫기 → 폰 보기

```
이제 개강이라 힘이 쭉 빠진 나..
+ 학식도 없는 방통대 3학년, 저녁도 알아서 해결해야 됨
오늘 저녁 고르는데
치킨이 너무 먹고 싶은 거 있지?
+ 근데 통장은 조용하고...
```

> `+` 중 **방통대 3학년**은 미션 요건(나를 표현하는 키워드)이라 빼면 안 됩니다.

### #3 AI탭에 묻기 (14~40초) · **여기가 영상의 전부입니다**

구매를 안 하므로 **이 구간이 분량의 절반 이상**입니다. 한 번 묻고 끝내면 30초가 안 나옵니다.
**질문 3번 = 고민이 좁혀지는 과정**으로 가세요.

```
그래서 AI한테 물어봄
   (화면) 네이버 앱 → AI탭 진입

── 1차
   (화면) "만원으로 먹을 수 있는 치킨 알려줘"
+ 오 이런 것도 있네?

── 2차
+    (화면) "편의점에서 살 수 있는 걸로"
GS에 만원짜리 치킨 추천해주는 화면
+ 이건 진짜 몰랐는데

── 3차
+    (화면) "혼자 먹기 좋은 양이야?"
+ 오케이 확인 완료

+ 처음엔 좀 엉뚱한 것도 알려주더라
```

> **진입 → 입력 → 답변** 3단계를 다 보여줘야 요건 충족. (DO ②)
> 마지막 줄(솔직한 소감)은 DO ①(피상적 칭찬 금지) 대응이라 꼭 한 줄 넣으세요.
> 화면 녹화본에 **알림·계정명** 안 찍혔는지 확인. (DO ④)

### #4 결정 (40~50초) · 폰 내려놓기 → 정면

```
+ 오늘 저녁은 이걸로 정했다
+ 고민 3분 컷
+ 저녁 뭐 먹을지 못 정하겠으면 이렇게 물어봐
+ 저장해두고 써먹어
```

> **이 영상의 진짜 가치는 "만원 치킨"이 아니라 "저녁 고민이 3분 만에 끝났다"** 입니다.
> 사지 않아도 성립하는 결론이라 정직하고, 시청자가 저장할 이유도 여기서 생깁니다.

## 💡 3초짜리 컷 하나만 더 (선택)

미션 브리프는 *"장소를 직접 방문하거나, 개강 필수템을 구매해 사용해보며"* 라고 예시를 듭니다.
사지 않아도 **필수 조건(AI탭 화면 노출)은 충족**되지만, 브리프 예시와는 거리가 생깁니다.

**엔딩에 "사러 나가는 뒷모습" 3초 컷 하나만 붙이면** 부합도가 확 올라갑니다.
구매도 리뷰도 안 하고, 문 열고 나가는 그림 하나면 됩니다.

```
+ (컷) 겉옷 걸치고 현관 나서는 뒷모습
+ 자막: "사러 감"
```

> 넣기 싫으면 안 넣어도 규정 위반은 아닙니다. 시간 남으면 찍어두세요.

## 오늘 반드시 지킬 것

| 항목 | 이유 |
| --- | --- |
| **30초 이상** | 위 구성대로면 약 50초. **AI탭 구간을 줄이지 마세요** |
| **가격·상품명은 화면에 나온 대로만** | AI탭 답변 화면 기준. 행사가는 시점·점포별로 다릅니다. 기억으로 쓰지 마세요 |
| **"이 시점 기준" 한 줄** | 가격 자막 옆에 작게. 사지 않았으므로 더더욱 필요 |
| **AI탭 3단계 화면** | 진입 → 입력 → 답변 |
| **AI탭 질문 3라운드** | 구매 컷이 없으니 여기서 분량이 나옵니다. 줄이면 30초 미달 |
| **솔직한 코멘트 1줄** | DO ① 대응 |
| **해시태그 3개 + 하단 문구** | 누락 시 요건 미달 |

```
3. (선택) 현관 나서는 뒷모습 3초
```
