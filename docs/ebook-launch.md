# 전자책 배포·판매 자산

> 책 두 권(무료판·유료판)을 **실제로 사람 손에 넘기는** 문구 모음.
> **[확인]** 저자 기록·공식 문서 / **[추정]** 추론 / **[모름]** 확인 불가

---

## 0. 전체 동선

```
릴스 (계속 올림)
   ↓  영상 안에서 언급
프로필 링크
   ↓
무료판 받기 (이메일/DM 등 수집 지점)
   ↓  읽고 실제로 영상이 바뀜
유료판 구매
```

**이 순서를 건너뛰지 마라.** `ebook-funnel.md`에 이미 적혀 있는 이유 —
**지금 오디언스가 지불 의사가 있는지 [모름]** 이라서다.
유료부터 만들면 안 팔렸을 때 원인을 알 수 없다.

## 1. 프로필 링크 문구

### 원리

| ❌ 안 되는 것 | 왜 |
| --- | --- |
| "프로필 링크 확인" | 클릭할 이유가 없음 |
| "전자책 판매 중" | 파는 사람 사정이지 보는 사람 사정이 아님 |
| "많은 관심 부탁드립니다" | 요청이지 제안이 아님 |

**되는 것 = 구체적 산출물 + 즉시성 + 방금 본 영상과의 연결**

### 무료판 단계 (지금 걸 것)

```
편집 프로그램 없이 릴스 만드는 법 ↓
```
```
릴스가 추천에서 빠지는 6가지 — 무료 ↓
```
```
내가 3개월간 틀린 것 전부 ↓
```

> **1번을 권한다.** 산출물이 가장 명확하다.
> 2번은 호기심은 세지만 "6가지"가 팁 나열처럼 읽힌다 [추정].

### 유료판까지 붙일 때

```
편집 못 해도 릴스 만드는 법 (무료 먼저) ↓
```

**"무료 먼저"를 붙여라.** 클릭 장벽이 내려간다 [추정].

## 2. 릴스 CTA

### 현재 쓰는 것 [확인]
> "이런 개꿀템 알려주는 AI 프롬프트 궁금하면 댓글에 정보 남겨줘!"

**제품 쪽 CTA다.** 무료판과 연결이 안 된다.

### 제작 축으로 바꿀 때

| 위치 | 문구 |
| --- | --- |
| 영상 마지막 자막 | **"이거 편집 프로그램 없이 만듦"** |
| 〃 (대안) | **"편집 못 하는데 만들었음"** |
| 캡션 첫 줄 | **"이 영상 편집 프로그램 안 쓰고 만들었습니다. 방법은 프로필 링크에"** |

> **주의: 미션 제출 영상에는 붙이지 마라.**
> 디깅클럽 활동물에 개인 전자책 유도는 운영사무국 확인 없이 하지 말 것 [확인 — `ebook-funnel.md`].

### 왜 "편집 못 하는데 만들었음"이 세나

자랑이 아니라 **결핍 선언**이다.
"잘 만들었다"는 부러움을 만들고, **"못 하는데 만들었다"는 가능성을 만든다** [추정].
보는 사람이 자기 얘기로 읽는다.

## 3. 무료판 배포 페이지 카피

### 헤드라인

```
내 릴스는 알고리즘에 진 게 아니었다
애초에 후보에서 빠져 있었다
```

### 서브

```
인스타그램이 공식 문서에 적어둔 "추천하지 않는 릴스" 6가지.
그리고 내가 영상 한 편을 19번 고치면서 틀린 것 전부.
```

### 본문

```
편집 프로그램을 다룰 줄 모릅니다.
프리미어도 파이널컷도 안 배웠습니다.

그 상태로 AI에게 시켜서 릴스를 만들었고,
3개월 동안 팔로워 약 1,000명이 됐습니다.

이 자료에는 "당신도 1,000명 된다"는 말이 없습니다.
그건 제가 모릅니다.

대신 두 가지가 있습니다.

1. 인스타그램이 공식적으로 밝힌 것 — 추측이 아니라 문서에 적힌 것
2. 제가 틀린 기록 — 훅, 자막, 컷 순서, 잘린 글자까지 그대로

시중 자료의 "3초에 50% 이탈", "도달 5~10배" 같은 수치는
출처가 확인되지 않아 한 줄도 넣지 않았습니다.
```

### 받기 버튼 위 문구

```
준비물 없습니다. 구독도 설치도 필요 없습니다.
읽고 오늘 올릴 영상부터 바뀝니다.
```

## 4. 유료판 판매 페이지 카피

### 구성 순서

```
① 헤드라인
② 19번 틀린 기록        ← 신뢰를 여기서 만든다
③ 목차 8장
④ 준비물               ← 구독 고지. 담백하게, 부정문 없이
⑤ 사지 마세요          ← 기대치만. 비용 얘기는 여기서 안 한다
⑥ 가격
```

> **④와 ⑤를 분리한 이유.** 비용 고지와 구매 차단을 같은 자리에 놓으면
> 구매 직전에 "손해 보는 느낌"이 된다. 정보는 위로, 차단은 기대치로만.

---

### ① 헤드라인

```
편집 프로그램 없이, 폰으로 릴스 만들기
```

### ② 서브 — 과장을 먼저 깬다

```
19개 버전을 만들었고, 자막 싱크를 세 번 틀렸습니다.
마지막엔 AI가 아니라 제가 귀로 듣고 잡았습니다.

"AI가 알아서 해준다"는 말은 이 책에 없습니다.
```

> **역방향 카피다.** 보통 판매 페이지는 쉽다고 한다.
> **어렵다고 먼저 말하는 쪽이 신뢰를 가져간다** [추정].
> "AI로 쉽게" 카피에 이미 지친 사람에게 먹힌다.

### ③ 목차

```
1장  폰에서 작업 환경 여는 법      ← 여기서 제일 많이 막힙니다. 제일 두껍습니다
2장  파일 준비 — 한글 파일명·폰트
3장  구간 지정 지시문 — "적당히"가 안 되는 이유
4장  합치기 — 여기서 첫 영상이 나옵니다
5장  자막·싱크 — 제가 세 번 틀린 곳. 실패한 방법 2개까지 공개
6장  안전영역 — 편집 화면은 거짓말을 합니다
7장  소스 구하기
8장  쿠팡 파트너스 연결
```

### ④ 준비물 — 자격 조건으로 쓴다

```
준비물

· 스마트폰
· AI 도구 유료 구독 (1장에서 안내)

이건 아무나 못 합니다.
월 구독을 감당할 사람만 쓰는 방법입니다.
```

> **같은 사실, 다른 프레임.**
> "돈이 더 듭니다"는 경고고, **"아무나 못 합니다"는 선별**이다.
> 정보량은 동일하고, 고지 의무도 충족한다.

### ⑤ 사지 마세요 — 기대치만

```
이 책을 사지 마세요.

· "클릭 한 번으로 완성"을 기대한다면
· 한 번에 성공하길 바란다면 — 저는 19번 만들었습니다
· 계정이 저절로 크길 바란다면 — 그건 보장하지 않습니다
```

> **비용 얘기는 여기 없다.** ④에서 이미 했다. 같은 말을 두 번 하면 그때부터 변명으로 읽힌다.

### ⑥ 보장 / 비보장

```
보장합니다      — 편집 프로그램 없이 릴스 1편을 끝까지 만드는 절차
보장하지 않습니다 — 계정 성장 · 조회수 · 팔로워 · 수익, 전부

제 기록: 인스타 3개월 약 1,000명 / 쿠팡 파트너스 2개월 중 가장 잘 나온 달 100만 원.
월 100만 원이 아닙니다. 2개월 중 한 달이 그랬습니다.
```

## 5. 가격 — 판매 인원별 단계 인상

### 확정 [저자 결정]

| 구간 | 가격 |
| --- | --- |
| **1 ~ 30번째 구매자** | **32,000원** |
| **31번째 ~ 59번째** | **50,000원** |
| **60번째 이후** | **80,000원** |

### 판매 페이지 문구

```
32,000원 — 30명까지입니다.

31명부터 50,000원, 60명부터 80,000원으로 올립니다.
미리 공지하고 시작합니다. 지금이 가장 쌉니다.
```

> **미래형이라 쓸 수 있다.**
> "원래 80,000원인데 할인" ❌ — 그 가격에 판 적이 없으면 허위 할인이다
> "앞으로 80,000원으로 올린다" ⭕ — 실제로 올리면 사실이다

### ⚠️ 반드시 지켜야 하는 것 — 한 번만 말한다

**공지한 인원에 도달하면 그날 올려라.**

31번째 구매자에게 32,000원에 팔면 그 순간 **허위 표시**가 되고,
다음 단계 공지가 영원히 안 먹힌다. 가격 인상 예고는 **지킬 때만 무기**다.

```
□ 판매 수를 셀 수 있는 채널에서 판다
□ 30번째 판매 직후 가격을 올린다 — 예외 없이
□ 인상 시점을 스토리·게시물로 공개한다 (다음 단계 신뢰가 여기서 만들어진다)
```

### 32,000원으로 시작하는 근거

| | |
| --- | --- |
| 후기 0개 | 첫 책이다. 높은 시작가를 정당화할 증거가 없다 |
| 30명 = 후기 수집 구간 | 이 30명이 다음 가격의 근거를 만든다 |
| 30,000 아닌 32,000 | 딱 떨어지면 "대충 정한 값"으로 읽힌다 [추정] |

> **시장 가격대는 [모름]이다.** 위 숫자는 저자 결정이고, 근거는 시장 데이터가 아니라
> "증거가 쌓이는 만큼 올린다"는 논리다.

### ⛔ 하지 말 것

- **"원래 80,000원"** 이라고 쓰기 — 판 적 없으면 허위
- 할인 전 가격 지어내기
- 인원 도달했는데 안 올리기

## 6. 출시 순서

```
D+0   무료판 배포 → 프로필 링크 교체 → 릴스 CTA 변경
D+3   유료판 오픈 (32,000원 / 30명 한정 공지)
      → 무료판 반응을 판매 페이지에 붙일 수 있다
계속  구매자에게 "어디서 막혔는지" 직접 묻기  ← 이게 유료판 8장을 채운다
30명  가격 50,000원으로 인상 + 공개 공지
```

> **무료판과 유료판을 같은 날 내지 마라.**
> 무료판이 유료판의 증거인데, 동시에 나오면 무료판이 광고로만 읽힌다.
> 3일이면 충분하다.

> **3주차를 건너뛰지 마라.**
> 지금 유료판에서 가장 약한 게 8장(쿠파스)이고, 두 번째가 1장 실제 이탈 지점이다.
> **무료판 독자가 그 데이터를 준다.** 추측으로 채우면 감사에서 또 걸린다.

## 7. 판매 채널 · 수집 지점

### 요구조건이 먼저다

가격을 인원별로 올리기로 했으므로 채널이 만족해야 할 조건이 정해져 있다.

```
□ 판매 건수를 실시간으로 셀 수 있을 것   ← 30명·60명 기준 때문에 필수
□ 가격을 즉시 바꿀 수 있을 것
□ 인스타 프로필 링크 하나로 연결될 것
□ 구매자에게 연락할 수단이 있을 것        ← 후기 요청용
```

### 유료판 → 크몽 권장

| | |
| --- | --- |
| **이미 계정과 거래 이력이 있다** | 6개월 판매 경험 [확인]. 새로 배울 게 없다 |
| 결제·정산 자동 | 계좌이체 수동 처리를 안 해도 된다 |
| 유입 | 플랫폼 자체 트래픽이 있다 [추정] |

**수수료는 약 20%** [추정 — 블로그 출처. 크몽 공식 고객센터는 세금계산서 절차만 안내].
**정산은 월 단위, 구매확정 기준** [확인 — 크몽 고객센터].

→ **돈이 바로 안 들어온다.** 출시 직후 현금이 필요하면 이 점을 계산에 넣어라.

### 수수료 20% 기준 실수령 [추정]

| 구간 | 판매가 | 실수령 | 수수료 |
| --- | --- | --- | --- |
| 1~30명 | 32,000 | **25,600** | 6,400 |
| 31~59명 | 50,000 | **40,000** | 10,000 |
| 60명~ | 80,000 | **64,000** | 16,000 |

> 30명 다 팔면 판매액 960,000원 / 실수령 약 768,000원 [추정].

### ⚠️ 가격이 오를수록 수수료 절대액이 커진다

80,000원 구간에서는 **한 건당 16,000원**이 나간다. 32,000원 구간의 2.5배다.

```
1~30명   크몽      ← 편하다. 수수료 감수
60명~    자체 판매 검토  ← 건당 16,000원이면 수동 처리할 값어치가 있다
```

**지금 정할 필요는 없다.** 60명까지 가면 그때 다시 본다.

### 무료판 수집 → 오픈채팅 권장

| 방식 | 마찰 | 재접촉 | 판단 |
| --- | --- | --- | --- |
| **오픈채팅** | 낮음 | **가능** | ⭕ 권장 |
| 구글폼(이메일) | 높음 | 가능 | 자산은 남지만 이탈 큼 [추정] |
| DM 수동 | 중간 | 가능 | 30명 넘으면 감당 안 됨 |
| 링크 바로 공개 | 없음 | **불가** | 누가 받았는지 모름 |

**오픈채팅을 권하는 이유는 재접촉이다.**
무료판 받아간 사람에게 **3일 뒤 유료판 오픈을 같은 방에서 알릴 수 있다.**
링크를 그냥 공개하면 그 사람들을 다시 찾을 방법이 없다.

```
동선
프로필 링크 → 오픈채팅 입장 → 공지에 무료판 파일 → D+3 유료판 공지
```

> 입장하자마자 파일이 보여야 한다. **"인사하면 드려요" 같은 조건 걸지 마라.** 거기서 나간다.

### 직접 확인할 것 [모름]

```
□ 크몽 수수료율 — 카테고리별로 다르다. 전자책 카테고리 실제 요율
□ 크몽에서 판매 건수를 실시간으로 볼 수 있는지
□ 크몽 상품 가격을 즉시 수정할 수 있는지 (30명 도달 시 당일 인상 가능해야 함)
```

**세 번째가 제일 중요하다.** 가격 수정에 심사가 걸리면 단계 인상 공지가 깨진다.

## 8. 아직 안 정한 것

```
✅ 가격        — 32,000 / 50,000 / 80,000 단계 인상
✅ 출시 목표일  — 무료판 즉시, 유료판 +3일
```
