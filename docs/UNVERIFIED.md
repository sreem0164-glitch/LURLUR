## 확인되지 않은 것을 다룰 때의 규칙

1. **모르면 "모른다"고 쓴다.** 그럴듯한 표로 만들지 않는다.
2. **사례 1~2건으로 시장 상황을 단정하지 않는다.**
3. **제품 성능을 전제로 구조를 짜지 않는다.** 테스트 결과를 먼저 받는다.
4. 영상 자막에 쓸 주장은 **화면으로 증명 가능한 것만** 쓴다.
