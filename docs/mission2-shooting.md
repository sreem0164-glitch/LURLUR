## 1. AI탭 화면 녹화 ★ 가장 먼저

**집에서 지금.** 이게 안 되면 영상이 성립하지 않습니다.

### 준비

1. **방해금지 모드 켜기** — 알림 뜨면 재촬영 (DON'T ④ 계정명·알림 노출 금지)
2. 네이버 앱 실행, **홈 화면부터** 시작
3. 폰 화면 녹화 시작

### 녹화 순서 — 끊지 말고 한 번에

```
① 네이버 홈 화면 (2초 정지)
② AI탭 버튼 누르는 장면
③ 질문 입력:
   창업 알아보는 중인데 무인점포는 다 망하고 파리바게뜨 하이브리드는 왜 달라?
④ 답변 뜨면 천천히 스크롤
   → 표(완전 무인 vs 하이브리드) 나오는 데서 2초 멈춤
   → 출처 표기(조선비즈 등) 보이는 데서 2초 멈춤
⑤ 이어서 두 번째 질문 입력:
   동네에 파바 또 있는데 왜 역 앞 매장만 바꿨을까?
⑥ 답변 뜨면 다시 천천히 스크롤, 핵심 문단에서 2초 멈춤
⑦ 녹화 종료
```

**⚠️ 질문 2개를 반드시 한 번의 녹화로.** 따로 찍으면 대화가 이어지는 게 안 보여서
가이드 ②("질문을 이어가며")를 못 지킵니다.

**⚠️ 스크롤은 아주 천천히.** 빠르면 편집에서 정지프레임을 못 씁니다.

총 1~2분이면 충분합니다.

## 2. 공실 — 2~3곳 ★ 훅

**각 5초씩, 멈춰서.**

| 프레임에 들어가야 할 것 | 들어가면 안 되는 것 |
| --- | --- |
| 내려간 셔터 | **간판 상호** |
| 임대 문의 문구·전화번호 종이 | 사람 얼굴 |
| 텅 빈 내부 (유리 너머) | 차량 번호판 |

**상호가 읽히면 "저 가게 망했다"가 되어 특정 업체를 지목하는 모양이 됩니다.**
간판이 잘리게 아래쪽 위주로 잡거나, 각도를 틀어주세요.

3곳이 연속으로 지나가야 "이 동네 자리가 안 붙는다"가 3초 만에 전달됩니다.
1곳만 찍으면 "저기 하나 비었네"로 끝납니다.

## 3. 탄방역점 외관 ★ 밤에

**해 진 뒤에.** 낮에 찍으면 24시간이라는 게 그림으로 안 읽힙니다.

| 컷 | 길이 | 내용 |
| --- | --- | --- |
| 3-a | 8초 | 매장 전체 — **24시간 표기가 보이게** |
| 3-b | 5초 | 간판 클로즈업 |
| 3-c | 5초 | 불 켜진 매장 안이 유리 너머로 보이게 |

**밤 촬영 주의** — 어두우면 셔터가 느려져 흔들립니다. 벽이나 난간에 **팔을 대고** 찍으세요.

## 4. 그랜드 오픈 흔적 · 새 인테리어

**5초.** 현수막·화환·리뉴얼 안내문 있으면 그거. 없으면 새로 한 인테리어가 보이는 각도.

"공사해서 바꿨다"가 영상의 핵심 논리라 이 컷이 근거가 됩니다.

---

## 5. 입구 카드 인증 장치

**5초, 가까이.**

하이브리드의 증거입니다. 카드 대는 단말기나 안내 스티커를 화면에 꽉 채워주세요.
**실제로 카드 대고 문 열리는 장면**이 찍히면 제일 좋습니다.

---

## 6. 키오스크 · 바코드 스캔

**각 5초.**

| 컷 | 내용 |
| --- | --- |
| 6-a | 키오스크 화면 |
| 6-b | 제품 바코드를 스캔하는 손 |

6-b는 **손이 움직이는 장면**이라 영상에 생기를 줍니다. 꼭 찍어주세요.

## 7. 탄방동 일반 파리바게뜨

**5초.** 질문②("동네에 파바 또 있는데")의 근거 컷입니다.

**3-a와 비슷한 각도·거리로** 찍어주세요. 나란히 붙였을 때 비교가 됩니다.
