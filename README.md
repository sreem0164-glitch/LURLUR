## 핵심 요약

1. **후킹과 정보는 반비례** — 한쪽을 정하고 반대쪽을 덜어낸다.
2. **두 번째 펭귄이 되라** — 기업 광고가 붙기 시작했다면 이미 마지막 펭귄이다.
3. **목적 없는 기획은 없다** — 도구를 쓰는 것이 아니라 목적이 기획을 이끈다.
4. **숏폼의 썸네일은 인트로다** — 첫 1~2초가 클릭이자 이탈 방지다.
5. **기획안은 반드시 쓴다** — 장표가 아니어도 머릿속에서는 정리되어 있어야 한다.
6. **편집을 알아야 기획이 넓어진다.**
7. **3초 안에 승부를 본다** — 궁금증·문제·반전·결과 중 하나를 맨 앞에.
8. **미션 영상은 계정에 별도 게시물로** — 전량 직접 촬영, 캡션에 제휴 링크 없이.

## 업로드 계정

미션 콘텐츠는 **네이버 클립 + 인스타그램 `푸리랩이슈`** 에 동시 업로드합니다.
계정은 얼굴을 노출하지 않는 **손 컷 + 자막** 포맷이며, 평소의 재편집 릴스와 달리
미션 게시물은 **전량 직접 촬영**한 별도 게시물로 발행합니다. 자세한 기준은
[푸리랩이슈 계정 운영 기준](./docs/account-purilab-issue.md)을 보세요.
